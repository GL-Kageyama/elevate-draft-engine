**`ledg` —「AIは嘘をつく。台帳は嘘をつかない。」**

**核心的主張**: AI時代に金を生むCLIは、AIを一切使わない。モデルは商品化が速く差別化は数ヶ月で消える——付加価値は測る側に移る。企業が最初に抱える痛みは「誰がいくらトークンを使ったか、誰も知らない」という会計の闇であり、勝つのは測定ツールだ。買い手は開発者ではない。CFOと監査役が払う。

**②課題と対象**: Claude Code・Cursor・自作エージェントの乱立で、費用が誰にも帰属しない「シャドーAI支出」が全企業で爆発している。対象は100人超企業のプラットフォーム責任者と財務部。支払い能力は最も高く、EU AI Actの開示義務が追い風になる。

**③主要機能**:
- `ledg run -- claude` — コマンドを包み、全LLM呼び出しのトークン量と費用を傍受して追記型台帳に記録
- `ledg report --by team --month 2026-07` — 部門別月次費用をJSON/CSVで出力
- `ledg check --budget 200000` — 予算超過で非ゼロ終了。CIゲートに組み込み
- `ledg audit --verify` — ハッシュチェーン検証で改ざんの不在を証明

**④Rustの理由**: 単一静的バイナリでランタイム不要——企業配布の敷居が最低。TLS終端と高頻度ロギングを安全かつ高速に処理し、SHA-256による改ざん検知も安全に扱える。clap・tokio・hyperの成熟エコシステム。

**⑤シンプルさ**: DBなし(追記型JSONL+ハッシュ連結)、デーモンなし、SaaSなし。SDK組み込みも不要——`ANTHROPIC_BASE_URL`等の環境変数にローカル転送プロキシを挟むだけで捕捉できる。本体約1,500行、依存はtokio・hyper・clap・serdeに限定。

**根拠**:
- 監査台帳は必須コンプライアンス予算であり、ツール支出と違い景気に依存しない
- 全データ社内完結のため、SaaS競合(Helicone等)と違いセキュリティ審査を通過して企業内に侵入できる
- 追記型台帳は記録が溜まるほど離脱コストが上がる——構造的ロックイン

**前提**: AI支出の監査が規制・ガバナンス上必須になる2026年の流れが継続すること。
