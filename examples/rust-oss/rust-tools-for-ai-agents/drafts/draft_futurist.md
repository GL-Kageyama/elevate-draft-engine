# 草案：Vellum —— エージェント実行の決定的リプレイ・検証基盤

## 核心的主張
エージェントの全実行（LLM応答・ツール結果・コンテキスト遷移）を追記型の決定的実行ログに記録し、任意時点への巻き戻し・分岐・再検証をビット完全に可能にする実行時基盤「Vellum」を、課題『信頼性』に対して作る。Rustを核とする理由は、GC非決定性ゼロの直列化と所有権によるコンテキスト生涯管理により、『記録と実行の一致』を言語レベルで保証できる唯一の言語だからだ。モデルの賢さがコモディティ化するほど、この記録層の価値は暴騰する——今最も過小評価されている資産である。

## 根拠
- LangChain等はループを抽象化するが実行の決定性を扱えず、誤動作の再現手段がない——Vellumは全実行を数百バイトのログ行に落とし、tokio上で高頻度ループを無停止で記録する（性能）。
- モデル・ツールの更新頻度が上がるほど旧バージョンとの挙動差分の検証需要は指数的に増える——毎回のリリースがVellumへの参照を義務付けるアンチフラジル構造（時間とともに価値増）。
- 単一バイナリで『実行可能な監査証跡』を顧客に納品できる——Pythonランタイム前提の既存基盤には不可能な、配布と安全性の同時解決。

## 前提
金融・医療・インフラなど実害領域でエージェントを運用する中〜大規模プロダクション開発者。LangSmith等は観測を外部SaaSに委ね決定的再生を保証しない——本構想は観測より一回り深い『再生可能な時間』という層を独占する。
