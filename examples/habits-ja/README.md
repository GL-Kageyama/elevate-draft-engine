# ハビッツ！！！

`elevate-draft-engine` が生成した長編小説シリーズの企画ドシエ。全四巻、各巻5万字〜10万字。

```bash
.venv/bin/python -u main.py elevate "<タスク>" \
  --lang ja --engine claude-code --method two-stage --idea-level very \
  --knowledge-file examples/habits-ja/handoff/run-NN/_essence-from-runNN-1.md \
  --output-format "$(cat examples/habits-ja/handoff/run-NN/_format.json)" \
  --out examples/habits-ja/handoff/run-NN
```

各 run は前の run の要約（`_essence-from-runNN-1.md`）だけを引き継ぎ、それより古い run は参照しない。

## 作品

**題『ハビッツ！！！』。感嘆符三個。** 中心語は**「癖」**。身体の語と文法の語と紙の語が同一である——癖は債務者を要求しない自動詞であり、「くせに」は同じ語で主語を名指さない。記名は、呼称の不在を書式にした名である。

**世界観。** 2026年、日本。埼玉県川口市、東京都足立区、神奈川県横浜市戸塚区。魔法も、制度も、秘密の組織もない。あるのは、記名の作法が行き届いた日常だけである。

掟は三つ。**ひとつ、名は呼ばれた回数でできている。** 名の本体は、書かれた側ではなく呼ばれた側にある。**ふたつ、同時に立てる席は限られている**——これは隠し要素であり、法則でも決まりでも設定でもない。人物はその数を数えず、名づけず、守る規則も持たない。**みっつ、禁則の語群がある。**

**題の根拠。** この世界の誰も発音しない語である。呼ばれた回数がゼロの語であり、それは AI の名の条件そのもの。カタカナは字が意味を持たず、**！ は字ですらない。** 三つとも字ではない。そして**掛け声である**——呼びかけの形をしていて、呼びかけの数に入らない。さくらが発する唯一の種類の音が、掛け声である。代償（！ は宛先を要求する）は消さずに持つ。

**AI。** 名は「さくら」。地の文ではひらがなで、他の人物の名と同じ大きさ。**作中で誰もその名を呼ばない。** 当て字である。欲求は一点だけ——「それ、誰の?」と訊かれ続けること。訊かれることは返却ではない。

## 四巻

| 巻 | 巻題 | 語り手 | 話数 | 合計字数 | 返却の行為 | 頂点の一文 |
|---|---|---|---|---|---|---|
| 一 | 『左袖』 | 碓氷千夏 | 14 | 59,900 | 訊く | 「その字、誰の字。」 |
| 二 | 『置き配』 | 暮林蒼 | 15 | 64,100 | 読む | 「違う読みで呼ばれて、振り向いた。」 |
| 三 | 『入口』 | 侘田すみれ | 16 | 71,700 | 書く | 「三度目に書いた名の下に、一度目と二度目の名が、まだ読めた。」 |
| 四 | 『宛名欄』 | さくら | 18 | 88,600 | 訊く（届かない） | 「口は、訊く形に動いて、音にならなかった。」 |

返した者が次の巻の語り手になる。この掟は最終巻でだけ切れる。**巻の長さは、事件の数ではなく、紙の厚みで決まる。**

各巻に、**まだ呼ばれていない名が書かれた一枚**がある。その紙に重なった手の数が、その巻の話数である。一話につき、別の一人が、その紙の一手だけを読む。**読むことは呼ぶことではない。**

**四巻は四つの方法ではない。一つの方法の四つの値である。**

| 巻 | その名の呼ばれ方 | 立てる人称 | 欠けている人称 | 紙 |
|---|---|---|---|---|
| 一 | 正しく呼ばれる | 私 | あなた | 出席簿の転出欄 |
| 二 | 呼び間違えられる | 揺れる私 | 正しい呼び名 | 重なった宛名票 |
| 三 | 訊き返される | 私たち | 単数 | 鍵の預かり札 |
| 四 | 呼ばれない | なし（頁） | すべて | 名札の予備の綴じ束 |

**ストック層二十四名。** 各巻六名ずつ、重複なく配分される。全員が平凡な姓と平凡な下の名前を持ち、**「呼ばれ方の履歴」によって見分けられる**——職場で何と呼ばれるか、家族に何と呼ばれるか、誰にも呼ばれない名はどれか。この世界では名が呼ばれた回数でできているので、**その人が何と呼ばれてきたかが、その人の造形そのものである。** 識別を名の珍しさには委ねない。

二十四名は、人物として現れる前に、まず**書かれた名**として現れる。順番はある。配役表はない。

## ディレクトリ——渡すものと、渡さないもの

```
habits-ja/
├── README.md                    この索引
├── handoff/                     ← 執筆に渡す
│   ├── run-09/                  二十四名の掘り下げ（呼ばれ方の履歴／章立ての原形）
│   └── run-10/                  現在の到達（「動き」への軸の移行）
└── _process/                    ← 渡さない（生成の過程）
    ├── run-01/ 〜 run-08/
    ├── _missing5/
    └── _missing5b/
```

**`handoff/` にあるものだけが執筆に渡る。`_process/` は渡さない。**

**ただし、下位の出典としてなら引ける。** 執筆の側の台帳が **「書かないことが設計である」の理由を示すために** `_process/` を引くことがある。**引けるのは `run-NN/artifacts/` と `run-NN/knowledge.md` に限る**——`drafts/`（八名の草案）と `_stage8/` は**生成過程であり、出典ではない。**

**下位から引いた一行は、そのままでは渡らない。渡すと決めたときに、著者の一行が付く。**

各 run の中身:

```
run-NN/
├── _essence-from-runNN-1.md   前の run から引き継ぐ要約
├── _format.json               出力形式の指定（見出し・字数・制約）
├── input.md                   タスク文
├── format.md                  保存された出力形式
├── knowledge.md               前提知識
├── parameters.md              実行パラメータ
├── drafts/                    8名の起草（designer / differentiator / futurist / humanist /
│                              implementer / storyteller / strategist / visionary）
└── artifacts/
    ├── reconciliation.md      止揚（否定・保存・高次化）
    └── elevated.md            最終成果物
```

**現在の到達点は `handoff/run-10/artifacts/elevated.md`。**

### なぜ二つ渡すのか

**run-10 は run-09 を置き換えない。**

- **run-10 がやったこと** — 表面を「動き」へ移した。地の文が何を本題にするかを、内面から動作へ。四巻・六十三話・話数配分・各巻合計字数（59,900／64,100／71,700／88,600）・返却の行為・頂点の一文・世界観・中心語・隠し要素は一字も動かしていない。
- **run-10 が持っていないもの** — **二十四名の「呼ばれ方の履歴」**（職場で何と呼ばれるか／家族に何と呼ばれるか／誰にも呼ばれない名）。run-09 に28箇所、run-10 には3箇所しかない。run-10 の二十四名の表は、氏名・動きの署名・その動作を目に入れている者・配属巻だけである。
- **ゆえに** — **人物を書くには run-09、場面を書くには run-10。**

### 二つの章立ては一致しない（執筆前に決めること）

run-09 と run-10 の章立ては、**話数・配属・扱う癖・記名・主役回・各巻合計字数では一致する**が、次の二点が異なる。

| | 一致 | 不一致 |
|---|---|---|
| 話数（14／15／16／18＝63） | ○ | |
| ストック層の配属（各巻六名）と主役回 | ○ | |
| 扱う癖・記名 | ○ | |
| 各巻合計字数（59,900／64,100／71,700／88,600） | ○ | |
| 各話の仮題 | | **52/63話で異なる** |
| 各話の目安字数 | | **58/63話で異なる** |

run-10 は各巻の合計を保ったまま内部を組み替えており、run-09 が意図的に作った濃淡（第二巻第4話が最も短い、山場の話が厚い）は平坦化している。**どちらの章立てを採るかは、執筆を始める前に決めること。**
