# タスク

【run-06】run-05 の企画書1本を改訂する。案は増やさない。企画は1本のみ。

■ 動かさないもの
中心語は「癖」。由来（債務者を要求しない自動詞／「くせに」と同語／所有者スロットなし）も動かさない。
タイトルは現行『くせに』。依頼者は「KUSENI とローマ字表記するなら許容する」と判断済み。これが現行の題である。
語の禁則（金融・債務・経済、および愛・所有・関係・恩・縁・功徳）も動かさない。深いものには名詞を与えず、疑問詞と否定形で言う。
隠し要素の規約（四つの通路＝呼称の揺れ／沈黙の長さ／発話の順番／「も」の位置。容量の申告ではなく主語の可視性）も動かさない。
ストック層の生成規則（ひとつの癖＋その帰属の未決・20〜30名）も動かさない。

■ 今回の課題は四点である。

【1】タイトル
『くせに』を前提に置いたうえで、この世界を射抜き、かつ作品名として成立する題を探せ。
「射抜く」とは、題から世界観が滲むこと。「作品名として成立する」とは、書店に並んで恥ずかしくなく、口に出して言いたくなること。
より良い題があるなら代える。無ければ KUSENI を維持する。維持する場合も、なぜそれが世界を射抜くのかを書くこと。
題は作中で誰も口にしない。誰も説明しない。

【2】キャラクター
四人（碓氷千夏・暮林蒼・侘田すみれ・AI）を一旦すべて再考する。碓氷千夏は依頼者が「かなりいい」と評価しているので、活かす方向で検討してよい。
各人に必ず次を付す——名前／性別／年齢／プロフィール（どこに住み、何で食っているか。職業と生活）／欲求／AIとの関わり／ルック／声／魅力。
名前は識別の代わりにならない。珍しい名前を並べることは造形ではない。
ストック層も同じ基準で作り直す。20〜30名、全員に一行のフック（ひとつの癖＋その帰属の未決）。

【3】現代日本との接続（今回の要）
run-05 の人物の細部は、2026年の日本に実在しないものが多い。代表例は「上着の両ポケットが吸い殻で膨らみ」。喫煙率は一割台まで落ち、路上喫煙は厳しく制限されている。吸い殻を両ポケットに入れて歩く人物は、読者の職場にも近所にもいない。匂いの時点で成立しない。
判定は次の三つ。
(a) その人物は、2026年の日本のどこに住み、何で食っているか。具体的に言えるか。
(b) 読者はその人物を、自分の職場・家族・近所の誰かとして思い出せるか。
(c) その細部を、あなたは確かめたか。確かめずに書いた細部は落ちる。
煙草に寄りかかった造形は、この作品から全面的に落とす（煙管を持ち歩く人物、吸い殻で膨らんだポケットなど）。ただし中心語「癖」の同語性の論証は動かさない——例だけを、2026年の日本に実在する癖に差し替えること。

【4】AI
(a) AIを「AI」と呼ばない。この世界特有の固有名を与え、その名で読ませる。AIの性質が名のヒントになる。名はこの世界の語彙の中から出て、その由来を書くこと。
(b) AIは第一巻第一話から常に世界に関わっていること。第三巻以降で急に前景化する構造を禁ずる。前景・背景を問わず、毎話にAIの関与があること。
(c) run-05 は「名を持たない者だけが、他人のずれを名指せる」という論証の上にAIの機能を建てていた。名を与えるなら、この論証を組み替えること。名を持ちながら、AIが「受け取ったことのない者」であり続ける道を探せ。

■ 出力
企画は1本のみ。
