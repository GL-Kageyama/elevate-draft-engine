# run-01 から持ち越すエッセンス（要約。全文の引用ではない）

run-01（8草案の弁証法的止揚）が到達した知見のうち、run-02 に効くものだけを残す。
固有名・時代設定・色彩・キャラクター名は run-01 の一解答にすぎないので引き継がない。

## 1. 枠組みの反転（持ち越す）

「1画面の人数制約」を、外から与えられた不純物として物語へ移植するのではない。
小説はもともと「視点」という制約を発明した張本人であり、読み続けられる限りにおいてのみ成立している。移植ではなく想起。

## 2. 制約の由来を問うた六立場と、その共通の僭称（持ち越す）

法／認知／儀礼／語り／経済／識別。六つとも「由来を語った」瞬間に僭称になる。
**説明した瞬間、不条理は制度になり、恐怖は設計図になる。**

由来を剥ぎ取ったあとに残るのは、六つとも同じ一つの動詞の活用形である——
交渉する・疲れる・数える・息をする・払う・見分ける。
これらは皆「いま、誰かを心に置く」という一つの行為の相であり、
**制約とは規則ではなく行為である。** 行為は毎日やり直されるから、隠すことも説明することもできない。ただ演じられるだけである。

## 3. 到達した機構（機構として持ち越す／世界法則として掲げることは持ち越さない）

- **保持残量**——人はいま誰かに心へ置かれている間だけ個であり、置ける数は固定の定数ではなく、疲労・愛・酒・喪で増減する残量である。
- 落ちた者は死なず**群**（名を失った集合）になる。落ちた者にも内面がある。
- 話すことは、群から一人を掬い上げ、別の誰かを沈める**転移**である。
- AIは制約の主体ではない。制約を課す者ではなく、制約が残した会計の帳尻であり、群の側から来る声である。
- ゆえに悪者は存在しない——**悪者がいないのに、毎日誰かが群へ戻っていく。**

## 4. 未解決の亀裂（持ち越す）

run-01 の三案（呼ぶ／数える／語る）は、**「呼びかけられなかった者は、呼び返せるか」**の一点で相容れなかった。
一方は呼び返せると賭け、一方は呼び返せないと断じ、一方は呼び返しを読者に委ねた。この亀裂は解消しない。読者だけが抱えられる問いである。

## 5. run-02 で反転させること（重要）

run-01 は上記の機構を**世界の存在論として全面に掲げてしまった**（世界法則・命名・組版の崩壊という形で読者に見せた）。
run-02 ではこれを採らない。**人数制約は隠し要素である。**

世界観の側から制約を説明・命名・法則化してはならない。
制約は、場面の切り取り・人物の配置・会話の力学としてのみ働く。
読者は制約を「設定」として知るのではなく、気づけばそうなっている、という形でのみ受け取る。

## 6. run-01 で不足していた観点（run-02 の課題）

- **日本の現代社会の写し鏡**であること。制度・金・労働・家族・孤独が、読者の今日の生活と地続きであること。run-01 の三案は、昭和三十年代の町・無機質なオフィス・白紙の帳簿と、いずれも抽象度が高く、現代日本の具体から離れていた。
- **20〜30人の魅力的なキャラクターが世界観にストックされている**こと。run-01 は各案4名しか具体化せず、ストックが活きている感じが出なかった。どの人物もいつか主役になりうるという気配が要る。
