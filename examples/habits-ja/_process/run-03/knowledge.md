# run-02 から持ち越すエッセンス（要約。全文の引用ではない）

run-02（8草案の弁証法的止揚）が到達した知見のうち、run-03 に効くものだけを残す。
固有名・現場（訪問介護／行旅死亡人／フードデリバリー）・キャラクター名は run-02 の一解答にすぎないので引き継がない。
run-01 の文書は参照しない。run-02 が既にその生存分を継承しているため。

## 1. 隠し要素の取扱規約（最重要・そのまま持ち越す）

「場面に同時に立てる席は限られている」——この上限は**隠し要素**である。
世界法則でも、法制度でも、設定でもない。人物はその数を数えず、名づけず、守る規則も持たない。
作中で禁ずる語：「上限」「定員」「キャパ」「枠」。設定資料にも数字を置かない。
読者に届く通路は四つだけ——**呼称の揺れ／沈黙の長さ／発話の順番／「も」の位置**。
読者はそれを設定として知らず、気づけばそうなっている、という形でのみ受け取る。
数え終わらせない。数えようとする場面は書いてよいが、必ず途中で別の用事が来る。

## 2. 反転の核（持ち越す）

**「何人まで」ではなく「誰が主語に立てるか」。**
上限は存在しない。存在するのは「いま、誰が主語か」だけである。
席の数は疲労・酒・喪で増減して見えるから、数えようとした者は必ず数え損ねる。

## 3. 到達した機構（持ち越す）

- **AIの位置**——AIだけが常に全員を名で呼べる。人間の会話には数人分の名しか出てこない。この落差が毎話の背景音になる。AIは理由を語らない。名を並べるだけである。AIのこの能力は、能力の名ではなく「誰も心に置けないこと」の別名である。
- **悪者がいない**——悪意ある者はいない。誰も規則を持たないのに、毎日誰かが零れていく。これが現代社会の作りそのものである。
- **ストック層**——20〜30人の全員が「主語の順番」を持っている。第1話で名前も呼ばれなかった人物に、第9話で一章が与えられる。読者は配役表を見せられないまま、まだ会っていない主役が二十何人も残っていると感じる。
- **躍動**——「主語の席が崩れる時間」として設計する。助詞が落ち、名が消え、敬体が吹き飛ぶ。会話に戻った瞬間、名前が戻る。読者は理由を知らないまま安堵する。

## 4. 継承されてきた系譜（背景として知っておく）

run-01 が到達し、run-02 が文法へ回収したもの——制約は規則ではなく**行為**である。
交渉する・疲れる・数える・息をする・払う・見分ける、は皆「いま、誰かを心に置く」という一つの行為の相である。
だから制約は隠すことも説明することもできず、ただ演じられる。
**説明した瞬間、不条理は制度になり、恐怖は設計図になる。**

## 5. 未解決の亀裂（持ち越す）

**すでに主語だった者が、再び目的語に戻ったとき、その人の内面は誰の文法で書かれるのか。**
これは解消しない。読者だけが抱える。

## 6. run-03 で満たすべき不足（run-02 が届かなかった点）

- **現代ファンタジーとしての世界観が無い。** run-02 は現代の写実に留まり、幻想の層を持たなかった。写し鏡であることは維持したまま、その上に確としたファンタジーの層を立てる必要がある。
- **AIが骨組みになっていない。** run-02 のAIは記録・シフト・与信といった道具であり、人間キャラの合間を埋める要素に留まった。AIキャラクター、AIによる仕組みを、物語を駆動する構造として設計する必要がある。
- **タイトルが世界観を掴ませない。** run-02 の各案のタイトルは現代の事物の名であり、幻想の層も世界の法則も滲まない。
- **キャラクターの視覚的特徴が、ビジュアル化を想定した識別性を持たない。** run-02 の描き分けは手や持ち物の細部に寄り、既存キャラとの類似を避ける設計になっていない。
