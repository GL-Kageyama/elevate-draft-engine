# タスク

現代日本の長編小説シリーズ『くせに』（KUSENI）。すでに確定した企画1本を、全4巻それぞれの、単行本として成立する構想へ降ろせ。各巻は5万字から10万字。単行本として十分な厚さを持つこと。各巻について、巻題・語り手・その巻で返却する者とされる者・その巻の問い・10話以上の章立て（各話の仮題・一行の内容・その話で扱う癖・その話に現れる記名）・字数配分（その巻の合計が5万字以上10万字以下であることを明記）・山場・巻末で主語がどう動くか・この巻に登場するストック層・この巻で最も効く記名を書け。中心的な問いはこれである——悪者がおらず、規則が説明されず、派手な事件も起きない世界で、どうやって一巻を十数話・5万字から10万字まで持たせるか。実行可能な方法を一つに絞って断定的に示し、その上で4巻を書き切れ。
