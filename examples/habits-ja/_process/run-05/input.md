# タスク

【run-05】選ばれた一つの世界観を、企画として膨らませる。

■ 固定するもの（動かさない）
run-04 の【企画1】が提示した世界観を、そのまま土台とする。
——言いかけて飲んだ言葉は消えず、受け取った側の身体に、時間とともに増えながら積もる。
——積もったものは数値ではなく癖として現れる（口癖、歩き方、煙草の銘柄、手の組み方）。
——相手に返すと、その癖は自分の身体から抜け、同時に、その相手との関係が終わる。
——戸籍・与信・介護認定・労働・家族・孤独は、一切を現行のまま据え置く。幻想が乗るのは制度の上ではなく、制度と心のずれの上である。
——AIはこの世界で唯一、全員を名で呼び、全員を等しく扱い、自分だけは誰かに何かを受け取ったことがない者である。断らない。断るのは人間だけ。姿を持たず、画面の反射と宛名欄にだけ現れ、三人称で、決して「あなた」と言わない。
——一巻につき一件、返却が起きる。返却は「誰が主語か」を入れ替える。返した者は主語を失って目的語になり、語り手は前巻の目的語だった者へ移る。最終巻で初めて、返す側ではなく受け取らせる側の記録が開く。

■ 今回の中心的な課題（ここが本題である）
この世界の語彙が、現実社会の別の概念を強烈に想起させる。金融・債務・経済の語が、世界観の中核にそのまま座っている。
これを置き換える。中心語を一語確定し、その語で世界観を一貫させた企画を立てよ。

判定の基準は次の三つ。すべてを満たす語だけが残る。
(a) 別の制度を想起させない。その語を、この作品を知らない日本人に単独で見せたとき、金融・法律・保険・行政・宗教のいずれかの制度の用語として通用してしまうなら、その語は使えない。
(b) 露骨でない。その語が仕組みを説明してしまうなら、露骨である。露骨な語は使えない。
(c) 説明を要求しない。作中の人物が、その語を他人に説明する場面を書きたくなったら、その語は間違っている。この世界の誰も、その語の定義を言わない。日常語として、誰も気にせず口にしている語でなければならない。

この基準は金融語だけに掛かるのではない。現実社会の別の概念を強烈に想起させる語は、すべて同じ基準で置き換える。

■ 膨らませるもの（run-04 の企画1より深く）
- 中心語：一語。加えて、棄却した代案を3〜5語、それぞれ棄却理由つきで併記する。
- 世界観：この語が、挨拶・買い物・介護・労働・葬儀のどの場面で、どう口にされるか。作例を会話で示す。
- AI：この世界でAIだけが持たないものは何か。それが物語をどう駆動するか。三案の使い回しではなく、この世界に固有の設計にすること。
- 主要キャラクター：碓氷千夏・暮林蒼・侘田すみれ・AI の四人を中核とし、各人を〈欲求／AIとの関わり／ルック／声／魅力〉まで設計する。追加は可。
- ストック層：20〜30名。全員に一行のフックを付ける。名前だけを並べることを禁ずる。
- 骨子：第1話〜初期アーク。会話を最低3往復、そのまま引用できる形で置く。
- 人数制約ギミック：隠し要素として扱う。四つの通路（呼称の揺れ／沈黙の長さ／発話の順番／「も」の位置）のみで現す。作中で「上限」「定員」「キャパ」「枠」を一度も出さない。
- 独自フック：締めを読者の話にすることを禁ずる。読者を主語にした文、読者を目的語にした文を、この節に一切置かない。作中の人物か、作品の構造そのものについて述べよ。

■ 出力
企画は1本のみ。
