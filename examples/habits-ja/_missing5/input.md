# タスク

「生活にAIが入り込んだ世界で、葛藤や悲喜こもごもを抱えて生きる人間たちの群像劇」を、長編シリーズとして成立する小説企画に膨らませる。エンタメ性（面白さ・続きが気になる）を備え、主人公は巻ごと・話ごとに交替してよい。キャラクターは各人に特徴的なルックを持ち、世界には多数のキャラがストックされている一方、1画面に同時に登場できるのは限られた人数である——この制約を、制約のまま隠すのではなく、世界法則・ルール・語りの形式として物語のギミックに自然に落とし込み、制約が制約に見えない仕掛けを設計すること。物語の中心はキャラ同士の会話劇の楽しさにあり、場面によっては会話劇を超えた躍動的なシーンも置く。ジャンル・トーンは問わないが、既存作品の焼き直しにならない独自のフックを持つこと。2〜3本の異なる企画を、以下の要素で構成して提示する：【仮タイトル】【ルック（世界観と画面の質感・色彩・構図のコンセプト、およびキャラごとの視覚的特徴の作り分け）】【テーマ（深み）】【シリーズ構造（何を単位に語られ、主人公がどう交替し、長期で何が進むか）】【主要キャラクター（3〜5名。各人の欲求・AIとの関わり・ルック・声の違い）】【骨子（第1話〜初期アークのあらすじ。会話劇の魅力が伝わる形で）】【人数制約ギミック（1画面の人数制約をどう物語の必然に変えたか）】【独自フック】。
