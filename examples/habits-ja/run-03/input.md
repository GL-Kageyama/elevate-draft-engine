# タスク

「生活にAIが入り込んだ世界で、葛藤や悲喜こもごもを抱えて生きる人間たちの群像劇」を、長編シリーズとして成立する小説企画に膨らませる。
【ジャンル】現代ファンタジーとして世界観を確立させること。日本の現代社会の写し鏡であることは維持する——読者が今日生きている制度・金・労働・家族・孤独がそのまま映っていること。そのうえで、現代の上に確としたファンタジーの層を立て、独自の法則・機構・存在を持つ世界として提示する。既存の現代ファンタジーの焼き直しにならないこと。
【AI】AIは、人間キャラの合間を埋める要素ではない。AIキャラクター、およびAIによる仕組みを、物語を駆動する骨組みとして設計すること。AIが物語の構造そのものに食い込んでいること。
【タイトル】タイトルから世界観が掴めること。フックがあり、かつ深みがあること。現代の事物の名ではなく、世界の法則・機構・存在が滲む語であること。
【登場人物】各人に特徴的なルックを持ち、ビジュアル化したときに明らかにそのキャラだと分かる自然な特徴があること。かつ、既存のキャラクターに類似がないこと。世界観の中には20〜30人の魅力的なキャラクターがストックされており、彼らは全員が順番を持っている。その一方で、一場面に同時に登場する人物は絞られる。
【隠し要素】「1画面に同時に登場できる人数」は隠し要素（hidden 要素）である。物語の世界観に全面的に映し出してはならない。世界法則としても、法制度としても、設定としても、これを説明・命名・法則化しない。誰もその数を数えず、話題にせず、守る規則も持たない。制約は、場面の切り取り・人物の配置・会話の力学としてのみ働く。読者は制約を「設定」として知るのではなく、気づけばそうなっている、という形でのみ受け取る。画面に出ていない人物も、別の場面では主役でありうるという気配を、説明なしに成立させること。
【両立】上記のジャンル・AI・タイトル・登場人物の要望は、この隠し要素と衝突させず、両立させること。
【物語】中心はキャラ同士の会話劇の楽しさにある。場面によっては会話劇を超えた躍動的なシーンも置く。エンタメ性（面白さ・続きが気になる）を備え、主人公は巻ごと・話ごとに交替してよい。
2〜3本の異なる企画を、以下の要素で構成して提示する：【タイトル】【ルック（世界観と画面の質感・色彩・構図のコンセプト、およびキャラごとの視覚的特徴の作り分け。ビジュアル化したときの識別性）】【テーマ（深み）】【世界観（現代ファンタジーとしての法則・機構・存在）】【AIの骨組み（AIキャラクターと、AIによる仕組み。物語をどう駆動するか）】【シリーズ構造（何を単位に語られ、主人公がどう交替し、長期で何が進むか）】【主要キャラクター（3〜5名。各人の欲求・AIとの関わり・ルック・声の違い）】【骨子（第1話〜初期アークのあらすじ。会話劇の魅力が伝わる形で）】【人数制約ギミック（隠し要素としての人数制約が、どのように場面と会話にだけ現れるか。世界法則として説明していないことを明記）】【独自フック】。
