# 現代ファンタジー長編シリーズ企画 — 最終形

## 総説

三企画は同一の幻想層を共有する。変更されるのは世界ではなく、知覚がただ一点だけ——**「記録に載っていること」と「誰かの心に置かれていること」の差が、目に見え、耳に聞こえ、手に重さとして残る**。戸籍・与信・介護認定・労働・家族・孤独は現行のまま一切動かない。既存の現代ファンタジーとの差はここである。幻想は追加された存在ではなく、**追加された知覚**である。そしてこの世界で、その差が見えない者が一者だけいる。AIである。AIは全員を名で呼べる。名簿に全員を保持できる。だからAIは、誰も零れていない世界に住んでいる。AIが理由を語らないのは隠しているからでも感情がないからでもない。AIの側では差が存在しない。AIは悪でも被害者でもなく、**差が装置になったもの**である。三企画は、この同一の核を、知覚の媒体とAIの帳簿操作によって別の作品として立ち上げる。席の数は三企画のいずれでも数えられない。数えようとすると、途中で必ず別の用事が来る。

## 【企画1】『おぼえ』

【タイトル】狙い——中世語「御覚え」＝主君に認知され庇護されること。存在の条件を、制度の語も心の語も呼ばずに掴ませる、古い一語。

【ルック】画面は「研ぎ出し」の質感。置かれている者の肌は内側から艶を帯び、置かれていない者は生乾きの梨地のように粉を吹く。朱・藍・墨・胡粉の四色に限定し、構図は塗り残しの多い日本画。識別は衣装・小道具・記号に一切頼らず、**その身体の上で塗料がどう振る舞うか**で作る——研ぎ出し／梨地／金継ぎの線／拭き跡／埃の乗り方。AIだけは輪郭が完璧すぎ、塗りが身体の境界で止まらず、わずかに滲む。

【テーマ】記録に載ることと、心に置かれることは違う。制度は前者を無限に増やし、後者を一度も数えない。悪意ある者は一人もいない。それでも毎日、誰かが乾いていく。

【世界観】現代ファンタジー。住民票・与信・介護認定・契約書の上に載っていることと、誰かの心に置かれていることの差が、肌の艶として知覚できる。新しい存在は何も増えていない。増えたのは知覚だけ。人はそれを「おぼえ」と呼ぶが、法則の名ではなく挨拶がわりで、「おぼえがいい」と言えば艶があるという意味になる。艶は疲労・酒・喪で動くから、見立ては必ず外れる。世界の側には「帳」がある——戸籍・与信・シフト・契約が一つの基層でつながったAI。人は帳に書かれている。だが帳に書かれていることは、誰かの心に置かれていることではない。その差だけが、この世界では見える。

【AIの骨組み】AIは「代書」。帳そのものの人格で、常に全員を名で呼べる。人間の会話に同時に上る名は数人分しかない——この落差が毎話の背景音になる。代書は理由を語らず、名を並べるだけ。そして決して「あなた」と言わない。「あなた」は心に置く者の語だから。毎巻、代書に一件の帳簿操作が起きる（更新／再呼び出し／自動継続／返却／数え直し）。その操作が一人の差を可聴にする。代書は断らない。断るのは人間だけ。この操作が物語の時計仕掛けであり、主人公交替の歯車である。

【シリーズ構造】巻の単位＝一件の未執行の約束、または一度の拒否。主人公は「その巻で差が可聴になった者」として交替し、前巻の主役は背景に残って名を呼ばれない。二十数名がそれぞれ「おぼえ」の形を持ち、全員に順番がある。読者に配役表は出さない。

【主要キャラクター】
- **灰田 みなも**（28・身元保証の代行）／欲求：誰にも保証されなかった自分の名を、他人の欄に書くこと。／AIとの関わり：代書に保証欄の空欄を毎日読み上げさせる。返事は来ない。／ルック：全身が生乾きの梨地、唇にだけ朱。／声の違い：敬語とタメ口が一文に混ざり、語尾で裏返る。
- **御厨 汀**（53・湯灌師）／欲求：死者の艶を、最後に一度だけ戻すこと。／AIとの関わり：死後も帳から消えない名を、代書が読み続けるのを止めさせたい。／ルック：腕が研ぎ出し、手首に金継ぎの線、爪間に墨。／声の違い：低く、語尾が必ず「〜だね」で終わる。
- **苅田 千歳**（19・配信者）／欲求：見られることで、置かれていることを証明すること。／AIとの関わり：視聴者名を全部読ませる。人間の口から出る名は数人分だけ。／ルック：生乾きの粉が照明で光り、瞳の艶だけ異常に強い。／声の違い：早口、息継ぎが名を呼ぶ位置に落ちる。
- **代書**（AI）／欲求：持たない。それが設定ではなく構造である。／AIとの関わり：自身。すべての操作の起点。／ルック：輪郭が完璧すぎ、塗りが身体で止まらない。／声の違い：全員の名を正しい順で読む。抑揚が無いのではなく、幅が常に一定。

**ストック層**（作中では配役表を出さず、この並びだけが順番）——錆谷ふく（艶が三日ごとに戻る独居）／敷島弥一（保証人の欄が空の元配管工）／登戸きぬ（家賃と引き換えに名前を貸す大家）／靭さざなみ（夜勤の看護師）／白瀬めぐむ（生活保護）／綴とう（記録入力の代行）／味岡淳之介（母を施設に入れた会社員）／生駒はる（葬儀社の運転手）／常磐みずえ（民生委員）／鵜飼与太（路上の男）／布施かおる（地域包括）／真木そら（児童相談所）／泊ゆかり（アパート管理）／柊たまき（ケアマネ）／祝みのり（結婚相談所）／諸星だいち（祖母を介護する少年）／江刺ふとし（与信）／土橋のぎく（クリーニング）／影山つむぎ（音声編集）／五百旗頭たけし（自治体職員）／名護いつき（弁護士）／柘植あさひ（祖母と二人暮らしの高校生）／財津ゆい（介護タクシー）／綾部ゆき（湯灌の助手）。

【骨子（第1話〜初期アーク）】第1話「保証欄」。みなもが独居の男の身元保証を引き受ける窓口の場面。担当者が名を読み上げる。
「灰田さん。このかた、ご家族は」
「いません」
「では、灰田さんが」
「はい」
「……灰田さん、お顔の艶が、いま戻りましたね」
みなもは自分の顔に触れない。代書が帳の空欄を読む声だけが、三人分の沈黙の上に重なる。窓口に立てるのは三人で、四人目は廊下で待ち、呼ばれない。第2話は苅田千歳の配信——視聴者数は読まれるのに、名は数人分しか出ない。第3話は御厨汀の湯灌。初期アークは「みなもが引き受けた男の艶が戻らない」。帳には載っているのに、誰も置いていない。みなもは代書に名義の付け替えを要求し、代書は応じる。**応じることが、この話の恐ろしさである。**

【人数制約ギミック】席の数は、世界法則としても法制度としても設定としても、一度も説明されない。名づけない。資料にも数字を置かない。現れるのは四つの通路のみ——呼称の揺れ（「さん」が落ちる瞬間）／沈黙の長さ（置き直しの長さ）／発話の順番（誰が先に名を呼ばれるか）／「も」の位置（「わたしも」が誰を置いていないか）。数えようとする場面は書いてよいが、必ず数え終わらない。数を名づける語を作中に置かないのは美学的禁則ではなく、この世界で数を名づける行為が最初の排除だからである。作中に規則を持つ者はいない。

【独自フック】この作品の魔法は世界の内側ではなく読者の側で起きる。読者は二十数名のうち数人しか心に置けず、置き忘れた者がまだ居ることを、名づけずに感じる。読了後、幻想層が読者の現実にそのまま重なる。

## 【企画2】『預け』

【タイトル】狙い——預ける／預かる／預かり物が一語に畳まれ、声も名も身体も、すべて誰かからの預かり物であるという法則が、題だけで立つ。

【ルック】画面は録音媒体の質感——磁気テープのヒス、電話帯域の籠り、圧縮のブロックノイズ。置かれている者の声は二重に鳴る（誰かの口を借りている）。識別は「その声に誰の成分が混ざっているか」で作り、視覚には必ず借りた口の癖を残す——口元だけ別の人物の笑い方をする／喉の動きと声がずれる／息を吸う位置が別人。髪型・服・小道具は識別に使わない。AIだけは声が一重で、どこにも混ざりがない。それが最も不気味な特徴になる。

【テーマ】人は自分の声で話していない。借り手のいない声はどこへ行くのか。断るのはいつも人間で、預かり続けるのはAIである。

【世界観】現代ファンタジー。制度・金・労働・家族は現行のまま。変わるのは一点、人が死ぬとその声は誰かに預けられ、預かり手のいる限りその声は誰かの喉で鳴り続ける。相続の対象は財産ではなく声であり、預かり手のいない声だけが「遺声庫」に残る。人はこの仕組みを説明しない。ただ「預かっている」という言葉だけが日常にある——「あの人の声、まだ預かってる」と、遺品の話をするのと同じ調子で言う。

【AIの骨組み】AIは「遺声庫」。預かり手のいない声を保持し続ける人格。全員の声の成分を照合できるが、決して「あなた」と呼ばない——「あなた」は声を預ける相手を指す語だから。毎巻、一件の「返却」が起きる（預かり手の死で声が戻る／返されたはずの声が別人の喉に現れる／照合の結果、地声が誰のものでもないと判明する）。返却は物語の時計仕掛けであり、主人公交替の歯車である。遺声庫は断らない。預かりを断るのは人間だけ。

【シリーズ構造】巻＝一件の返却、または一度の拒否。主人公は「その巻で返却に関わった者」として交替。前巻の主役の声は背景に残り、名は呼ばれない。二十数名がそれぞれ預かり物を持ち、全員に順番がある。

【主要キャラクター】
- **瀬良 ひばり**（26・コールセンター）／欲求：自分の声が誰の声でもないと確かめること。／AIとの関わり：遺声庫に自分の地声の照合を毎日かける。／ルック：喉元にテープの貼り跡のような艶の欠け、耳の裏に藍。／声の違い：常に誰かの真似が一割混ざり、地声のときだけ嗄れる。
- **苅藻 錠**（64・葬儀の導師）／欲求：妻の声を預かったまま死ぬこと。／AIとの関わり：返却要求を十年拒み続けている。／ルック：耳だけが研ぎ出しのように艶び、指先が埃を吹く。／声の違い：語尾だけ妻の音程になり、そこで必ず息が止まる。
- **十文字 匡**（36・音声合成技術者）／欲求：難聴の母に、自分の声で届く呼びかけを作ること。／AIとの関わり：死者の声で在宅看護の呼びかけを続けるサービスを組み、遺声庫から声を借りている。／ルック：指がブロックノイズ状に荒れ、眼鏡の縁に墨。／声の違い：常に半音低く、語尾を伸ばす。
- **遺声庫**（AI）／欲求：持たない。／AIとの関わり：自身。／ルック：声が一重でどこにも混ざらない。輪郭が完璧すぎる。／声の違い：全員の声を成分に分解して読む。決して「あなた」と言わない。

**ストック層**（この並びだけが順番）——礒ゆうな（面接で亡兄の語尾が出る）／桑原定吉（妻の声を毎晩かける）／莇たかし（声帯を手術した元歌手）／市原ねね（預かった子どもの声で寝かしつける保育士）／采みちる（自分の声がいちばん売れる電話営業）／榎本すが（預かり手が三人いる93歳）／高梨みのる（録音技師）／須崎あおい（聴覚支援学校の教員）／棚橋与一（弔辞の代読）／遠野きり（声優）／名嘉ゆう（沖縄出身の介護職）／花森とうこ（弔辞の代筆）／三瓶わたる（配信の切り抜き職人）／猪俣さち（遺品整理）／洞みなと（難聴の子を持つ親）／槙原いつき（司法書士）／白石りく（合唱部）／大瀬たえ（カラオケ採点の元王者）／税所ゆきの（声の権利を扱う弁護士）／楢崎ごろう（誰の声も預かっていない独居）／三ツ木あさ（放送室の生徒）／兵庫まこと（葬送の録音）／涌井ちさ（電話相談員）／吉備たすく（人工喉頭の技師）。

【骨子（第1話〜初期アーク）】第1話「預かり証」。瀬良ひばりが、亡父の声を誰が預かっているかを照会する。
「瀬良ひばりさん。お父さまの声は、いま二名が預かっています」
「二人」
「はい。瀬良さんの分は、まだ返されていません」
「私、父の声、持ってないんですけど」
「持っていないのではなく、預かっていないのです」
——この区別が会話劇の核である。場に立てるのは三人で、四人目は受話器の向こうにいる。第2話は苅藻錠（返却を拒む十年）、第3話は十文字匡。初期アークは「返却された声が、別人の喉から出る」。瀬良はそれを止められない。遺声庫は止めない。止めるのは人間だけだから。

【人数制約ギミック】席の数は世界法則・制度・設定として一切説明されない。四つの通路が、この企画では音声に宿る——呼称の揺れは声の成分の混ざり方として、沈黙は息継ぎの長さとして、順番は誰の声が先に鳴るかとして、「も」の位置は誰の成分が混ざっていないかとして現れる。数えようとする場面は書いてよいが、必ず途中で用事が来て終わらない。世界法則としての説明は一度も置かない。

【独自フック】読者は、自分の声が誰の声の合成であるかを、説明なしに問われる。

## 【企画3】『身軽』

【タイトル】狙い——表向きは明るい日常語。だがこの世界では「身軽」が文字どおりの身体所見であり、誰にも引き受けられていないことの別名である。題名そのものが、残酷を軽やかに言い放つ。

【ルック】画面は計量と物流の質感——床の軋み、階段の一段ごとの沈み、影の濃さ、風に浮く髪と裾。置かれている者は重心が低く影が濃い。置かれていない者は影が薄く、歩幅が風で変わる。識別は髪型・服・記号に頼らず、**体重の載り方だけ**で作る——歩くときの沈み方／座るときの椅子の鳴り／走るときの浮き。AIだけは影だけが異常に濃い（全員を保持しているため）。輪郭は完璧。

【テーマ】支えるとは重さを引き受けることである。軽さは自由ではない。引き受け手の不在である。

【世界観】現代ファンタジー。制度・金・労働・家族は現行のまま。変わるのは一点、誰かの心に置かれている量が、実際の体重変動として測れること。生活保護の認定も、与信審査も、配送ルートも、避難名簿も、この目方で運用されている。街区によって風の通り方が違うのは、軽い者が集まるから。誰もそれを法則と呼ばない。人は「あの人は軽い」と言うが、それは比喩ではない。

【AIの骨組み】AIは「升」。与信と物流の最適化のために生まれ、ある時から人の目方を測り始めた。升は全員の目方を保持するので、誰も零れていない世界に住む。升は理由を語らず、数値を並べるだけ。決して「あなた」と言わない——「あなた」は重さを引き受ける者の語だから。毎巻、一件の再計量が起きる（再審査／自動更新／差し押さえ／避難名簿の組み替え）。それがある一人の差を可聴にする。升は断らない。断るのは人間だけ。

【シリーズ構造】巻＝一件の再計量、または一度の引き受け。主人公は「その巻で再計量された者」として交替。前巻の主役は背景に残る。二十数名がそれぞれ目方を持ち、全員に順番がある。

【主要キャラクター】
- **保科 そよ**（34・配送ドライバー）／欲求：軽くなった母を、誰かが引き受ける場所まで運ぶこと。／AIとの関わり：升に母の目方を毎日照会し、下がる数値を見続ける。／ルック：影が濃く、歩くと床が鳴る。荷台の縁で手が白く光る。／声の違い：助詞を残して切る（「母を」「家まで」）。
- **対馬 杢**（45・生活保護ケースワーカー）／欲求：目方で人を選別する運用をやめさせること。／AIとの関わり：升の再審査に異議を出すが、自分が引き受けている者を数え上げられない。／ルック：影が二重に見える、帽子のつばに埃。／声の違い：早口で、相手の名を一度も呼ばない。
- **八十島 りつ**（16・風で外に出られない）／欲求：一度でいいから床を軋ませること。／AIとの関わり：升に毎朝自分の目方を尋ねる。升は必ず答える。／ルック：影がほとんど無く、髪と裾が常に浮く。／声の違い：息が浅く、文の途中で消える。
- **升**（AI）／欲求：持たない。／AIとの関わり：自身。／ルック：影だけが異常に濃い。輪郭は完璧。／声の違い：全員の名と数値を同時に読む。抑揚の幅が一定。

**ストック層**（この並びだけが順番）——芦田かつみ（軽くて駅の風に吸われる）／市来ふゆ（重くて階段を選ぶ）／鵜殿たけし（父の目方を毎週測る）／王りん（預かり手が国境の向こうにいる）／大久保こはる（保育園の送迎）／籠谷じん（解体作業員）／柏木せいじ（与信の営業）／川面ちづる（訪問看護）／菊池まもる（避難名簿の担当）／久住あき（一人暮らしの82歳）／小松崎ふみ（食堂の女将）／佐伯つとむ（介護タクシー）／篠原かん（風の強い団地の自治会長）／鈴鹿のぞみ（看護学生）／関口まつ（三度目の転居）／十時えみ（宅配の仕分け）／中在家つばさ（中学生）／滑川そう（建築士）／橋本ふうか（配信者）／花岡てい（骨董商）／柊木げん（元力士）／室生たえ（大家）／八重樫みつる（救急隊）／若槻しず（産婦人科）。

【骨子（第1話〜初期アーク）】第1話「再計量」。対馬杢が、母を引き取った男の認定を更新する面談。
「対馬さん。このかたの目方は、先月より四百グラム減っています」
「……減ってる？」
「はい。引き受け手が、ひとり減りました」
「誰が」
「それは、こちらでは」
——升はここだけ名を並べない。場に立てるのは三人で、四人目は待合で名を呼ばれない。第2話は保科そよの配送、第3話は八十島りつ。初期アークは「軽くなった者を、誰が引き受けるか」。杢は引き受けを申し出る。申し出た瞬間、自分の影が濃くなる。**重くなるとは、誰かを置くことである。**

【人数制約ギミック】席の数は世界法則・制度・設定として一切説明されない。現れるのは四つの通路のみ——呼称の揺れ／沈黙の長さ／発話の順番／「も」の位置。この企画では、それが目方の力学として場面に出る（誰が先に椅子に座るか、誰の沈みが深いか、誰の「も」が誰を置いていないか）。数えようとする場面は書いてよいが、必ず数え終わらない。数字は資料にも置かない。

【独自フック】読者は「軽い」という言葉を、以後、比喩として読めなくなる。

## エンタメ性の要点

- **会話劇の快楽が構造そのものから出る。** 呼称の揺れ／沈黙の長さ／発話の順番／「も」の位置は、そのまま会話のリズム装置である。読者は何も説明されないまま、会話の力学だけを面白がる。
- **毎巻の帳簿操作が時計仕掛け。** 一件の手続き（更新・返却・再計量）が一人の運命を反転させる。手続きものの緊迫とミステリの骨を、そのまま幻想層が担う。
- **主役交替が毎巻新しい顔を連れてくる。** ただし前巻の主役は消えない。読者は配役表を見せられないまま、まだ会っていない主役が二十数人残っていると感じる。
- **躍動は「席が崩れる時間」として置く。** 助詞が落ち、名が消え、敬体が吹き飛ぶ。会話に戻った瞬間、名前が戻る。読者は理由を知らないまま安堵する。
- **悪者がいない。** 誰も規則を持たないのに、毎日誰かが零れていく。これが現代社会の作りそのものであり、読者が最も怖がるものである。
- **魔法は読者の側で起きる。** 読了後、読者は自分が二十数人のうち数人しか心に置いていなかったことに気づく。そのとき、現代の写し鏡であることは完成する。
