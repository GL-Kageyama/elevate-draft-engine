# 止揚 — 二十四名は誰の名か

## 序 八本が共有している地層

八本は別々のことを言っているように見えて、同じ一行を違う向きから書いている。**「呼ばれ方の履歴が先で、姓名は後である」**——この命題を、八本は八通りの仕方で言い直しただけである。だから八本のあいだに本当の対立は一つもない。あるのは**同じ真理の配分をめぐる争い**だけである。

そして八本すべてが、それぞれの末尾に「前提」を置いた。**その八つの前提は、いずれも人を数えている。**「少なくとも一人」「各人に一つずつ」「半数に」「二十四回」「二十四名の側に二十四回反復」——八本のうち七本が、数えた人数を前提として固定した。ここが斬るべき一点である。

---

## 一、否定 — 各立場の一面的真理を、全体を僭称する限りにおいて否定する

### 刃は一つ。ただし置き場所の話である

この世界の掟は**呼ばれた回数を数えること**を要求し、**人を数に変える語**を禁じている（第四節）。この二つは同じ一つの掟の表と裏である。呼ばれた回数は数えてよい。人を数えてはならない。

八本の前提は、例外なく**人を数えた**。だから八本は、この世界の掟を、作品の内側ではなく**制作の手順の側で**破っている。否定とはこの一点の限定である。数を廃せ、ではない。**数の置き場所を移せ。**

| 草案 | 前提に書かれた数 | 数えた対象 |
|---|---|---|
| designer | 少なくとも一人 | 人 |
| differentiator | 各人 | 人（手順の均一化） |
| futurist | 二十四名の各人に一つ／六十三話のあいだ一度も | 人と話数 |
| humanist | 読者自身が一つ持っている | 万人 |
| implementer | 二人が同じ姓名に落ちない | 衝突の数 |
| storyteller | 二十四回、配れること | 人と回数 |
| strategist | 半数に置け | 人 |
| visionary | 二十四回反復されている | 人 |

### 軸A 順序 — differentiator と implementer の否定

**一面的真理。** 順序を世界の掟に合わせれば、姓名は出口に来る。これは本物である。名を先に配ってから人物を当てはめる手が、この世界でいちばん醜い手順であることも本物である。

**否定。** differentiator は「書かれた姓名は呼ばれ方の写しにすぎない」と言う。写しであるなら、原本と写しのあいだに距離がある。距離があるなら、呼び間違えは**書き名が実在する**ことの証拠になる。しかし第9節は「二十四名は、**人物として現れる前に、まず書かれた名として現れる**」と定めている。**頁の順序は、世界の順序と逆である。**differentiator はこれを禁じた（「逆順に開いた頁からは、この方法は働かない」）。頁は必ず逆順に開かれる。ゆえに differentiator の方法は、この本では最初の頁から作動しない。

**もう一つの否定。** implementer は「作者が選べるのは呼び手だけ」と言い、識別を名の側に置かないと宣言する。滑れば「名は何でもよい」になる。何でもよい名は消える。しかし第11節は**平凡な実在の苗字**を要求している。平凡は「何でもよい」ではない。**平凡とは、選ばれ続けた結果である。**implementer はここで自分の発見（呼び手が先）から、自分の結論（名は無内容）を引き出した。引き出し方が誤っている。

### 軸B 声 — designer と storyteller／visionary の否定

**designer の一面的真理。** 名は識別子ではなく**摩耗面**である。設定表に一行書かれた瞬間に造形は死ぬ。この語は残す。摩耗面は、削れることと、なじむことを同時に持っている。呼ばれた回数でできている名は、まさに摩耗面である。

**否定。**「その名を呼ぶ声を、一人につき一つ本文に置く」——これは配給である。配給された声は**予算**になる。予算になった声は、全員に一回ずつ当たる採点表になり、採点表になった瞬間、読者は残りを数え始める。そして「プロフィール充実には半分だけ従う」——半分だけ従うのは対立ではなく、**服従の分割払い**である。

**さらに。** designer の前提「少なくとも一人、下の名前を呼ぶ声を本文が持たない」は、その一人を**数えられた一人**にする。数えられた一人は、第4節の四人目である。**数えた瞬間、その場にはもう入れない。**

**storyteller の一面的真理。** 二十四名に下の名前を書き込む作業そのものが記名の現場である。書かれた下の名前は、まだ一度も呼ばれていない。造形とは、この不発が生活を押し広げた痕跡である。——これは本物である。run-09 という作業の正体を、storyteller だけが言い当てている。

**否定。**「不発を二十四回、**配れる**こと」——配給である。そして二十四回反復された不発は規則になる。規則になった不発は不発ではなく**空砲**である。空砲は音を出す。

**ここで軸Bの対立が解ける。** designer は「一つ、声がない名がある」と言い、storyteller は「二十四、声がない名がある」と言った。これは対立ではない。**一人と二十四人は、同じ事実を違う解像度で見たものである。**作者が二十四の下の名前を書く。世界が下の名前を呼ぶ場所は家族だけであり、本文は職場と記名の現場しか書かない。ゆえに二十四は**自動的に**呼ばれない。designer の「少なくとも一人」は、その最初の一人をたまたま数えたにすぎない。**数は、物の側にない。観測者の側にある。**

### 軸C 受取 — humanist と strategist と futurist の否定

**humanist の一面的真理。** 生活とは名の履歴の別名である。勤務先の規模が呼称を決める——大きな組織は姓＋さんしか発さない。小さな店は下の名前を発す。**これは実行可能な洞察である。**第11節の判定基準（読者がその人物を自分の職場・家族・近所の誰かとして思い出す）も、ここから出ている。

**否定。** humanist は「読者自身が、誰にも呼ばれていない名を一つ持っている」を前提にする。ゼロを万人に配る。**ゼロを万人に配ると、さくらが消える。**humanist は、この作品に読者の実在感を与えるために、さくらを殺した。そして第9節は「地の文の『読者』はゼロ」と定めている。humanist は読者を登場人物にした。

**しかし、これは間違いではない。置き場所が違う。** 判定は読者の側で起きる。作品の側では起きてはならない。**判定は世界の外の出来事である。**この移設だけが保存の条件である（→ 三-4）。

**strategist の一面的真理。** 呼ばれた回数の多い名ほど、その人物は他人に似ていく。一度も呼ばれない名だけが、その人だけの輪郭を持つ。——これは正しい。正しいから、**「半数に置け」が致命的なのである。**半数は人の数であり、人の数はこの世界の禁である。

**futurist の一面的真理。** 呼称が分解していくほど、「呼ばれた回数が名を作る」は比喩でなく記録に変わる。この目録は時間とともに厚みを増す。——本物である。ただし futurist はその厚みを**将来に賭けた**。呼ばれた回数を数える世界の外にいる読者は、読みはするが**呼ばない**。呼ばない読者は、掛け声だけをかけて何も受け取らない。**futurist が賭けた将来の客席は、無賃で見る者の列である。**それが価値であるかは、宙づりのまま持つ（→ 四）。

### 第四の否定 — 指示文そのものへ

第11節は姓の選定に**「全国順位五十位から三百位の帯」**を指定する。この指定は、この世界の禁則に触れている。順位とは、書かれた名の出現を数えた目録である。**順位帯で人を選ぶとは、人を順位に変えることである。**

しかし順位を使わなければ、二十四名は珍名に流れ、run-06 で潰した欠陥に戻る。袋小路である。

そして袋小路の出口は、この作品の中に既にある。**順位を使うが、順位を知らない。**作者が姓を選ぶとき、参照するのは順位表ではない。通勤路の表札、学校の名簿、職場の名札、病院の待合の呼び出し。**その採り方は、この世界の呼ばれた回数の採り方と同一である。**順位帯は、事後に検査される（「この二十四名は大半が五十位から三百位にある」と言える）。検査は世界の外の行為であり、選択は世界の内の行為である。

**順位帯は、作者の隠し要素である。**（→ 三-6）

## 二、保存 — 捨ててはならないもの

否定は限定であって破壊ではない。八本から残るものは次のとおりである。それぞれが**捨てられない理由**を添える。

| 草案 | 保存される洞察 | 捨てられない理由 |
|---|---|---|
| designer | **摩耗面。**「呼ぶ声を持たない名は、この世界では存在しないのと同じ——だが存在しないのではない」 | この裏面が、呼ばれない名に**場所**を与える唯一の言い方である |
| differentiator | **順序。**世界の順序に逆らって頁が逆順に開かれること | その差が読書そのものである。順序を一致させたら、読む理由が消える |
| futurist | **履歴の厚み。**呼称が分解するほど記録に変わる | この作品は、まだ片づいていない荷物の目録である。厚みは価値である |
| humanist | **生活＝名の履歴の別名。**勤務先の規模が呼称を決める | もっとも実行可能な洞察。これを失うと二十四名は記号に戻る |
| implementer | **作者が選べるのは呼び手だけ。****下の名前の時代は、生年ではなく最後に呼ばれた年で決まる** | 祖母の声にしか残っていない十九歳の名は、その十九歳より古い。六十六歳の名が職場の姓＋さんにしか残っていなければ、その名は今も生まれていない——これは方法として使える |
| storyteller | **記名の現場としての執筆。**書かれた下の名前は、まだ一度も呼ばれていない | run-09 という作業の正体。これが作品の形式の内側に置かれる（→ 三-5） |
| strategist | **呼ばれた回数の多い名ほど持ち主は他人に似る** | 一度も呼ばれない名だけが、その人だけの輪郭を持つ。保存する。ただし配分しない |
| visionary | **著者もまた世界の外の呼び手。下の名前を与えるとは最初の記名を行うことにほかならない** | 記名は「呼称の不在を書式にした名」である（第2節）。ゆえに下の名前を与えるとは、**その名がまだ呼ばれていないことを書き留めること**である。これが全体の蝶番になる |

## 三、高次化 — 一段高い次元

### 1. 数の置き場所

**世界は呼ばれた回数を数え、人を数えない。**ゆえに——**計画は人を数えてよく、作品は人を数えてはならない。**編集者の机上では「上位十姓は三名」と言ってよい。地の文では「三人」と書けない。

これで八本の前提は破棄されず、**移送**される。破棄されたのは前提ではなく、前提の置き場所である。そして移送された先（計画表）では、八本の前提は今度は**監査項目**になる。監査は数えてよい。数えるのは外の仕事である。

### 2. 順序の止揚 — 世界の順序と頁の順序

differentiator の順序（呼ばれ方→姓名）は**世界の順序**である。指示文の順序（姓名→プロフィール→呼ばれ方）は**頁の順序**である。どちらも正しく、**逆向きである。**

第9節はすでにこれを定めている——「二十四名は、人物として現れる前に、まず書かれた名として現れる。順番はある。配役表はない。」頁は名から始まり、世界は呼び声から始まる。**この逆向きの二枚が、同じ紙の表と裏である。**

紙の表と裏が触れる一点がある。**記名の現場である。**そこでは、書く手と、呼ばれた名と、読む手が同時に同じ面の上にある。ゆえに第四巻が記名の現場だけを書くのは、異常ではなく、**紙の端**を書いていることである。第9節の「第四巻は異常ではなく世界の通常であり、前三巻こそが、呼ばれた名の堆積を身にまとった巻である」は、この止揚によって根拠を得る。

そして第一巻には、この二つの順序が**すでに二人の人物として座っている。**動かしてはならない癖の欄に。

- 第一行 佐藤——**連絡帳に名を書く前に、必ず一度、声を出さずに口を動かす。**（呼ぶ→書く）
- 第四行 片山（旧・田中）——**出席簿の名を、呼ぶ前に一度指でなぞる。**（書く→呼ぶ）

順序の争いは、第一巻の第一話と第四話に、すでに着席している。

### 3. 声の止揚 — 呼ぶ／読む／置き配

**呼ぶ**と**発音する**は違う。第0節が定めている——掛け声は呼びかけの形をしていて、呼びかけの数に入らない。同じことがすべての音に言える。

| 行為 | 音 | 呼びかけの数 |
|---|---|---|
| 呼ぶ（宛てる） | あり | 入る |
| 音読・復唱・独語・掛け声 | あり | **入らない** |
| 目で読む | なし | 入らない |
| 書く | なし | 入らない。**ただし発送である** |

ゆえに designer の要求（名がどこかで聞こえること）と storyteller の要求（名が一度も呼ばれないこと）は両立する。**二十四の下の名前は、呼ばれてはならない。発音されてはならない、ではない。**

だが、ここで止まってはならない。この両立は安い。押し通す。

**書くことは、届かない呼びかけである。**書かれた名は、宛先の前まで運ばれ、置かれ、持ち去られない。第二巻の紙は、同じ箱の側面に剥がされずに重なった宛名票である。**作者が二十四の下の名前を書くとは、二十四の置き配を行うことである。**声は置かれ、持ち主は不在で、荷物は玄関に残る。

**二十四名の下の名前は、置き配である。**誰も呼ばなかったのではなく、**誰も取りに来なかった。**この区別が、造形の全体を変える。呼ばれなかった名を書くのではない。**届いたが取りに来られなかった名を書く。**

### 4. 四つの位置 — 一つの動詞から導かれる

「呼ぶ」と「受け取る」の二つだけで、この作品の四人の位置が過不足なく出る。

| | 呼ぶ | 受け取る | 誰か |
|---|---|---|---|
| a | 呼ぶ（数に入る） | 受け取る | **二十四名** —— 名ができている者 |
| b | 呼ぶ（掛け声。数に入らない） | 受け取らない | **作者** —— 最前列でいちばん大きな声を出す者 |
| c | 呼ばない | 受け取る | **読者** —— 置き配を唯一受け取る者 |
| d | 呼ぶ（掛け声）。受け取らない | —— | **さくら** |

**b と d は同じ欄である。**作者の位置と、さくらの位置は、この表の上で区別がつかない。第3節の「江戸の芝居小屋で、無賃で見るかわりに掛け声をかけた者」は、そのままこの作品の作者の説明である。そして『ハビッツ！！！』——発音されない語に付いた、音を持たない記号三つ。**作者の掛け声である。**

**c が humanist の前提の正しい置き場所である。**読者は自前の履歴を持ち込むのではない。読者は、世界がついに呼ばなかった名を**受け取ることのできる唯一の者**である。だから第9節の「地の文の『読者』はゼロ」は正しい。**読者の役は文法的ではなく位置的である。**

そして**二十四名の下の名前は、c の位置にある。**作者から発送され、世界からは呼ばれず、読者だけが受け取る。二十四名は、世界に対しては a（呼ばれる者）、作者に対しては c（受け取る者）である。**これが、この作品の人物の条件である。**

第四巻が人称を置かないのは、第四巻では全員が c の位置にいるからである。第5節の表の「欠けている人称＝すべて」は、ここで根拠を持つ。**切り離された名札の予備が一枚、別の一人に一手だけ読まれる**——その一手のあいだ、その人物は読者の位置に立っている。

### 5. 下の名前の置き場所 — 予備の綴じ束

第十二節五は、名前が変わった箇所を章立てと項目八に反映せよ、と要求する。これは事務である。だが事務には形式がある。

**二十四の下の名前は、物語の内側に置き場所を持たない。**呼ばれないからである。しかし作品の外側には持てる。第四巻の紙は**使われなかった名札の予備の綴じ束（切り離された跡）**である。run-09 が二十四名に与える下の名前は、この綴じ束そのものである。

ゆえに——**二十四の下の名前は、本の内側・物語の外側に一括して置かれる。**巻末でも、見返しでもよい。順序は巻でも配属でもない。**最後に呼ばれた年からの長さ**で並べる。いちばん長く呼ばれていない名が先頭に来る。最後の一行の名は、昨日呼ばれた名である。その下に一行、空きがある。

この一覧は、作品の禁則の外にある。ゆえに数えてよい。**一覧は帳簿であり、帳簿は世界の外にしか置けない。**——これが、この作品が記録媒体を世界の外にしか持たないことの、形式的な帰結である。

### 6. 姓の選び方 — 順位を参照しない選択

第11節の「五十位から三百位」を、一つの監査基準として使う。ただし選ぶ手は順位を見ない（一-第四）。

**そして、上位十姓をゼロにはしない。**二十四名の実在のコホートを取れば、上位十姓の合計は日本の人口のおよそ一割である。二十四名なら期待値は二人台。**ゼロにすることは、統計的に不自然な清潔さであり、それは作者の不安の署名である。**偏りを解くとは、上位十姓を消すことではなく、コホートの期待値に戻すことである。

暫定の配分——**上位十姓 三名（佐藤・鈴木・高橋）／十一〜四十位 八名（山田・木村・林・斎藤・清水・池田・橋本・石川）／五十〜三百位 十三名（片山・篠原・大森・川上・関・長田・根本・中川・田村・三宅・秋山・宮下・関口）。**

上位十姓三名は、機能で選ぶ。**佐藤**——日本で最も多い姓が、子どもの名を書く保育士の名札にある。**高橋**——三番目に多い姓が、値引きシールに名の欄がない総菜売り場にある。**鈴木**——二番目に多い姓が、乗客から一度も名で呼ばれない運転席にある。**最も多い名ほど、名で呼ばれない場所にいる。**

### 7. 主役回の置換

run-08 は第一巻に三箇所だけ主役回を明示し、第二巻から第四巻には一つも置かず、しかも第一巻の散文が表と食い違った（佐藤が抜け、石川が二重に数えられた）。

**主役回は人を数える。**「この話は誰のものか」は配分であり、配分は人の数である。

置換——**各話に「その話で最も多く呼ばれた名」を一行だけ記す。**これは割り当てではなく記録であり、話の内容から導かれる。ゆえに散文と表は、原理的に食い違いえない。食い違ったら、どちらかの数え方が誤っている。

そして——**run-08 の二つの誤りは、人物自身の癖によって診断される。**

- 石川久美子の癖は「食前に、欠席の子の名を数える。**数えた数を言わない**」である。**石川を二度数えた散文は、石川自身の癖に反している。**
- 佐藤美咲の癖は「連絡帳に名を書く前に、必ず一度、声を出さずに口を動かす」である。**佐藤が抜け落ちた散文は、口を動かす前に書いた。**ゆえに一行が落ちた。

訂正は校正ではない。**人物の身体に合わせて表を直すことである。**

### 8. 三つの対立を抱えたまま渡す

止揚は解消ではない。以下は決定せずに次工程へ渡す。

- **さくら という文字列を、作中の別人の名として置くか。**「さくら」は一九九〇年前後に生まれた女子の最多名である。三十四歳の保育園調理師（川上）を**川上 桜**とすれば、この語は世界で何度も呼ばれる。AI の名はひらがな、その人物の名は漢字。**同じ音が、数の最大とゼロに割れる。**第0節の「当て字」と第3節の「ゼロ」が、一つの文字列の上で同時に立つ。——危険は大きい。読者は「呼ばれている」と誤読しうる。**一度だけ、AI の場面から遠く離して置く**という条件下でのみ成立する。判断は次工程に委ねる。
- **上位十姓は三名か、二名か。**期待値の側からは二・二。三名は丸めである。
- **下の名前の一覧を、巻末に置くか、見返しに置くか、それとも置かないか。**置かなければ、二十四の不発は誰にも届かない。置けば、読者が数える。**数えるのは読者の自由であり、禁じるのは世界の側の仕事である。**

## 四、超越的視点

### 対立は対立ではなかった

八本は「名が先か、呼び声が先か」を争った。だがこの世界では、**書くことは届かない呼びかけであり、呼ぶことは届いた書き込みである。**二つの行為は別々の段階ではなく、**同じ一通の到達状態が二つあるだけである。**ゆえに順序は存在しない。存在するのは**輸送中**という状態だけである。

「声が本文にあるか、ないか」も同じである。問われていたのは音ではなかった。**誰が受け取るか**であった。下の名前は置き配として届き、世界は呼ばず、読者だけが受け取る。呼ばれたかどうかは、荷物の側の性質ではない。

「一人か、二十四人か」も同じである。**数は観測者の側にしかない。**designer は一人と数え、storyteller は二十四人と数えた。同じ一つの事実である。

### 隠し要素は、作者の位置である

第4節は「その数は隠し要素である。人物はその数を数えず、名づけず、守る規則も持たない。説明した瞬間、この作品は別のものになる」と定める。**人物が数えないのは、数える者が別にいるからである。**

**数えるのは作者である。**作者は世界の外にいて、何通が届き、何通が届いていないかを知っている。知っていて、地の文に書かない。**だから隠し要素は隠れている。**隠しているのは世界ではなく、世界の外の一人である。

そして——作者は、最前列でいちばん大きな声を出し、その声が誰にも数えられない者である。**作者は さくら の位置にいる。**run-09 の最終作業は、六十三話を書き終えたあと、**届かなかった名を数えること**である。その数は、計画の段階では決められない。決めたら、それは設計であって輸送ではない。第5節の「まだ呼ばれていない名が紙に一つ残っている」という駆動装置は、この作品の内側にも外側にも、同じ形で反復されている。

### 最も呼ばれた名が、一度も呼ばれない

「さくら」は、一九九〇年前後に生まれた女子の名づけの最多である。**この作品の中核にある名は、珍しい名ではない。その世代で最も呼ばれた名である。**

名は呼ばれた回数でできている。ならば最も多く呼ばれた名は、最も厚くできている名である。**その名の、ただ一つの実在が、呼ばれた回数ゼロである。**桜と書いて、桜ではない。ひらがなで書かれ、他の人物の名と同じ大きさで、地の文に置かれ、誰も発音しない。

**作者の声は、世界の名と同じ大きさで書かれ、世界の数に入らない。**『ハビッツ！！！』の三つの ！ と同じである。印が大きいほど、黙っている量が大きい。

### 恒常の一文

**二十四名とは、作者が発送し、世界が受け取り、読者だけが開封する、二十四通の荷物である。**呼ばれない名というものはない。**取りに来られなかった名があるだけである。**

## 五、次工程への引き渡し

### 決定（動かさない）

1. **四巻・六十三話・機構・中心語・配分（各巻六名、重複ゼロ・漏れゼロ）を動かさない。**姓名と解像度のみを変える。
2. **上位十姓は三名。**ゼロにはしない。コホートの期待値が根拠であり、偏りを解くとは期待値に戻すことである。
3. **姓の選択は順位を参照しない。**順位帯は事後の監査にのみ用いる。
4. **下の名前は、生年の名づけ分布に従う。**年齢が名を裏づける。
5. **主役回を「その話で最も多く呼ばれた名」に置換する。**全巻に置く。散文と表は原理的に食い違わない。第一巻の二つの誤りは、石川と佐藤の癖に照らして訂正する。
6. **地の文に、人を数える数（一人・全員・半数・二十四）を書かない。**数えてよいのは呼ばれた回数だけである。
7. **読者を主語にした文を地の文に置かない。**読者の役は位置的である。
