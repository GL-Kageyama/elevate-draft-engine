- **二十三番、石川久美子の呼ばれ方を一箇所だけ訂正した。**「姑は、最後のひと月、彼女を『ゆみちゃん』と呼んだ」→「**くみちゃん**」。**久美子から「ゆみ」は導けない。** 同じ run の三番、高橋**由美**（ゆみ）からの混入である。二十四名の呼ばれ方を全数照合した結果、**ずれはこの一箇所だけで、他はすべてその人の名から正しく派生していた。**

以降の工程は、この判断を前提とする。
