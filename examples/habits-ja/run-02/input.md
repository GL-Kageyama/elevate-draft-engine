# タスク

「生活にAIが入り込んだ世界で、葛藤や悲喜こもごもを抱えて生きる人間たちの群像劇」を、長編シリーズとして成立する小説企画に膨らませる。日本の現代社会の写し鏡として書くこと——読者が今日生きている社会の制度・金・労働・家族・孤独が、そのまま映っていること。エンタメ性（面白さ・続きが気になる）を備え、主人公は巻ごと・話ごとに交替してよい。キャラクターは各人に特徴的なルックを持ち、世界観の中には20〜30人の魅力的なキャラクターがストックされている。その一方で、一場面に同時に登場する人物は絞られる。【最重要】「1画面に同時に登場できる人数」は隠し要素（hidden 要素）である。物語の世界観に全面的に映し出してはならない。世界法則としても、法制度としても、設定としても、これを説明・命名・法則化しない。誰もその数を数えず、話題にせず、守る規則も持たない。制約は、場面の切り取り・人物の配置・会話の力学としてのみ働く。読者は制約を「設定」として知るのではなく、気づけばそうなっている、という形でのみ受け取る。そのうえで、20〜30人のストックが活きること——画面に出ていない人物も、別の場面では主役でありうるという気配——を、説明なしに成立させること。物語の中心はキャラ同士の会話劇の楽しさにあり、場面によっては会話劇を超えた躍動的なシーンも置く。ジャンル・トーンは問わないが、既存作品の焼き直しにならない独自のフックを持つこと。2〜3本の異なる企画を、以下の要素で構成して提示する：【仮タイトル】【ルック（世界観と画面の質感・色彩・構図のコンセプト、およびキャラごとの視覚的特徴の作り分け）】【テーマ（深み）】【シリーズ構造（何を単位に語られ、主人公がどう交替し、長期で何が進むか）】【主要キャラクター（3〜5名。各人の欲求・AIとの関わり・ルック・声の違い）】【骨子（第1話〜初期アークのあらすじ。会話劇の魅力が伝わる形で）】【人数制約ギミック（隠し要素としての人数制約が、どのように場面と会話にだけ現れるか。世界法則として説明していないことを明記）】【独自フック】。
