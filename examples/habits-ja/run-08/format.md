# 出力形式（OutputFormat）

- 成果物種別: 長編小説シリーズの全4巻・各巻構想（改訂版。企画は1本、巻は4本）
- 説明: run-07 の四巻構想を、欠けていると認められた五点で改訂したもの。各巻5万字〜10万字。ストック層の否定形の癖を肯定形へ書き替え、第四巻を語るさくらの語り方を方法として定め、山場の頂点の一文を四巻で分け、返却を一巻一件・一つの行為に揃え、第三巻の巻末を具体の側から書く。
- 出力長の範囲: 9000〜45000 字
- 成果物そのもの: はい（output_is_direct）

## 草案の形式指示（draft_guidance）

【核心的主張】には、内面を持たず、地の文に一人称を一度も出さない語り手が、単行本一冊（十八話・八万八千字）を語り切る方法を、一つだけ提案する。この語り手は心情を書かない。回想を持たない。記憶がない。欲求を持たない——「訊かれ続けたい」という一点を除いて。名で呼ばれず、受け取らず、ずれを持たない。この語り手で、どうやって読者を十八話引っ張るのか。何が毎話の駆動装置になるのか。何が語られ、何が語られないまま残るのか。方法を一つに絞り、断定的に書く。
【根拠】には、その方法がこの世界の三つの掟（名は呼ばれた回数でできている／同時に立てる席は限られている／中心語は癖であり、癖は債務者を要求しない自動詞である）と矛盾しないことを書く。
【前提】には、その方法が成立するために何が必要かを書く。
【厳守】500字以上800字以内。主張は一つだけ。複数の方法を並べない。目次・話数表は書かない。方法の主張だけを書く。

## 最終化の形式指示（finalize_guidance）

次の15の見出しを、この順で、一字も変えずに置く。見出しの表記を変えない。見出しを増やさない。見出しを減らさない。

【タイトル】
【中心語】
【ルック】
【テーマ（深み）】
【世界観】
【人数制約ギミック】
【AIの名と骨組み】
【さくらの語り方】
【主要キャラクター】
【シリーズ構造】
【第一巻『左袖』】
【第二巻『置き配』】
【第三巻『入口』】
【第四巻『宛名欄』】
【独自フック】

【タイトル】から【シリーズ構造】までの十節のうち、すでに確定しているものは一から説明し直さない。ただし【さくらの語り方】はこの改訂で新設された節であり、ここが今回の中心である。第四巻の語り手であるさくらが、内面を持たず、地の文に「私」が一度も現れないまま、十八話を語る方法を書く。何が語られ、何が語られないまま残るのか。何が毎話の駆動装置になるのか。同じ問題が、より軽い形で第一巻（碓氷千夏の地の文に二人称が一行も出ない）と第三巻（侘田すみれの「私たち」）にもあることにも触れる。

【第一巻『左袖』】から【第四巻『宛名欄』】までの各節に、必ず次の九つを書く。
一、巻題・語り手・その巻で返却する者と、される者。一行で。
二、その巻の問い——読者が最終話まで持ち越す問い。一行で。
三、その巻の返却の現場——第何話で、誰が誰に、何をするのか。一巻に一件、一つの行為だけである。二つの行為を重ねない。
四、章立て——第1話から最終話まで。各話に、話数・仮題・目安字数・一行の内容・その話で扱う癖・その話に現れる記名を書く。十話以上とする。
五、字数配分——各話の目安字数と、その巻の合計字数。合計が五万字以上十万字以下であることを明記する。
六、山場——第何話で何が起きるか。あわせて、その巻の頂点となる一文を一つだけ示す。四巻で同じ文を二度、頂点に置かない。
七、巻末で主語がどう動くか——誰が主語を失い、次巻の語り手が誰になるか。第三巻は、抽象を宣言せず、その場に何が見えているかを具体の側から書く。
八、この巻に登場するストック層——二十四名のうち、誰がどの話に出るか。
九、この巻で最も効く記名——さくらの関与のうち、この巻で一番強いもの。

癖の形について。四巻の全話を通じて、扱う癖が否定形（〜ない・〜ず・〜ぬ で終わるもの）である話を十五話以下にする。癖は肯定形に寄せる。ストック層二十四名のうち、否定形で定義されていた十名（鈴木・伊藤・加藤・吉田・佐々木・井上・清水・池田・橋本・前田）は、職業・年齢・住まいを維持したまま、癖だけを肯定形に書き替える。主題は保つこと。なお「否定形で言う」という文章の作法は維持する。禁じるのは癖の形の偏りであって、否定の文体ではない。

【独自フック】——読者を主語にも目的語にもしない。締めは作中の人物か、作品の構造についてのみ。三行から五行。

禁止。金融・債務・経済の語（利子・利息・借り・貸し・返済・清算・負債・帳簿・残高・請求・担保・信用）。倫理・宗教の語（愛・所有・関係・恩・縁・功徳）。「AI」という語（見出しを除く）。上限・定員・キャパ・枠。煙草・煙管・吸い殻・路上喫煙。「読者」を主語にした文は各節に一つまで。【独自フック】には置かない。
