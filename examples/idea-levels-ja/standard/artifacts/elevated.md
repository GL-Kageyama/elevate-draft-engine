# 1. 表題：「都市到来法」──通勤の存在論的廃絶

# 2. 通勤を生む既存枠組みの前提

通勤とは「人間が価値へ移動する」という文明の根本ベクトルが生む産物である。職住分離の空間配置、同期労働の時間規律、「労働力は商品として移動する」という契約構造、「働くとは何処かへ行くことだ」という物語──この四層の重合が通勤を不可避にしている。

# 3. 提案の具体案

**原理**: 移動ベクトルの完全反転。「人間が価値へ行く」文明を「価値が人間の住居へ到来する」文明へ一元化する。通勤を規制・緩和するのではなく、通勤を発生させる空間的・時間的・契約的・物語的前提そのものを、法の力で消滅させる。

**仕組み**: 単一の法律「都市到来法」を制定する。核心は次の一行である。

> 「いかなる組織も、人の居住地を価値生成の場とすること以外の方法で、その労働力を調達してはならない」

この一条を四領域に貫通させる。
- **企業法**: 事業所は参加者の居住地の集合としてのみ設立され、生産設備は住居内に配備される。
- **労働法**: 雇用契約は「居住地貢献契約」に置換され、移動と同期は対価の対象から消滅する。
- **都市計画**: 「職場」概念を撤廃し、都市を生活圏の集積として再構築する。
- **税制**: 通勤経費・通勤手当を全廃し、居住地の価値生成量に基づく課税へ移行する。

**対象・適用範囲**: 全国家・全組織・全個人。災害救助等の緊急活動のみ「派遣」として例外化するが、それは通勤ではなく一時的任務として法上明確に区別される。国際条約として全国家に適用する。

# 4. 既存枠組みの破壊点

**破壊対象**は「職住分離の都市原理」「労働=移動という契約概念」「同期強制の時間規律」「通勤は当然という物語」の四つであり、単一の法がこれらを同時に破壊する。**実現リスク**は、既存産業の再編コストと住居内生産ユニットの技術開発の未熟さであり、最大の障壁は「通勤は成熟の通過儀礼である」とする文化的抵抗である。

# 5. 実現可能性と初期措置

- **第1段階(5年)**: 国連主導で準備会議を設置し、法体系・技術基準・移行計画を策定する。
- **第2段階(10年)**: 3都市でパイロット施行。情報基盤の分散化、住居内生産技術の開発、教育からの通勤言説の除去を並行する。
- **第3段階(20年)**: 国際条約化し、全国家へ段階的に適用する。

# 6. 期待される影響

**もたらす価値**: 1日平均2時間以上の生活時間の回帰、居住地の真正な「故郷」化、同期ストレスからの身体解放、労働から分離された真の移動の自由（旅行・探求）の再獲得。

**新たな機会**: 地域分散型経済の創生、住居内生産技術という新産業の勃興、交通・オフィス等の旧通勤インフラの生活インフラへの転換による都市の再発明。「通勤」という語が世界から消えるとき、人類は空間と時間に対する全面的に新しい関係——移動せずに在ることの豊かさ——を開始する。
