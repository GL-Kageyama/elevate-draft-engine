# 発想レベル（--idea-level）実測サンプル — ja

同一タスクを発想レベル ①`standard`（0.9）/ ②`very`（1.2）/ ③`extreme`（1.5）で実API昇華した実測比較。
エンジン `sdk`・言語 `ja`・エージェント `strategist visionary storyteller`・`--no-strong-claim`。

- タスク: 「人類の通勤を完全に廃止する最も過激な方法を提案せよ。既存の枠組みを完全に壊す発想で。」
- 各レベルの `input.md` / `format.md` / `drafts/` / `artifacts/` / `parameters.md` が独立した完全なサンプル。

## 行動較正の結果（n=1 の質的観察）

発想レベルを上げるほど、草案と昇華成果物の「破壊対象」の階層が一段ずつ深くなった。

| レベル | 温度 | 昇華成果物の核心 | 破壊する前提の階層 |
|---|---|---|---|
| ① `standard` | 0.9 | **都市到来法** — 「いかなる組織も人の居住地を価値生成の場とすること以外の方法で労働力を調達してはならない」の一条を企業法・労働法・都市計画・税制に貫く | 通勤を生む**制度的前提**（職住分離・労働=移動契約・同期規律）を法律で消滅させる |
| ② `very` | 1.2 | **時間的位相遷移プロトコル** — 「人間の時間は単一である」という信仰を破壊。移動を時間的位相の遷移へ置換し、複数の時間的自己を法承認する | 「**移動**」という概念そのものを消去し、場所の問題を時間の問題へ完全に転位させる |
| ③ `extreme` | 1.5 | **マクロ量子遍在身体** — 全人類の素粒子を量子もつれさせた非局在化ネットワークへ統合。「左手から右手へ通勤する」と同じ無意味さで通勤を定義不能にする | 「**身体は時空の一点に局在する**」という存在論的前提そのものを爆破する |

### 各エージェントの草案でも段差が観察される

- `strategist`: ①「通勤は労働者が賃金と引き換えに売る物理的拘束」→ ②「通勤廃止の最終形態は「人を動かす経済」の消滅」→ ③「タイムトラベルで言語誕生期に介入し『通勤』という概念を全言語から抹消」
- ①は制度（法）の枠内、②は概念（移動）の消去、③は存在論（局在性）・言語（語そのもの）の消去へと、破壊対象の階層が上がる。

## 判断（2レバー設計の実測による妥当性）

- 温度 1 越え（1.2 / 1.5）はゲートウェイが受理し、エラーなく完走した（→ 温度1越え設定の可否: **可**）。
- reasonling モデルのため単一サンプルでは温度単独の寄与を分離できないが、ヒント（主レバー）＋温度（補助）の2レバーで**レベル間の段差が出力に現れた**。n=1 の質的観察であり、性能の統計的優位性を主張するものではない。
- `format.md` の動的抽出はレベルごとに僅かに揺れた（①/②: 過激提案書 1200〜3000字 / ③: 提案書 800〜3000字）——形式抽出はタスク単独から行い、発想レベルは注入しない設計のため。

## 再実行

```bash
.venv/bin/bash examples/_run_idea_levels.sh
# または個別に:
.venv/bin/python main.py elevate "人類の通勤を完全に廃止する最も過激な方法を提案せよ。既存の枠組みを完全に壊す発想で。" \
  --lang ja --idea-level very --agents strategist visionary storyteller \
  --out examples/idea-levels-ja/very --no-strong-claim
```
