# Strategist 草案

## 核心的主張

Reiは家計簿アプリ市場に参入しない。「金融プライバシー」という新カテゴリを創設し、ミニマリスト富裕層に月額2,000円を請求する。共感もぬくもりも売らない——無料・広告・データ販売を一切拒否し、サーバーにデータを一バイトも置かない冷徹な箱だけを売り、10万人×2,000円＝月商2億円・年24億円、粗利率90%超を目指す。既存大手は全てデータ収益化に依存しており、このカテゴリでReiに追随すれば自社モデルが崩壊する——勝者は「データを持たない者」ただ一人であり、大手は買収でしか参入できない。

## 根拠

- MoneyForwardは登録2,000万超に対し有料転換は数%・月額約500円で頭打ち——データ型モデルは「支出が少ない＝広告価値が低い」ミニマリスト層では構造的に収益化不能だ。
- FIRE層は高所得・低消費の富裕層であり、「選んで使わない」美学ゆえに広告で稼ぐ無料アプリを忌避し、月2,000円を合理的に支払う。
- データ非保存は広告前提の全競合にとって模倣＝自滅であるため、模倣不能な独占的堀となり、かつ大手からの買収という明確なExitを保証する。

## 前提

業界常識の「ミニマリスト＝低単価・低支払意欲」は誤読であり、ミニマリズムは高所得だからこそ選べる富裕層の美学であって、支払意欲は平均ユーザーより桁違いに高い。
