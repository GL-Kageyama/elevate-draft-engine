# 「Rei」事業計画書 — ミニマリストのための、家計の余白

---

## 0. 一頁要約（Thesis）

家計簿アプリ市場は「もっと見せる」方向に走ってきた。マネーフォワードMEは2,500以上の連携と全資産ダッシュボード、Zaimは43分類とOCR、広告と金融商品のクロスセル。**日本の家計簿カテゴリは「注意経済」に毒されている。**

ミニマリストが欲しいのは「もっと情報」ではない。**もっと不安がないこと**だ。彼らは記録を買うのでなく、**余白（コントロール感）**を買う。

Rei はその逆を設計する。**「開くのは1日1回」「カテゴリは5つ」「データは売らない」**。成功のKPIを「滞在時間」ではなく「削減した注意量」に再定義した、プレミアム・ミニマル家計簿。YNABが「メソッド」を売って米国で成功したように、Reiは「**令和のゼロメソッド**」という物語と美学を売る。

市場は狭い（国内PFM市場約120億円、成長率CAGR約5%）。だからこそ、VCに毒されず、**小さなチーム・高い利益率・直接課金**で、ヨットのように小さいまま儲ける。規模ではなく「1ユーザーあたりの穏やかさ」で勝つ、いわば**ミニマリズムを実践する事業**である。

## 1. 市場構造：なぜ「継続率9割挫折」市場なのか

### 1-1 市場規模と矛盾

- 日本の個人財務管理（PFM）市場は2025年に約8,050万米ドル（約120億円）、CAGR約4.94%で2035年に1億2,420万米ドルへ。
- 伊藤忠は国内家計簿アプリ市場がFY2027に130億円（FY2021比約4倍）に達すると予測。物価上昇・キャッシュレス化・新NISAブームが追い風。
- ところが**ユーザーの9割以上が最終的に挫折する**（台湾・中国・日本の調査で共通）とされる。継続率こそがこの市場の本当のボトルネック。

### 1-2 挫折の原因＝市場の地雷（Reiはここを拾う）

調査から浮かぶ挫折要因は、機能不足ではなく**過剰と摩擦**である：

| 挫折要因 | 内容 | Reiの設計対応 |
|---|---|---|
| 記録の面倒さ | 手入力が「本に書くのと同じ」 | ゼロ入力志向（自動同期＋AI自動分類） |
| 設定のハードル | 口座連携の認証・権限付与に抵抗→アンインストール | 銀行連携は任意の有料オプションに格下げ |
| 分類が多すぎる | 11大項目＋43小項目で「どれを選べばいいかわからない」 | **カテゴリは5つ固定** |
| 完璧主義スパイラル | 「1日忘れた→もうダメだ→アプリを消す」 | 不完全を許容する設計（後から補記OK） |
| フィードバック欠如 | 記録しても「変化が見えない」 | 毎日見せず、**週1回の余白レポート** |
| 自己否定 | 「また無駄遣いした」と罪悪感 | **「〇〇が足りない」ではなく「余白があと¥3,000」**と未来志向で表示 |
| AI分類ミスの修正負担 | 直す作業がストレス | 修正は1タップ、「AI主体＋手動微調整」のハイブリッド |

> **洞察①**：この市場で差がつくのは「追加機能」ではなく「引き算」。挫折原因の大半は既存プレイヤーの過剰さが生んでいる。Reiは**構造的に続くアプリ**として入る。

## 2. 競合地図と空白地帯

| プレイヤー | ポジション | 料金 | 弱点（Reiの取るべき空間） |
|---|---|---|---|
| マネーフォワード ME | 総合資産管理No.1、2,500連携、広告・金融クロスセル | 約¥500/月 | 情報過多・開くたびに「仕事」。個人データを広告に使う姿勢への不信 |
| Zaim | 老舗、OCR、バイリンガル、Good Design Award | ¥480/月 | 分類43個、やはり機能過剰。定着率83%は自社広告値 |
| みにまむ/マイ支出等 | 個人製ミニマル無料アプリ | 無料 | 美学・ブランド・メソッド・サポート不在。機能が「ただ少ないだけ」 |
| Kakeibo Tracker | 4分類メソッド、完全オフライン | 無料 | 海外製、UI/UX粗い、日本語ローカライズ不足 |
| （参考）YNAB | メソッド販売型。4つのルール＋教育＋コミュニティ | $109/年 | 日本未対応。「spendfulness」で92%がストレス減少、平均初年度$6,000貯蓄 |

**空白地帯 = 「プレミアム・ミニマル」の象限。**
「機能が少ないだけ」の無料アプリでもなく、「何でも見せる」総合アプリでもない。**美学と哲学とメソッドを持った、有料で、それでいて広告がない**アプリが日本には存在しない。ここに1社分のポジションが空いている。

> **洞察②**：YNABの成功は「ツール」ではなく「**メソッド＋物語＋親切**」を売ったこと。Reiは日本版YNABではなく、「日本ならではの引き算」を売る。YNABは「お金に役割を与える（足す）」。Reiは「**余白を残す（引く）**」。

## 3. プロダクト定義

### 3-1 ブランド／ネーミング：Rei = 「令」×「零」

「Rei」に2つの漢字を重ねる。これがブランドの芯になる。

- **令（レイ）** — 秩序・おきて。令和という時代への接続。家計に「令（ルール）」を置く。
- **零（レイ）** — ゼロ。無駄な支出・サブスク・不安をゼロに。「ゼロメソッド」の象徴。

**タグライン案：「令和の家計に、秩序（令）と余白（零）を。」**

### 3-2 哲学：「記録から、余白へ」

主役はグラフではなく**「残量」**だ。
- 一般的なアプリ：`今月いくら使ったか`（過去・罪悪感）
- Rei：`今月、あといくら自由に使えるか`（未来・コントロール感）

### 3-3 「3つの約束」（差別化の公約）

1. **開くのは1日1回まで。** 通知は週1回の余白レポートのみ。それ以外は一切鳴らさない。
2. **カテゴリは5つだけ。** 食 / 住 / 暮らし / 楽しみ / 学び。サブカテゴリなし。1回の記録に5秒以上かけない。
3. **あなたのデータはあなたのもの。** 広告なし・データ販売なし。いつでも無料でCSV書き出し可能（**「簡単に辞められる」こと自体が信頼になる**）。

### 3-4 機能セット

**MVP（3ヶ月）**
- 60秒オンボーディング（名前→月収→固定費3つ→今月の予算1つ→完了）
- 大きな数字ボタン＋ウィジェット＋音声入力。AI自動分類（修正1タップ）
- 1画面：**今月の余白**（残予算）＋固定費の1行表示
- 週1の余白レポート（AIによる短文。「今週の食費は¥12,000。予算まであと¥3,000。外食を1回減らすと貯金が¥2,000増えます」）

**Premium（6〜12ヶ月）**
- **夫婦シェア**（2人で1つの余白。マネーフォワードが2025年に「シェアボード」を出したことで需要は実証済み）
- **銀行・カード自動連携（オプション、E2E暗号化）** — ゼロ入力の本命
- **サブスク検出** — 「あなたが払っている見えないお金」を自動発見。最もミニマリストの心に刺さる節約機能（YNABエコシステムでも需要確認）
- 複数月の余白の積み立て（生活費/貯金/自由の3バケット）
- 年間まとめ（1年を1ページに要約）

## 4. ターゲットとペルソナ

**プライマリ（25〜40歳・都市圏）**
- ミニマリスト自認、または「断捨離・シンプルライフ」への憧れを持つ層
- 新NISA・FIRE・副業に関心があり、お金と真剣に向き合いたいが**マネーフォワードの画面に圧倒されて辞めた経験者**（既存アプリのチャーン層がそのまま顧客プール）
- サブスク疲れ。デジタルデトックス志向。プライバシー意識が高い

**セカンダリ：共家計簿カップル**（「ふたりで1つの余白」— マネーフォワードのシェアボード投入で需要は実証済み）
**ターシャリー：日本在住の外国人／海外ミニマリスト市場**（英語対応でグローバル展開可能）

> **洞察③**：競合のチャーン層がReiの潜在顧客。**「マネーフォワードを3回インストールして3回辞めた人」**に「もう家計簿は大丈夫です」と届けるのが最短の需要形成。

## 5. 差別化とビジネスモデル

### 5-1 「買って逃げる」モデル（反・注意経済）

この市場は全員が「ユーザーの注意とデータを売って」儲ける。Reiは逆で、**「あなたの注意とデータを売らないこと」そのものを課金対象**にする。

- 広告なし → 収益は直接課金のみ
- データ販売なし → プライバシーがビジネスモデル
- **「あなたが払うのは、あなた自身を商品にしないための代金」**。これはミニマリストの倫理観と完全に一致し、ブランドの物語そのものになる。

### 5-2 価格設計（サブスク嫌いとの整合）

ミニマリストはサブスク嫌い。そこで**3段階**で逃げ道を作る：

| プラン | 価格 | 役割 |
|---|---|---|
| 無料 | ¥0 | 1予算・3ヶ月履歴・5カテゴリ・広告なし。**価値のデモ** |
| Premium年間 | ¥2,900/年（≈¥242/月） | 主力。夫婦シェア・銀行連携・サブスク検出 |
| **生涯版（Lifetime）** | ¥8,900 一度きり | 「サブスクを持ちたくない」層への決定的回答。**先行キャッシュを生む** |

価格はマネーフォワード（¥500/月）の半額以下だが、「安さ」ではなく「**1年で無駄なサブスク1本分**」という言い方でフレームする。価格競争ではなく、メソッドと信頼で正当化する（YNAB方式）。

### 5-3 ユニットエコノミクス

前提：プレミアム転換率4%（日本の有料アプリ相場2〜4%）、解約率5%/月（年40%）、Lifetimeはプレミアムの約3倍単価。

| 指標 | 値 |
|---|---|
| Premium LTV | ¥2,900 ÷ 0.40 ≈ **¥7,250** |
| 平均ユーザー年間ARPU | 4% × ¥2,900 ≈ ¥116/年（＋Lifetime一時金） |
| CAC | ASO＋コンテンツ中心で**¥300〜800/インストール** |
| 回収期間 | 1年以内に成立 |

**ただし正直なところ**：このARPUでは大規模MAUを追うビジネスにはならない。だからこそ費用を極限まで落とし、**10万MAU前後で黒字化**する設計にする。事業自体がミニマリズム。

## 6. GTM／成長戦略

1. **美学が最大のマーケティング**：Apple Design Award・「今日のアプリ」選出を目標に設計品質を磨く。日本の家計簿でADA級の美学を持ったものは皆無。
2. **メソッドの教育（YNAB方式）**：note/Zennで「Reiの家計哲学」連載。「令和のゼロメソッド」をコンテンツ化。ミニマリストYouTuber・新NISA系インフルエンサーへのシーディング。
3. **#Reiの余白**ハッシュタグと、週1のメールレター（1行だけ）。ミニマリスト向けに「コミュニティ疲れ」を避けた最小コミュニティ。
4. **夫婦口コミ**：共家計簿は自然な招待動線（パートナーを誘う＝DAU×2）。
5. **ASO**：「シンプル 家計簿」「サブスク 見直し」等の検索語で上位を取る。

## 10. KPIと成功の定義（再定義）

ミニマリストアプリは成功すると**滞在時間が減る**。だから従来指標では誤って評価される。成功を次のように再定義する：

**主KPI（従来と逆）**
- 1日あたりアプリ滞在時間（**下げる**＝目標90秒以下）
- D30 / D90 継続率（上げる）
- プレミアム解約率（下げる。40%/年以下）

**副KPI（質）**
- 自己申告「お金のストレス」スコアの低下（YNABでは92%がストレス減）
- 週1余白レポートの開封率
- 紹介率（夫婦招待のコンバージョン）

> **洞察④**：この市場でVC的な「MAU・滞在時間」を追えば追うほど、製品はミニマルでなくなり、チャーン率は元に戻る。**KPIの再定義こそが事業の防衛線。**

## 11. 深い洞察（総括）

1. **家計簿カテゴリは注意経済に毒されている**。Reiは非注意経済で勝つ最初の日本製アプリになる。
2. **ミニマリストは記録を買わない。「余白」を買う**。主役を過去の棒グラフから未来の残量に移す。
3. **人はツールではなくメソッドと物語を買う**（YNABの実証）。Reiは「令×零」という物語を売る。
4. **成功KPIを「削減した注意量」に再定義する**。これは投資家には理解されにくいので、調達せず自分たちの尺度で経営する。
5. **事業自体がミニマリズムを体現する**：小さなチーム、成長より利益率、広告より直接課金、データ販売より信頼。**ボートではなくヨット。**

Reiの価値提案を一言で言えば——**「もう、家計簿を考えなくていいですよ」**。これを日本で最初に、美学を持って、儲かる形で届けるのがこの事業計画である。
