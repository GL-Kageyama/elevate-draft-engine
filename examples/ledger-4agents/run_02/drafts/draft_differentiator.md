# 発散草案：Rei（零）

**核心的主張**

Reiは家計簿アプリではなく「金断食」の儀式装置で、UIは一日一回の二択「超えた/超えてない」と週一度の一行メモのみ——分類もチャートも銀行連携も予測も、すべて「症状を育てる餌」として実装しない。金銭データは一切保持しない（盗むに値するDBが存在しない）——価格は一回9,800円の卒業制のみでサブスクは持たず、ユーザーは90日で「卒業」し、アプリは自己消去する。Rei=零。ゼロ機能・ゼロ継続課金・ゼロ残存——唯一のKPIは「最終オープンからの経過日数」が伸び続けること、つまり自己の陳腐化を売る。

**根拠**

1. 「知識→管理→安心」という全アプリの前提は虚構で、現実には数字を見るたび不安が再生成される——明治以来100年、形を変えず生き残ったkakeiboの本質は「手書きの遅さ」という自己抑制の儀式であり、情報を増やすのではなく減らすことだった。
2. 銀行API自動同期を「ミニマル」と称するのは詐称で、あれは入力を省いただけで、見る・比べる・反省するという認知負荷の本丸は残る——真のミニマリズムは自動取得ではなく「データを取らないこと」だ。
3. サブスク家計簿は「自立=解約」で死ぬから、金銭的自立を謳う宣言と収益構造が構造矛盾する——一回払いの卒業制だけが矛盾を解き、固定費ゼロ・サポートゼロ・CACほぼゼロの単位経済学になり、「卒業で半額返金」の価格設計が回遊を金銭的ペナルティに変えてインセンティブを反転させる。

**前提**

ユーザーの病は情報不足ではなく「金への不安」であり、不安は可視化ではなく遮断でのみ消える——よって市場は支出失調の不安富裕層であり、「貧困層の節約支援」という慈善劇場は構造的に成立しない。
