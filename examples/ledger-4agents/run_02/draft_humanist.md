# Rei 事業計画 ― 人間中心デザインの観点からのテーゼ

## 核心的主張（3文）

Rei は家計簿ではなく、お金の記録を通して「あなたの人生がどこに向かっているか」を静かに語る告白装置である。通知・アラート・達成バッジを一切持たず日常から姿を消し、年に一度だけ姿を現す——その一年で本当に大事にしたものを「人生の手紙」として返すために。成功指標はエンゲージメントではなく「見られた」と感じた回数であり、このアプリはお金を通じて自分自身と向き合うための、最後に残る一本の道具である。

## 根拠（3点）

- 人は「減らせ」と脅されるのではなく「あなたはこれを大切にしていた」と認められたときにだけ変わり、恥で駆動する通知は三日で記憶から消えて、認める言葉だけが数年残る。
- 家計簿のデータは同じでも、そこに意味が宿るかどうかで心は動き、数字を並べるアプリは「監視」を売る一方、物語を返すアプリだけが泣ける——「あなたは月に一万二千円を、友達と飲むコーヒーに使った。それは無駄ではなく、友情の値段だ」と書けるかどうかが分かれ目だ。
- ミニマリストが払うのは機能ではなく解放感であり、アプリが空(ゼロ)に近いほど人生は満ちて見えるから、価格は定額制ではなく生涯一度の「生涯購読」で、十年後もあなたを知っているアプリに一度だけ金を払わせる。

## 前提

人は自分の支出を恥の記録ではなく、人生の選択の記録として読み直したいと心のどこかで願っている。
