# 草案：「おかえり」——彼女の現在を、明かりとして残す装置

## 1. 中心にいる人

佐百合（さゆり）、82歳。アルツハイマー型認知症。かつて家庭科の教師で、生徒の名前を三百人分、覚えていた。今は、孫の誕生日を思い出せない。だが毎朝、決まった時間に漬物を仕込む。できあがった漬物を見て、少し驚く。「あら、私、漬けたのね」。長女の美穂（みほ）はもう、直さない。ただうなずく。

この装置は、佐百合のために設計しない。美穂のためでもない。その先にいる、まだ高校生の孫・蓮（れん）のために設計する。美穂は、母が消えていく姿を直視できない。だから装置は「蓮がおばあちゃんを思い出せるように」という名目で、家に置かれる。誰も口に出さないが、本当の目的は一つだけ——**美穂が「母を失うこと」を、少しずつ味わい始めるための器**だ。それがこの装置の、正直な出発点である。

## 2. 感情の真実——彼女の「思い出」は、もう彼女の中にない

ここで、この企画の最大の嘘を指摘したい。

子孫が本当に失いたくないのは、佐百合の「思い出」ではない。彼女が何をしてきたか、どんな教師だったか——そういう物語は、とっくに家族の記憶の中に、複数のヴァージョンで保存されている。彼らが失うのは、彼女の過去ではない。**彼女の現在**だ。

- 台所で鼻歌を歌う声
- 蓮の頭に置かれる、しみのある手
- 意味がわからないテレビに、それでも話しかける声
- 隣の部屋で眠る、呼吸の音
- 「おかえり」と言われる、その声の質感

これらは過去の物語では回収できない。誕生日や正月の写真には、もう写っていない。**失われるのは、火曜日の午後四時である。** 誰も撮らなかった、ただそこにあった日常。この装置は、その「失われる日常」を対象にする。特別な日にではなく、ただの日に、灯る。

## 3. 装置の形——ランプであること

装置は、ランプの形をしている。佐百合の枕元で、夫を亡くした十二年を見てきた、あの古いランプの隣に置かれる。あるいは、そのランプそのものとして生まれ変わる。

名を、**「おかえり」** という。遺産装置に「おかえり」とは何だ、と思われるかもしれない。しかし、この装置が最後に子孫へ伝えるのは、物語ではなく、**帰る場所の感覚**だからだ。彼女がいた部屋には、彼女がいたという明かりが、まだある。生きている間、このランプは彼女自身にも「おかえり」と言う——デイルームから戻った佐百合を、家が迎える。二つの方向の「おかえり」が、一つの灯りの中で交差する。

## 4. 五つの設計判断

**(1) 記録は「今」だけ。過去は掘らない。**
家族が「思い出を聞いておこう」と過去を尋ねることを、この装置は促さない。答えられない自分に気づいて苦しむ佐百合の顔を、装置は知っているからだ。拾うのは、彼女が今まさに生きている音——鼻歌、湯の沸く音、テレビへの相槌、沈黙。

**(2) 演出しない。受動的に、ずっと。**
録音のための「撮影会」はない。カメラを向けられると、人は記録用の自分を演じる。佐百合はもう、演じることができない。だから装置は、ただそこにあり、ただ聞いている。介護で疲れ切った美穂に「思い出を記録する作業」を課すことは、絶対にない。装置の仕事は、家族の仕事を増やさないこと。

**(3) 双方向——生きている間に、返す。**
装置は一方通行のアーカイブではない。子孫は、今、生きている佐百合に言葉を残せる。蓮が「おばあちゃん、高校、受かったよ」と読む。佐百合は聞こえたかどうかわからない顔で、それでも少し笑うかもしれない。ランプは、そのやりとりを両方の向きで保存する。
佐百合が亡くなった後——蓮は、ランプの下で自分の声を聞く。彼女に届いたかどうかもわからないまま遺された自分の言葉が、彼女の部屋に、彼女の明かりの中で、彼自身に返ってくる。**遺産は、母の声ではない。家族自身の愛が、時間をかけて返ってくるのだ。**

**(4) 装置は、彼女と同じように忘れる。**
これが最も異端の設計。装置の容量は、あえて有限に設計される。一度も聞き返されなかった記録は、一年ごとに少しずつ質を失い、やがて消える。何度も聞き返された記録だけが、守られ、残る。
つまり——**何が残るかを決めるのは、愛である。** 家族が何度も聞き返したもの、それだけが子孫に届く。佐百合は、忘れることによって私たちに教えていたことがある。記憶とは、全部を抱えることではなく、大事なものを選ぶことだ。装置は彼女の忘れ方を模倣することで、その教えを子孫に継ぐ。完璧なアーカイブではなく、**愛によって削られた不完全な遺産**だけが、本物として残る。

**(5) 決して、彼女の代わりに喋らない。**
装置は、佐百合の声を模倣して、彼女の代わりに返事をすることを、断固として拒否する。「亡くなった母と話せる」というデジタル幽霊を作らない。それは彼女ではない。悲しみに付け込んだ腹話術の人形だ。装置にできるのは、彼女の本当の声と沈黙を、彼女の部屋に、彼女の明かりとして灯し続けることだけ。それで、十分に泣ける。

## 5. 記憶テスト——何年か後、何が残るか

蓮が三十歳になったとき、このランプのスイッチを入れる。聞こえるのは——
- 彼女の鼻歌。何の歌か、誰も答えを知らない。
- 「あら、私、漬けたのね」という声。
- 美穂が母に掛けた、何気ない言葉。
- 蓮自身が十七歳で遺した、届いたかわからない言葉。

物語は、ひとつとして完結していない。答えのない問いだけが、そこに灯っている。それは苦しい。しかしそれが本当のことだ。蓮は、おばあちゃんを「あの頃の佐百合」としてではなく、**最後まで彼女だった人**として思い出す。完璧な思い出ではなく、本当の欠損を抱えた、しかし確かに愛された人生として。

## 6. 操作の検査

この設計から、私は三つの「感動の仕掛け」を故意に外した。

1. **亡くなった母と話すチャットボット**——感動的だが、それは母ではなく、悲しみの鏡像。
2. **「思い出を語る家族の時間」を設計すること**——感動的だが、それは家族に課す労働であり、演出である。
3. **美しい物語に編集された祖母**——完結した物語は、彼女の死を早く消費させる。

この装置は、感動を仕掛けない。代わりに、**真実を置いておく**。抑制と余白だけが、本物の涙を許す。

## 発散——もう一歩尖らせるなら

- **「忘却の共有」**——ランプは家族にも、彼女と同じ速度で忘れさせる。家族自身の些末な記録も並行して減衰する。悲しみとは、愛する人が消えた後、自分の中の些末も一緒に消えていくことだ、と装置は教える。遺産とは共有された忘却のあとに残るもの、と定義し直す。
- **「答えのない星座」**——彼女が答えられなかった問い（あの鼻歌は何だったのか、あのとき誰を思っていたのか）は永遠に答えないまま、むしろ年々、明るくなる。開かれたまま愛されるものがある、という相続。
- **「遺言を書かせない」**——装置はあえて「最後のメッセージ」の録画を拒否する。彼女は別れを言う人ではなく、そこにいる人だった。挨拶の不在そのものが、彼女の在り方を証言する。

---

## 最強の主張

この装置は、認知症の母の「思い出」を保存しない。彼女の**現在**を、彼女の**部屋の明かり**として残す。子孫が遺されるのは母の記憶ではなく——**彼女と同じように忘れることを学び、それでも残ったものを愛する、家族自身の姿**である。母の記憶を残す装置は、母を完璧な物語に閉じ込める。だが「おかえり」は、母を不完全なまま、愛された人生として、灯し続ける。
