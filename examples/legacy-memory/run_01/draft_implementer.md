認知症の母の記憶を子孫に残す。この設計を始める前に、私は罠の名前を挙げておく。**「AIで母を甦らせる」**。これは作れてしまう。だからこそ、まず発散し、型破りまで行き、それから斧を振るう。私は実装者だから、最終的に残るのは「最初の1年で実際に動くもの」だけだ。

# 第一章 発散 — どこまで行けるかを試す

まず、可能な限り自由に発想する。極端なものも含めて8つの方向性を挙げ、それぞれに一振りずつ判定を下す。

**① AI蘇生チャットボット**
LLMで母の人格を模倣し、孫が何年でも話し続ける。技術的には今日成立する。だからこそ**禁忌**だ。「似ている」は「本物」を追い出す。孫は母ではなく、解像度の高い幻覚と暮らすことになる。悲嘆の完結が永遠に遅れる。作ってはいけない。**ただし**、その欲望の根は本物だ——「もう一度話したい」。この根だけを別の経路で汲む。

**② 記憶考古学**
母は「陳述記憶」（いつ・どこで・だれが）から失われる。だが「感覚記憶」「手続き記憶」「長期意味記憶」は驚くほど残る。昭和の歌、故郷の方言、料理をする手、アメ玉の包み方。これらを手がかりに、沈んだ記憶を**発掘**する。これは罠ではなく、捕獲戦略の核になる。

**③ 逆転メモリ・ダイアリー**
母は日記を書けない。だから家族が毎日「今日の母」を一筆書く。母視点に見える観察記録が、日々積み重なる。実装は最小、価値は最大。**これはMVPそのものだ。**

**④ 食卓アーカイブ**
居間に置き、家族の時間だけ常時収音する。お茶を淹れる手、テレビに笑う声、小言、食器の音。普通の日々こそ、子孫が最も欲しがる遺産だ。会話は流れていく、装置だけが残す。

**⑤ 百年プロトコル**
デジタル遺産の本当の敵は技術ではない。フォーマット腐敗とベンダー死亡だ。WAV、プレーンテキスト、JPEG、チェックサム、三重の複製、「鍵の儀式」。50年後に確実に開く設計。

**⑥ 正直なアバター**
「これは本人ではない」と明示した再構成——写真の動画化、場所の再現、母が話しそうな言葉。孫が祖母を「知る」ための教材だ。ラベルが全て。

**⑦ 霧の記録**
末期も記録する。母が迷い、同じことを繰り返し聞く。それは子孫にとっての真実でもある。だが、それ以上に——娘が本を読み聞かせる声、手を握る手、髪を撫でる手。**遺産とは母の記憶ではなく、母が愛されたことの記録だ**という反転。これが一番型破りで、一番強い。

**⑧ 再定位ループ**
朝、「今日は◯◯。ここは◯◯。あなたは◯◯」と伝える装置。迷いの症状を和らげ、いまの母を助ける。その副産物として、母の日々の現実が記録される。**奪わず、与える。装置は採掘機ではなく、互恵の道具でなければならない。**

---

**判定。** ①は禁止する——ただし欲望は④と再配線する。②と⑧は採用、捕獲の主力。③は採用、最小実現単位。④は採用、ただしプライバシー設計を最優先。⑤は採用、全設計の基盤。⑥は縮小採用（再構成は「教材」に限る）。⑦は限定採用——同意と保護を条件に、「愛された記録」として遺す。

# 第二章 決断 — 三つの原理

発散の果てに、私は三つの原理でこの設計を固定する。

**原理その一「記憶はダウンロードできない。だから、拾い集める。」**
脳のコピーは永遠に不可能だ。だが断片はまだ取れる。残る資源（感覚・手続き・意味記憶）から発掘し、家族の観察で補完する。ここで誤解してはならない——**データは彼女ではない。彼女の痕跡だ。** この謙虚さが、後の倫理設計の全てを決める。

**原理その二「取り出すのではなく、引き出す。」**
録音するのではなく、会話を誘発する。音楽、香り、写真、食べ物、方言。引き出した語りは、母にとって「いま」の喜びでもある。装置は、母が「語りたい」と思える場を設計する。抽出ではなく贈与。これが装置を採掘機から救う。

**原理その三「生成するな、検索せよ。」**
この設計の最も重要な技術的判断。母の「続きの会話」をLLMに**生成させてはいけない**。代わりに、母が**本当に話した言葉**を検索で呼び戻す。孫が語りかけ、装置は彼女の実録音の最適な断片を返す。画面上に常に「彼女の言葉、当時に話されたもの」と表示する。生成ゼロ、検索のみ。これが、①の欲望（もう一度話したい）に答えつつ、幻覚と悲嘆依存を回避する**唯一の正直な経路**だ。

# 第三章 設計 — 「声壺（こえつぼ）」二段構え

装置の名は**「声壺」**。声を壺に封じて、後で開く——日本の民話的な形象。木と布でできた温かい箱。ボタンは一つ。聞いているとき琥珀色に光る輪。500グラム。施設に持ち運べる電池内蔵。認知症装置に見えない、ただの家庭の器物であること。

## 捕獲期（生きている間に）— 愛採

- **M1 生命インタビュー**：診断直後、能力が残っているうちに集中実施。StoryCorps型の構造化インタビュー。3時間×複数回。一人称の生涯語り、つまり「背骨」を作る。ここが最高価値・最優先。
- **M2 感覚発掘**：週1回・10分の誘発セッション。音楽、写真、香り、料理、方言で沈んだ記憶を引き出す。
- **M3 食卓の常時**：家族の時間だけの環境収音。手、歌、日常句。ミュートボタンと表示灯つき。
- **M4 再定位**：朝の定位ループ。母への現在の利益と、日々の記録。
- **M5 今日の母**：家族による一筆ログ。「今日、母は◯◯をして、◯◯と言った。」母視点に見える観察の連鎖。

## 語り継ぎ期（亡き後に）— 開壺

- **R1 背骨**：検索可能な一人称の生涯語り。彼女の声のまま。
- **R2 断片**：日々の普通の瞬間。お茶を淹れる手、笑う声。
- **R3 再構成**：明示ラベル付きの教材。「記録ではなく再構成」。顔のフォトリアル生成はデフォルト禁止。
- **R4 対話**：実録音だけを返す「語りかけ」モード。生成なし、検索のみ。孫が「おばあちゃん、今日学校でね…」と語りかけ、壺は彼女の実言葉を返す。
- **R5 愛された記録**：家族の愛情の記録。読み聞かせる声、握られた手。子孫が本当に継ぐもの。

# 第四章 実現可能性を検証する

**技術。** 全て今日の技術で成立する。

| 機能 | 技術 | 判定 |
|---|---|---|
| 収音 | 4マイク・アレイ、遠距離収音 | ○ |
| 文字起こし | オンデバイス Whisper級 | ○（方言で精度低下→「方言キーパー」で緩和） |
| 誘発コンテンツ | 音楽・写真・問いかけのライブラリ | ○（ここが最大の開発工数） |
| 検索 | 埋め込み＋意味検索 | ○ |
| 再構成 | 明示ラベル付き | ○ |
| プライバシー | ローカルファースト・暗号化・クラウド非依存 | ○ |

**コスト。** ハードウェアは組立品で約5万円、DIYキットで2.5万円。本当のコストはシリコンではなく**プロトコルと人**——インタビュー台本、誘発ライブラリ、そして「記憶番人」という新しい人間の役割だ。これはサービス層であり、差別化そのもの。

**運用。** セットアップ30分。セッションは家族か記憶番人が運営する。施設では、既存の「回想療法」と接続することでスタッフの負担をゼロにする。ボタン一つ、トレーニング不要。

**制度・倫理。** これが最大の依存関係。同意は診断時、能力が残存しているうちに**「記憶の遺言」**として取得する——何を記録し、誰がいつ開くか（「軽いものは孫に即時、重いものは亡き後」等）。継続的な同意は、セッション中の彼女の表情で判定する。疲れ・不快の光信号で装置は即停止し、音楽に退避する。

# 第五章 実行手順を書く

- **Phase 0（0–1ヶ月）**：MVP＝生命インタビュー＋「今日の母」ログ。スマホアプリと紙の台本。**ハードウェア不要。今日から始められる。** 合格ライン：ある家族が3セッションで「背骨」を作れる。
- **Phase 1（2–4ヶ月）**：誘発→記録→検索エンジン。オープン形式（WAV＋プレーンテキスト）。合格：彼女の言葉が検索可能になる。
- **Phase 2（5–8ヶ月）**：声壺ハードウェア。常時モード、プライバシー枠組み、再定位ループ。
- **Phase 3（9–12ヶ月）**：検索-as-対話（R4）。再構成キット（R3）。
- **Phase 4（常設）**：百年プロトコル。5年ごとの形式移行ドリル、三重複製、鍵の儀式。

最初の一歩は、装置ではない。**「今日の母」一筆ログ**だ。紙でもスマホでも、今日から家族の習慣にできる。

# 第六章 品質の条件を定める

「届けた」と言える状態とは——

**ある家族が、背板（背骨＋断片＋検索可能な全文）を、ベンダー依存ゼロで、30年後に孫が開ける。** それが合格ライン。

- **技術**：文字起こしが実用になる。検索応答1秒以内。3重の複製。テキストエディタで開ける（形式が人に読める）。
- **倫理**：全項目に同意の由来がある。再構成は全てタグ付き。対話モードは常に「彼女の言葉、当時に話されたもの」と表示。
- **感情テスト**：祖母に会ったことのない孫が、30分で「彼女の声、笑い方、愛したもの」を一つ説明できる。**これが品質だ。**

# 第七章 破綻点を探す

1. **家族がセッションをやめる**（悲嘆・忙しさ・気まずさ）。→ 誘発を10分に短縮。装置が促す。記憶番人層で補完。
2. **同意の喪失／後年の削除要求の衝突**。→ 早期同意、不変の監査ログ、「アーカイブ守護者」を指名。
3. **対話モード（R4）が悲嘆依存になる**。→ 利用時間制限。「あなたの祖母は、ここにいる」と生きている家族へ誘導する。
4. **ベンダー死亡／形式腐敗**。→ オープン形式、百年プロトコル、物理バックアップ。アーカイブはフォルダであって、専用データベースではない。
5. **同居家族の同意なし収録**。→ ミュート、表示灯、世帯合意の初期設定。
6. **再構成（R3）が本物と誤認される**。→ 常時ラベル。顔のフォトリアル生成はデフォルト禁止。
7. **施設で誰も回さない**。→ ワンボタン設計、家族／ボランティアモデル、回想療法との接続。

# 枠を埋める

- **実現可能性**：全て今日の技術で成立。最大リスクは技術ではなく、同意のタイミングと家族の継続。どちらも設計で解決済み。
- **実行手順**：Phase 0は紙とスマホで今日から。ハードウェアはその後。
- **品質条件**：孫が30分で祖母を「説明できる」こと。フォーマットが30年後に開くこと。
- **破綻点**：7つを列挙。すべてに対策あり。特に「生成ゼロ・検索のみ」が、AI甦生という最大の破綻を最初から排除する。

## 最強の主張

母の記憶を「ダウンロード」する装置は存在しない。だが、家族が母を愛した時間を「拾い集め」、母の実音声だけを検索で返す装置は、**今日**作れる。AIで甦らせるな。生成するな、検索せよ。最初の一年で動くのは、診断時の生命インタビューと家族の一筆ログ——それだけで、孫は祖母の声を三十年後に開ける。
