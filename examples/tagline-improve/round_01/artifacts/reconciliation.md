# 昇華——「新品です。過去つき。」×「新品を、一度も履いたことがない。」

二つの草案の対立軸を先に定めておく。両者とも「エコ＝贖罪物語」の拒否では完全に一致している——その共有された否定こそ昇華の土台である。しかし、その先で二つは正反対へと裂ける。

| | differentiator草案 | visionary草案 |
|---|---|---|
| 過去の存在場所 | **物の中**（素材に痕跡が刻まれる） | **観念の中**（新品とは社会的合意） |
| 履く者の位置 | 無罪ではない——**共犯** | すでに完全——**丸** |
| 身振り | 告発（他者へ向かう） | 解放（自己へ向かう） |
| 時間性 | 過去は積載される（重荷） | 過去は消去される（非在） |
| 商品との距離 | コピーが商品に密着 | コピーが商品から浮上 |

ここでの決定的な対立は「物質と観念」ではなく、**「主体は咎を負っているのか、それとも完全であるのか」** という、主体の位置をめぐる対立である。この対立を論理で「解消」することはできない。双方が真であり、しかも互いに相手の真を不可能にする。だから止揚する。

---

## 1. 否定（Negation）

### differentiator草案の否定——告発は贖罪の反転であって、脱出ではない

この草案の核心「共犯にする」は、贖罪物語を否定しながら、**贖罪の文法の内部に留まり続ける**。贖罪物語が「あなたは無罪になれる」と言えば、本草案は「あなたは無罪ではない」と言い返す。だが両者とも、「罪」という枠組みの内側にいて、正負を反転させただけだ。罪を消す代わりに罪を背負わせる告発は、消費者を罰する快楽——被造物への道徳的優位——をひそかに味わっている。英雄を否定した者が、今度は審判者という新しい英雄の座を占める。

さらに致命的なのは、**このコピーは商品の存在を自己否定する**。「買った瞬間にゴミは増えている」が真なら、一貫した行為は買わないことだ。ところがこれは靴を売る広告である。購入を共犯行為と断じるコピーは、靴を履く者に「お前は加害者だ」と告げながら、同時にその加害者に金を求める。これは告発の演技であり、実質は無罪放免——「共犯だと自覚する私」という新しい自己肯定の売り物である。マーケティングが贖罪を脱ぐと告げて、実はより洗練された贖罪（告発という自意識）を着ている。

一面的真理の僭称とは、**「過去は物の側にある」という物質主義を、主体の全真理だと思い込むこと**である。それだけでは、過去は重荷であり、履くことは罪の引き受けであり、出口は永遠に閉じている。

### visionary草案の否定——解放は物質を蒸発させる

この草案の核心「新品とは合意の上の幻影」は、物理の水準では正しい。だが**物質的な非対称性を消し去る**。再生材とバージン材の間に現実の差異（環境負荷、資源消費）がある以上、「新品など存在しない」という命題を強調すればするほど、Maruが再生材でできていることの意味が失われる。あらゆる靴がこのコピーを名乗れる——それは差別化の放棄である。differentiator草案が商品に密着していたのに対し、こちらは商品から完全に浮上し、靴である必然性を失う。

さらに、「新品の呪い」という枠組みは**問題を主体の認識に閉じ込める主観主義**である。呪いを解くことが消費システムの何かを変えるか。認識を変えることと、素材の流れを変えることは、このコピーの内部では接続されない。「丸は円だ。はじまりがないから、終わりも、使い古しもない」は、危険なほど慰めに近い——過去を非在とみなすことで、主体を物質的な応答責任から解放する美的神秘主義へ堕ちる危険をはらむ。differentiator草案が「買うな」とまで言いかねない硬直に落ちたのに対し、こちらは「何も変えなくていい」という軟着陸に落ちかねない。

一面的真理の僭称とは、**「新しさは観念の側にある」という構成主義を、存在の全真理だと思い込むこと**である。それだけでは、物質はただの乗り物であり、履くことは認識の余興になる。

### 両者に共通する一面的前提

そして何より、**両者は「過去は処理を要する何かである」という前提を共有している**。differentiator草案は過去を贖うべき重荷として、visionary草案は過去を消去すべき幻として——方向は逆だが、「過去」を一つの問題として対象化している点で一致している。ここに両者の対立はまだ現れていない。本来的な対立はもっと深い。

## 2. 保存（Preservation）

### differentiator草案から保存すべき真理の核

**第一に、物質主義の真実——過去は本当に素材に刻まれている。** 色ムラ、残る質感、消えない傷。これらは商品の欠陥ではなく、この靴だけが持つ履歴の可読性である。完全な循環は実在せず、その不完全さこそが嘘を真実にする。この洞察は捨ててはならない——これがなければ、後のコピーはどれほど美しくても空中に浮遊する。

**第二に、贖罪物語への拒否という誠実さ。** 「地球を救う」という洗浄コピーは差し替え可能な貼り紙であり、どんな競合にも使い回せる。救いを売らない、という断言には、マーケティングが普段隠す真実への敬意がある。

**第三に、商品への密着。** 「新品です。過去つき。」は、この靴の素材を指さしたコピーである。この具体性は、いかなる抽象化の後にも保存されねばならない。

### visionary草案から保存すべき真理の核

**第一に、構成主義の真実——新品は物の性質ではなく、共同体による合意である。** 新品という一瞬は、代金を払った瞬間に蒸発する。人は消える幻を買っている。この発見は、「新しさ」を自然なものとして受け入れる消費者の認識を揺さぶる——これは捨てられない。

**第二に、消費＝自己形成という人類学的洞察。** モノを語る言葉は自己理解の枠組みであり、消費は常に自己形成の儀式である。買い物を効用だけに還元しないこの視点は、コピーを商品説明から自己変革へと引き上げる。

**第三に、言語の救済。** 「新品／中古」という呪いの対立に対し、「丸ごと／まるまる」——使われても減損しない全体性を指す言葉が日本語には既にある。言語がすでに脱出口を知っているというこの発見は、コピーの言語感度の中核として保存される。

**そして何より——解放という身振りそのもの。** 主体を断罪しないこと。共犯と告げる代わりに、「あなたは新品でなくとも完全である」と語りかける慈愛。differentiator草案が冷酷な真実を引き受ける勇気なら、こちらはその真実を下ろしてやる優しさである。昇華はこの両方を失ってはならない。真実は告発の形で、慈愛は解放の形で——どちらか一方が欠ければ、コピーは硬直するか、浮遊するかである。

## 3. 高次化（Elevation）

### 軸の移動——「物か心か」から「履くという出来事」へ

両草案の対立は空間的な問いだった——「過去は物の中にあるか、心の中にあるか」。昇華はこの問い自体を解体し、**時間的な問い**へ置き換える——「**履くという瞬間に、何が起こるか**」。

「新品です。過去つき。」（物に過去が在る）と「新品を、一度も履いたことがない。」（心に新しさは非在である）は、二者択一ではない。両者は**履くという出来事の中で出会う**。靴を履いた瞬間、素材に刻まれた過去（differentiator草案）と、観念としての新しさ（visionary草案）は同時に変容する。新しさは死に、過去が生まれる。いや——新しさと過去は、履くという一点で**同じものの表裏**であることが露呈する。

ここで日本語が決定的な手がかりを与える。

> **履く（はく）と 履歴（りれき）は同じ字である。**

日本語は無意識のうちに真理を語っていた——靴を履くこととは、歴史に入ることである。**新品とは「まだ履かれていない過去」にほかならない。** どんな新品も、購入者は履くことによって、その物の履歴の次の一行を書く。あるいは反転して——どれほど「新品」とラベルされた物でも、それは未だ履かれざる過去であり、過去の不在ではなく、過去の未経験なのである。

この一つの規定が、両草案を包含する。

- differentiator草案の「過去つき」——**その通り、過去は在る。だがそれは重荷としてではなく、履かれるのを待っている履歴として。** 靴が「新品です。過去つき。」であるのは、あらゆる靴がそうだからではなく、Maruだけが**過去を隠さず表面に刻んでいる**からだ。普通の新品は過去を隠す（合意による忘却——visionary草案）。Maruは過去を隠さない。したがって、
- visionary草案の「新品を、一度も履いたことがない」——**その通り、新品は履けない。だがそれは新品が幻だからではなく、履いた瞬間に新品は「過去」になるからだ。** 新品は履くことのできない過去であり、履かれてはじめて現在になる。

二つのコピーは矛盾していなかった。**前者は「靴が運ぶ過去」を、後者は「履くことによって過去になる新しさ」を語っており、両者は履くという一点で接続する。**

### 丸の深層化——「共犯」と「丸」は同じ図形である

次に、両草案の主体の位置をめぐる対立——「共犯か、完全か」——を昇華する。

differentiator草案の「共犯」の真意を、道徳から解放して吟味する。買うことがゴミを増やす、という告発の奥に、より深い事実がある——**存在することはすべて、変容への共犯である**。あらゆる生き物は、他の存在を変容させずに存在できない。靴は他の素材の死の上に成り、あなたはその靴を履くことで世界の変転に加担する。この「共犯」は罪ではなく、**存在の条件**である。

visionary草案の「丸」もまた、単なる慰めではない。円とは「はじまりがない」ことではない——**どの点もが中間である**ことだ。円の完全性は、各点が他のすべての点と連関していること（円環の全体に引き込まれていること）によって成立する。**円の完全性とは、まさに全体的な共犯のことであった。**

つまり「共犯」と「丸」は対立していない。**円とは、完全であることと、すべてに引き込まれていることの、同じ一つの構造の二つの名である。** 完璧に丸いものは、それが何であるかにすべてを含んでいる——他の何かとの関係を一切断たずに存在する円は存在しない。Maruが再生材で丸く編まれるとき、その丸さは「無垢」ではなく「すべての引き受け」（引き受ける＝円が全ての点を内包する）として現れる。

### 高次化されたコピー（後続工程への材料）

以上の止揚を、一つの言語的ジェスチャーに圧縮する試み。ただしこれは後続の最終分析が仕上げる素材であり、最終形ではない。

**中核候補：**
> **「新品とは、まだ履かれていない過去。Maruは、過去を履く。」**

- 「新品とは〜」の定義的転換がvisionary草案の構成主義を引き継ぎ（新品を物の性質から合意の認識へ）、
- 「過去を履く」がdifferentiator草案の物質主義を引き継ぎ（過去は実在し、それは履かれるべき履歴である）、
- 「履く」と「履歴」の同字が両者を一つの出来事へと接続する。

**補助候補（丸の深層化）：**
> **「新品と中古のあいだに、丸はある。」**

新品でも中古でもない第三項——二項対立そのものを内包しつつ超える円。あるいは

> **「新品ではありません。だから、丸い。」**

否定が否定のまま保存され、その否定を根拠として肯定（丸さ）が生まれる——文法の内部に弁証法を埋め込んだ形。「だから」の接続が、過去を欠点から条件へと転位させる。

## 4. 超越的視点——対立が「対立ですらなかった」と見える次元

止揚の果てに、元の対立がそもそも対立ではなかったと見える地点がある。

両草案は「過去は物の中にある（罪）か、心の中にある（幻）か」と問うた。だが昇華の後に見えるのは、**過去と新品は物や心の性質ではなく、関係の時間性である**——という事実である。物はそれ自体では「新品」でも「中古」でもない。新品とは、履くという関係が入る前の呼び名であり、中古とは、履くという関係が入った後の呼び名である。同一の靴が、ある関係から見れば新品であり、別の関係から見れば中古である。**「新品」と「過去」は、履くという出来事を挟んだ前後の名前にすぎず、両者の対立は、静止したものに動的な時間を押し込んだときに生じる疑似対立だった。**

このとき、さらに深い解体が起きる。「無垢な英雄」か「汚れた共犯」か、「贖罪」か「解放」か——これらの選択肢は、**主体と客体を切断する主体性の幻想から生じていた**。自分が独立した主体であり、物が独立した客体であるという前提に立てば、確かに「私は物の過去に対して無罪か有罪か」という問いが生じる。だが履くという出来事の中では、主体と客体は互いに変容し合う——靴はあなたの歩幅を形づくり、あなたは靴に折り目を刻む。**履くことは相互変容であり、相互変容においては、無罪も有罪も成立しない。** あるのは継続だけである。あなたは靴の過去を履き、靴はあなたの現在を過去にする。

この次元では、二草案の核心的命題——「あなたは共犯である」と「あなたは丸い」——は対立ですらなく、**同じ一つの構造（関係のうちにある存在）への二つのアクセス路**だったことが見える。丸いことは、すべてを内包することであり、すべてを内包することは、すべての共犯関係を引き受けることである。**完全性とは無垢ではなく、全的な関係性そのもの**——それは仏教が縁起と呼んだもの、すべての存在が他の存在の存在の上に成り立つという構造にほかならない。Maruは、その縁起を足の裏で触れることのできる物体へと凝固させたものである。

そして最後に、両草案が共有した盲点が照らし出される。両者とも「過去は処理を要する問題である」と前提していた——贖うべきか、消去すべきか、という形で。昇華の後に見えるのは、**過去は問題ではなく、過去こそが現在の材料である**、という逆転である。処理を要するのは過去ではなく、過去を隠す「新品」という名の忘却である。Maruはこの忘却を拒む靴として、過去を隠さず、履くという出来事をそのまま履かせる。

したがって最終的なコピーは、「新品です。過去つき。」の反転でも「新品を、一度も履いたことがない。」の反復でもなく、**「新品」という呼び名の無効化**として成立する——新しいとも中古とも呼ばれない円として、Maruは立ち現れる。

> **「新品も、中古も、まだ履かれていない。Maruは、履くたびに、つづき。」**
