# 弁証法的止揚——『Maru』キャッチコピー

## 序：対立の配置

両草案は、前回の和解（「新品も中古も、まだ履かれていない過去だ」）を**同じ理由の正反対**から拒絶している。Differentiator は和解が「製品を無害化した」と攻め、Visionary は和解が「人間を中心に置いたまま」と攻める。すなわち——

- **草案A（Differentiator）**は**市場への反乱**である。人間を「円を閉じる最終工程」という英雄に立て、死蔵経済（履かないことに価値を置く経済）を正面から撃つ。人間は円の**外側**に立ち、歩くことで円を完成させる。
- **草案B（Visionary）**は**人間への解体**である。円には中心がない。人間は完成者ではなく「最新の再生素材」であり、Maruが人間を履く。人間は円の**内側**を通過する一点にすぎない。

対立の形は「人間は円を**閉じる**か、円を**通る**か」。だが注目すべきは、両者とも**同じ一つの出来事**——履くという瞬間——を指差していることだ。両者とも「靴は未完成で売られ、履くことで完成する」と言っている。違いはただ、その完成の最終主体を「人間（主体）」と見るか「素材（客体）」と見るかだけである。この一点に、両者の一面的真理と共通の錯誤が凝縮している。

---

## 1. 否定（Negation）

**草案Aの否定——英雄の幾何学的不可能性。**
Aの真理は「履くことが価値を生む」という死蔵経済への背信だが、全体の真理を僭称する瞬間、それは**主人の入れ替え**に堕ちる。Aは「工場の最終工程を自分の一歩で請け負う」と言う。これは人間を生産過程の**外側**に立つ最終作業者として措定する——まさに死蔵コレクターが持つ構造と**同じ所有の構図**である。収蔵家が「履かずに所有する」主人なら、Aの人間は「履いて所有する」主人だ。円環は依然として**彼の手柄**であり、「履き続けた者だけが丸になる」という功徳主義の門が残る。Aは商品フェティシズムを労働倫理フェティシズムに置き換えたにすぎない。そして幾何学的に、円は**外側からは閉じられない**。閉じる者は常に円周上にいる。外側から円を閉じる「完成者」は存在しえない——Aの英雄は不可能な位置に立つことで、その一面的であることを自ら証している。

**草案Bの否定——脱中心の自己矛盾。**
Bの真理は「新品という記憶の消去こそが真の廃棄物である」という軸の転換だが、全体の真理を僭称する瞬間、それは**語りかける主体を殺し、広告という言語行為そのものを無効化する**。純粋な脱中心は「あなた」を消す。あなたがただの素材なら、Maruを履くことも捨てることも、買うことも買わないことも**無差別になる**——選ぶ理由も、責任も、差異も消える。そして決定的なことに、Bの宣言は**遂行的自己矛盾**を孕む。「中心は虚構である」と言いうるためには、円全体を俯瞰する一点——すなわち**最も中心的な神の位置**——に立たねばならない。脱中心の身振りは、あらゆる立場を相対化して見渡すという点で、最も中心化された身振りなのである。Bは否定する主体を、否定の瞬間に密輸入している。

**共通の錯誤。**
両者は対立しながら、**同じ前提**を共有している。すなわち、円（丸）を**空間的な閉じた図形**として扱い、「人間はその内側（素材）か外側（完成者）か」を争う。だが円の本質は空間ではない——**時間**である。円とは還ることである。時間的な図形には内も外も中心も完成それ自体も存在せず、ただ還帰の運動がある。両草案は、時間的なものを空間的なものに読み替えた上で、その誤読の内部で対立していたのである。

## 2. 保存（Preservation）

**草案Aから保存するもの。**
- **使用による価値**という背信の構図。死蔵（時間を止めること）への攻撃は、このキャンペーンが独占しうる唯一のスキャンダルであり、捨ててはならない。
- **物質的な証明への要求**。「言葉でなく素材が約束を証明すること」——摩耗で浮かび上がる丸、経年で変わる繊維。この前提は、キャンペーンをグリーンウォッシュから護る錨であり、保存すべき。
- **「未完成のまま売る」という逆転**。製品とは箱の中身ではない、という触知的なフック。

**草案Bから保存するもの。**
- **「新品」という虚構の告発**。新品とは過去の消去である。真の敵が廃棄物そのものでなく「記憶の消去」であるという洞察は、エコの枠組みを道徳的犠牲から存在条件へと移し、罪悪感の装置を解体する——Aの功徳主義がまだ必要としていた罪悪を、Bは不要にする。
- **人間と素材の連続性**。身体は最初から再生材であり、星屑の原子が足を形作る。これはリサイクルを特殊技術でなく人間の存在条件として晒す——Aが攻撃する死蔵経済への攻撃を、より深い層から支える。
- **脱中心という批判的レンズ**。円の完成は誰の手柄でもない。この「誰も中心に立てない」という制約は、Aの功徳主義の過剰を常に留める批判装置として保存される。

要するに——Aの「**歩くことで円が閉じる**」というテロスと、Bの「**円に中心はない**」という制約。この二つは、捨てるべきどころか、互いを欠陥から救う対である。

## 3. 高次化（Elevation）

**新しい枠組み——「完成と通過は同一の出来事である」。**

Aは円を外側から閉じようとするが、幾何学上、円は**通過によってしか閉じない**。Bは円の中心を消すが、円周上の一点の運動こそが円の完成そのものである。すると両者の対立は解消するどころか、**一つの事実の二つの見え方**になる——円を「歩く者の側から」見れば、円は私の歩みによって完成する（Aの真理）。円を「どの点からも」見れば、円は中心的でなく無関心に回帰する（Bの真理）。円とは、**一点の運動と全体の無関心との同一性**だからである。

ここで円は空間から時間へと引き上げられる。Maruは「物」ではない。**時間の関係**である。
- **再生素材**＝靴が**過去**を運ぶこと（ゴミの記憶）。
- **履くこと**＝靴が**未来**を蓄積すること（摩耗、経年、丸の完成）。
- **人間**＝円の**現在**。過去（ゴミ）と未来（丸）が一致する一点。

人間は円の作者でも素材でもない——人間は円の**現在時制**である。そして時間の枠組みでは、Aの「完成」とBの「通過」が同じ出来事として立つ：**円は踏破されることによってのみ閉じる**。閉じることと通ることの対立は、ここでは対立ですらない。

**高次化された表現の方向性**（後続工程への素材として）：

- メイン候補：
  - **「丸に、中心はいらない。一歩で、閉じる。」**——Bの脱中心とAの完成を、一つの構文に同時に保持する。
  - **「まだ、歩いていない。」**——Bの「新品も中古も」という軸の消去と、Aの「履くことこそがテロス」を、一文で止揚する。
- マニフェスト：**「死蔵は時間を止める。新品は時間を消す。Maruは時間を履く。丸の中心に誰もいない——だが丸は、歩く者の中でしか閉じない。」**

**高次化された前提**：この約束は、**時間の通過を可視化する靴だけが偽らない**。Aの前提（摩耗の可視化）は保存され、同時にその可視化された経年こそが「主体と客体」を時間の二相へ還元してBの前提を満たす——素材が老いる様を見る者は、もはや自分を円の外側の主人とは措定できない。

## 4. 超越的視点

止揚を経て初めて見えるのは、次のことである——**両草案の対立は、そもそも対立ではなかった。**

両者は「Maruと人間の関係は何か」という問いを共有し、「人間が完成するか、人間が素材か」を争った。だがMaruは人間と**関係を持つ物**ではなく、人間と靴が**共有する時間のあり方**の名である。真の区別は「新品／中古」でも「主体／素材」でも「履く／蔵う」でもない——**時間の否認か、時間の承認か**である。

死蔵経済と新品崇拝は、どちらも**時間の否認**だ。デッドストックは対象を最大価値の瞬間に凍結する（時間を止める）。新品は過去を消去する（時間を消す）。両草案は実は**同じ敵**——時間の否認——を攻撃していた。ただAはそれを「死蔵」と名指し、Bは「記憶の消去」と名指した。名指しが違ったために、人間の位置をめぐって対立するかのように見えたにすぎない。この次元では、AとBの対立は、**同一の円を内側から見るか外側から見るか**の違いでしかなかったことが露呈する。

そして最深の一点——**Maruの買い手が買うのは靴ではない。時間の扱い方である。** 死蔵は時間を殺す。新品は時間を偽装する。Maruは時間を「履く」。円とは、同じでありながら同じでない**還帰**——ゴミが丸として還り、足が記憶として還る——の形である。この意味で、Maruの最も本質的なキャッチコピーは、どの草案にもなかった一語に収束する。

**「時間を、殺さない。」**
