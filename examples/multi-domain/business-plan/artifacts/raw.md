# LED照明 事業計画書

## 事業名（仮称）: LUMIÈRE JUSTE ／ 事業コンセプト:「食事と商品を美しく見せる光」

---

## 1. エグゼクティブサマリー

**要旨**: 欧州の高級レストラン・ブティック向けに、**Ra90以上・高R9・フリッカーフリー**という「上質な光」を、**1台200〜400EUR**で提供する照明メーカーを立ち上げる。

現在の市場には明確な空白がある。

| 競合層 | 価格帯 | 光の品質 | 課題 |
|---|---|---|---|
| 欧州高級ブランド（ERCO / Zumtobel / XAL系） | 500〜1,500EUR+ | 高品質 | **高すぎる**。予算の限られた飲食店には過剰 |
| アジア低価格品 | 20〜80EUR | Ra80未満・色むら・ちらつき | **品質が足りない**。食材や商品を美しく見せられない |
| **当社（空白地帯）** | **200〜400EUR** | **Ra90+・R9高・SDCM≤3・フリッカーフリー** | なし |

**勝てる根拠（3本柱）**:
1. **規制の追い風**: EUエコデザイン指令により2030年までに蛍光灯販売禁止 → 全施設で強制的な転換が発生。LED化率60%は「過渡期の入口」であり、残り40%＋既存LEDの更新需要が確実に立ち上がる。
2. **品質の空白**: Ra80はEUの**最低法定ライン**。高級接客空間が実際に買うべきはRa90以上・R9・色の一貫性（SDCM）・ちらつきのなさ。粗悪低価格品はここを満たさない。
3. **価格の空白**: 高級ブランドの半額以下で「品質を数値で証明できる」プレイヤーがいない。

**3年目標**: 売上 **€60万 → €168万 → €384万**、損益分岐は2年目後半、3年目に営業利益率約14%。

## 2. 市場分析

### 2-1. 市場構造
- EUのプロ用照明市場（非住宅）は概算**€130〜140億**規模。うち商業施設・ホスピタリティが主要セグメント。
- 2025年時点のLED化率は約**60%**。残り40%は蛍光灯・HID等で、**2030年の販売禁止により確実に置き換えが発生**する。
- 高級レストラン・ブティックは、**改装サイクル7〜10年**＋新規出店で毎年一定量の照明需要が発生する。光は内装費の数%だが、**空間の印象を決める**ため、値切られにくい支出項目。

### 2-2. 規制がもたらす需要の「波」
| 規制/制度 | 内容 | 当社への影響 |
|---|---|---|
| EUエコデザイン指令 | 2030年までに蛍光灯販売禁止 | 置き換え需要の確実な発生 |
| ErP規則 (EU) 2019/2020 | 光源の最低効率・**Ra≥80**・EPREL登録義務 | Ra80は最低ライン → 競争の舞台はRa90以上へ |
| エネルギーラベル新基準 | 光源のA〜G再表示 | 品質・効率の可視化で「証明できる商品」に有利 |
| ENEC / CE / RoHS / REACH | 認証・物質規制 | 粗悪輸入品への参入障壁。**当社は正規取得で差別化** |

> **重要な含意**: Ra80は規制の最低ラインにすぎない。規制が効くほど、**「Ra90以上・R9・色一貫性・ちらつき」という次の競争軸**が明確になる。当社は最初からこの軸で勝負する。

### 2-3. TAM / SAM / SOM（概算）
- **TAM**: EUプロ用照明の高品質セグメント — 約€20〜30億/年
- **SAM**: 欧州の高級レストラン・ブティックの照明設備投資 — 約€300〜500M/年
- **SOM（3年目）**: 16,000台・€384万 = **シェア約1%**。大きな市場に対して現実的な獲得水準。

## 3. ターゲット顧客と購買心理

### 3-1. 購買者（買うのは施設ではなく「デザイン」）
高級飲食・小売では、**照明は建築家・照明デザイナー・内装デザイナーが「スペックイン」**して決まる。エンドユーザーは最終承認者だ。

| 役割 | 求めるもの | 当社のアプローチ |
|---|---|---|
| 照明デザイナー / 建築家（ゲートキーパー） | 測光データ、グレア管理、調光性能、納期 | IES/Dialux/BIMデータを公開し、スペックしやすくする |
| 高級レストラン経営者 | **料理が美味しそうに見える**、客の滞在時間、リピート | 食材の見え方を実証するケーススタディ |
| ブティック経営者 | **商品が高級に見える**、売上貢献 | 素材別（革・シルク・金属・宝石）の見え方比較 |

### 3-2. 顧客が抱える本質課題
- **粗悪LEDで料理が「青白く・のっぺり」見える** → 高級店の価値（体験）が毀損
- ちらつき（100Hz）による不快感・目の疲労 → 長時間滞在する飲食店では致命的
- 高級ブランド品は品質が良いが**予算を超過** → 中間価格の選択肢がない
- 安価品は色むら（SDCM大）で**同じ空間に複数台並べると色が揃わない**

> 彼らは「照明器具」を買うのではなく、**「料理が美味しく見えること」「商品が高級に見えること」**を買う。マーケティングは機能ではなく成果で語る。

## 4. 製品戦略

### 4-1. 技術仕様（差別化の根拠）
GaN（窒化ガリウム）系LEDを採用。GaNは高効率と高演色の両立を可能にする基盤技術であり、**「GaNベース」を技術的信用の裏付け**として訴求する。ただし真の差別化は以下で作る：

| 項目 | 低価格品 | 当社 | 根拠 |
|---|---|---|---|
| 平均演色評価数 Ra | 80未満（実測） | **≥90** | 肌・食材の自然な発色 |
| 深赤色評価 R9 | 考慮外 | **≥50** | ステーキ・赤ワイン・口紅の発色 |
| 色の一貫性 SDCM | 大（バラつき） | **≤3** | 複数台並べても色が揃う |
| ちらつき | 100Hz/高フリッカー | **フリッカーフリー（調光1%まで）** | 目が疲れない・安心感 |
| 色温度 | 固定 | **2700K / 3000K / チューナブルホワイト** | シーン演出（昼→キャンドル） |
| 寿命 | 記載なし | **L70 50,000h / 5年保証** | 総保有コストの根拠 |
| 認証 | 曖昧 | **CE / ENEC / ErP適合 / EPREL登録** | 正規市場での信用 |

### 4-2. 製品ポートフォリオ
| ライン | 用途 | 想定売価 |
|---|---|---|
| トラック・スポットライト | ブティックの商品スポット照明（主力） | €250〜400 |
| 埋込ダウンライト | レストランのアンビエント照明 | €200〜320 |
| ペンダント / デコラティブ | レストランのメイン照明・アクセント | €250〜400 |
| チューナブルホワイト対応 | シーン演出（ランチ/ディナー切替） | +€80〜100 |

### 4-3. 「品質を証明する」武器
- **測光データ全公開**（IES / LDT / Dialux・RELUX・BIMデータをWebで無料公開）
- **実測値の透明化**: SDCM・R9・フリッカー率をカタログに明記
- **5年保証＋補修部品の供給保証**（安価品ができないこと）
- サステナビリティ: リペアブル設計・再生材料・**EPD（環境製品宣言）**を提供

## 5. ビジネスモデルと販売戦略

### 5-1. 収益モデル
| 項目 | 内容 |
|---|---|
| 収益源 | 照明器具の販売（単価€200〜400）＋調光制御/演出システム＋無料の照明デザイン支援 |
| 商談サイズ | 高級レストラン1店舗=30〜60台 ≈ **€12,000〜20,000/プロジェクト** |
| チャネル | ①直販（デザイナー案件）②照明卸・電気卸（Sonepar / Rexel系）③チェーン店一括受注 |

### 5-2. スペックイン戦略（最重要）
1. **デザイナーとの初期案件**: 立ち上げ期に名のある照明デザイン事務所と組んで**フラッグシップ20件**を獲得。写真・データを「実績」として使う。
2. **商談の武器**: 「同じ料理をRa80の光とRa90+の光で照らした比較写真」を営業資料に。
3. **展示会**: Light+Building（フランクフルト）等で存在感を出す。
4. **卸チャネル**: 初期は直販で案件数を積み、認知が出た段階で卸に展開（卸は2年目以降）。

## 8. リスク分析と対策

| リスク | 影響度 | 対策 |
|---|---|---|
| 大手高級ブランドの価格攻勢 | 中 | 価格でなく「認証・データ・納期・デザイン自由度」で勝負。下位ブランド化しない |
| 中国勢の品質改善・参入 | 中 | SDCM・R9・フリッカー等「規制外の品質軸」とスペックイン関係で先行者優位 |
| 為替・物流コスト変動 | 中 | EU内倉庫・複数拠点調達・為替ヘッジ |
| 景気後退による改装投資減 | 中 | チェーン店の標準化受注で安定化、リペア/リトロフィット需要にも対応 |
| スペックサイクルの長期化（6〜18ヶ月） | 高 | 初期にフラッグシップ案件を集中投入、パイプラインを常に多層化 |
| 部品調達（LEDチップ・ドライバー） | 中 | 主要部品の2社化、長尺発注契約 |

## 10. 結論 —— この事業の要諦

1. **規制が需要を保証し、品質が価格を守る。** 2030年の蛍光灯禁止は市場の「波」を確実化し、Ra90+という上質軸は低価格競争から身を守る。
2. **空白地帯に立つ。** 高級ブランド（高すぎる）と粗悪品（安すぎる・質が悪い）の中間、**「品質を証明できる200〜400EUR」**に競合はほぼいない。
3. **売るのは光の機能ではなく、料理の見え方・商品の高級感という「成果」。** スペックインネットワークと実測データで、この業界特有の長期・高LTVの関係を築く。
4. **最小初期投資€55万で検証→黒字化の道筋**を立てられる、運転資金の軽いビジネス。
