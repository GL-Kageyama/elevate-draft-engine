# 出力形式（OutputFormat）

- 成果物種別: 分析レポート
- 説明: 複数の視点を昇華した、超越的で具体的な分析。
- 出力長の範囲: 300〜1500 字
- 成果物そのもの: いいえ（成果物についての分析）

## 最終化の形式指示（finalize_guidance）

上記の止揚に基づき、このテーマの最終分析を記述せよ:
1. 止揚の中間過程（草案同士の比較・経緯説明）は含めず、高められた結論だけを書く
2. Target（対象顧客）・Value（提供価値）・Risk（リスクとその対策）・Opportunity（機会）の4観点で整理しつつ、これらを超越する統一的視座を示す
3. 具体的・整合的・実行可能でありながら、元のどの草案にもなかった超越的統合であること
4. 確信できる点は断定的に、不確実な点は前提として明示する
5. 単なる「バランスの取れた報告書」ではなく、一段高い次元の理解を読者に与えること
