# 物語の核心（テーゼ）

**核心的主張**
このリリースは靴を売らない。「海が、靴になって帰ってきた」という、誰かが自分の言葉で話したくなる一文を世に放つ。軽量・通気性・環境負荷70%削減は、その物語を信じさせる証拠であり、買う人は「靴」ではなく「語れる自分」を買う。機能はどこの競合も模倣できるが、この帰還の物語だけは模倣できない——それがMaruの唯一の防衛線である。

**根拠**
- 製品名『Maru』＝円環は、循環・帰還・完成を名前に埋め込み、名前そのものを語り継ぎの装置にしている。
- 海岸回収という起点は、誰も見たがらないゴミを、誰もが聞きたがる救済の物語へ反転させる核を内蔵している。
- 20〜30代は「その靴、どこで買ったの？」の一言を待っている——物語は所有物ではなく、語り手の身分を変える。

**前提**
人は機能を比較して買うようで、実際には、自分が語れる物語を買う。
