海の歌で人の心に残るものは、水平線でも潮騒でもない。人が語り継ぐのは《不可能な行為を、愚直に反復する者》だけだ。この歌は書く——沈んだ船に灯りを灯しつづける男を。風景は一枚も描かない。ただひとつの行為と、その反復だけを。

---

**(1) タイトル候補**

- **『帰る日まで』**（副題：灯台守の歌）——本命。「まで」が来ない約束＝永遠だと、聴き終えてから気づく仕掛け。
- **『沈んだ船に灯りを』**——歌の全筋が一行に収まる。このまま標語になる。
- **『火を抱く海』**——水と火の倒置。矛盾がそのまま主題。

**(2) 断片** —— 視点：沖で沈んだ息子の魂を「灯台の火」だと決めた灯台守。父は海に祈らない。海と**取引**する。

**Aメロ**（夕凪、潮が引く）
```
陽が沈むたび、潮が引く
引いた砂に、おまえの足跡が浮かぶ
波はそれを消しにくるのに
おまえの足跡だけ、沖を向いている
```
全行が「引く／浮かぶ／くる／向く」と **-く** で畳まれる。足跡が沖を向く＝息子はまだ海へ帰りたい。父はそれを「帰ってくる」と読む。

**Bメロ**（あの夜の記憶）
```
あの夜、沖で雷が光った
光ったあと、海は笑っていた
笑った海が、おまえを呑んで
呑んだ拍子に、火は浮かんでいた
```
各行が前行の動詞を引き継ぐ連鎖。「海が笑う」は古典的な凪の詩語——それを、呑んだあとに嘲笑う海へ裏返す。「火は浮かんでいた」、この瞬間に息子は灯りになった。

**サビ**
```
沈んだ船に、灯りを
帰る日まで、消させない
おまえの火は、海のものじゃない
だから今夜も、俺が灯す
```
1・2行目が反復核。3行目「海のものじゃない」がこの歌の全主張。4行目は毎夜の行為。

**ラストサビ**（転。父が死ぬ夜、あの夜と同じ雷が灯台を撃つ）
```
沈んだ船に、灯りを
帰る日まで、消させない
おまえの火と、ひとつになる
今日から俺が、灯りになる
```
同じ句を繰り返しながら、最後の一回だけ別の歌になる。「俺が灯す」→「俺が灯りになる」。雷は息子を取った夜と同じ雷で、父を取って返す。**歌は同じ反復で、意味だけ裏返る。**

**(3) テーマ軸（一文）**

海に沈んだ息子を「火」として返せと海と取引しつづける灯台守の歌——別れを受け入れない執念が、それ自体を愛の作法に変え、「帰る日まで」という来ない約束に永遠を閉じ込める、無常への抵抗。

**(4) サビ核の一節とリズム**

**核：「沈んだ船に、灯りを／帰る日まで、消させない」**

- **拍数**：11・11（第1句＝しずんだ4＋ふねに3＋あかりを4。第2句＝かえるひ4＋まで2＋けさせない5）。同数で対を成しながら内部の切れ目だけがずれる——破調。
- **母音**：第1句は「ず・ふ・ね・に」と濁音＋**u** が沈む（海・夜・沖）。第2句は「け・さ・せ」の歯擦音——火を吹き消す息の擬音。響きは **a・e** へ明るく上り「い」で終わる。反復のたび「灯りを(o)」が海へ投げかけられ、「消させない(i)」が頑なに跳ね返す。この **o→i** の往復だけが全曲の韻律になる。
- **リズム**：4/4、♩=60前後、ドラムレス。波の録音をそのままテンポ源にし、2小節＝1フレーズ。「消させない」の後に一拍休符を置いて海に沈黙を聞かせる。和声は導音を避け「終われない」——帰る日まで＝終わらない。
- **歌い方**：張らない。しゃがれた語り。呪文のように同じ2行を4回、表情を変えず繰り返す。

**語り継がれる核（誰が・なぜ）**

この歌を人は「あの、息子の魂を灯りにしてる灯台守の歌」として語る。漁師町の弔いの場に流れるフォークとして始まり、やがて「帰る日まで」の句が歌から離れて、弔辞・墓誌・SNSの投稿として一人歩きし、諺のようになる——句が歌であることをやめた瞬間に、この歌は語り継がれはじめる。
