**タイトル候補**
- 「光年越しの配達」（本命）
- 「八分二十秒」
- 「消えた光源」
- 「遅延放送」

**視点**：屋上に立つ男。星を宛先に手紙を書く。返事は来ない。届くのは、宛先が死んでから届いた光だけ。

---

**Aメロ断片**（8・8／淡々と・下降調）
```
街灯が消えて 夜が深くなる
星を待つ夜に 君の残像が
暗い宇宙を 今日もここまで
もう見えないのに 光を放った
```

**Bメロ断片**（7・7／息を切らせて・事務語を差し込んで冷やす）
```
君が光を 放った夜に
僕は気づいた 光は過去の
配達だって 住所は未来
誰も読まない 消えない宛名
```

**サビ断片**（8・8／等拍・「い」の響きで回帰）
```
光が届く日 君はもう居ない
届くのはいつも 君の過去ばかり
それでも夜空を 観測してるよ
光が届く日 君はもう居ない
```

---

**テーマ軸（一文）**
光が届いたとき、それはもう君ではない——届かないと知りながら手を伸ばすのは、未達のまま循環することだけが、この恋に値段を付けるからだ。

**サビの核・リズム骨子**
- 核の一節：**「光が届く日 君はもう居ない」**（8拍＋8拍、語頭にk音を置き、末尾母音「い」）
- サビは全行8・8の等拍。語尾の響きを「ない（あい）→ばかり（あい）→よ（お）→ない（あい）」とし、3行目の「よ」だけを解放に使い、最終行は1行目と同文で回帰させる。
- Aメロは同じ8・8で熱を落とし、Bメロだけ7・7に詰めて「配達・住所・宛名」の言葉で歌を冷やす。感情のピークを音価（拍数）で操作し、言葉では決して「待つ」と言わせない。
