あなたは「海」を愛でる側ではない。**海に奪われた側**として書く。そしてその喪失を悲しみのまま歌にしない——「悲しみ」は記憶に残らない。「まだ問いを放棄していない執念」だけが残る。故郷の海を美しいと一度も思ったことがない漁師の、返事を待ち続ける歌。

---

## (1) タイトル候補

- **主案『返さなくていい』** — サビの核そのもの。海への呟きではなく、海にさらわれた者への言葉。一読では意味が閉じない。
- 『潮の喪主』 — 海が喪主を務める葬式。遺体のない葬式。
- 『棺を叩く波音』 — 夜明けの波は、沈めた棺の蓋を内側から叩く音だ、という形象。
- 『絞ったシャツの灯り』 — 最愛の者の濡れたシャツを絞り、その水を捨てず、油のように灯した、という具体的な一悪。

## (2) 歌詞の断片

**Aメロ**（夜明け・出航の支度。死者の視点に立つのではなく、生者の手元の動作だけで綴る）

```
夜明けの波は　棺の蓋
お前が　裏から　叩いてる
絞ったシャツで　灯りを点け
暗いうちに　沖へ出る
```

**Bメロ**（光・風・記憶の比喩。朝の干潟に遺影を並べる——死者がまだ「そこにいる」証拠を集める）

```
干潟に光が　差すたび
硝子の裏で　お前が息をする
風が変わって　雨の匂い
生臭い夜は　骨まで近い
```

**サビ**（核の反復）

```
返さなくていい　返さなくていい
潮は　満ちて　引くだけだ
返さなくていい　それでいい
明日も　網を　干すから
```

## (3) テーマ軸

海は何も返さない——だが男は、返してもらうために沖へ出るのではない。返事を待つ人間がまだ生きていることを証明するために、明日も出る。**別れでも再生でも自由でもない、「問いを畳まない執念」の歌。**

## (4) サビの核とリズム

- **核となる一節**：「返さなくていい」（8拍）
- **母音の響き**：か→え→さ→な→く→て→い→い
  「あ・え・あ・あ・う・え・**い・い**」——開いた「あ」から始まり、二つの「い」に収斂して閉じる。閉じることで「返さない／手放す」が完了せず、次の反復へ引っ張られる。
- **反復構造**：8拍 → 8拍（同型反復）→ 5拍「それでいい」へ縮小。縮むことで、諦めではなく「答えが出た」錯覚をわざと避ける。
- **定型句**：「潮は満ちて引くだけだ」（11拍）——メロディは「引く」の語で必ず音を下げる。潮の干満を旋律そのものにさせる。**上昇を一切許さない**。これがこの歌が安っぽい再生を歌わないための鉄則。

サビを語尾変化だけで3回転させ、最後の一回は「返さなくていい」の主語を「潮」から「俺」に滑らせる——**「俺は、返さなくていい」**。奪った側ではなく、待つ側に居直る。ここで初めて歌は泣くことを許される。
