## 逸脱宣言

「君の光は僕を照らす」という慰めの図式は、嘘だ。届く光は常に**すでに死んでいる**。星が死んでから光が着くまで、その間あなたはもう別人になっている。だから愛は「届かない」のではない——**届いた瞬間にはもう別の形に変質している**。この到着の遅れ・ずれこそが、愛の唯一の実体だ。届かないと知りながら手を伸ばすのは、その歪みの中にしか僕と君は存在しないからだ。

---

### (1) タイトル候補
- **『光年（ひかりとし）』**——光と、年。距離がそのまま時間になっていること。
- 『届く頃には』——サビの核そのもの。届く時点が常に遅すぎる。
- 『彗星便（すいせいびん）』——一番遅く着く郵便。手紙は、二人が死んだ後に届く。
- 『残光』——消えた星が今放つ光。

### (2) 形象と断片

**視点**: 星に手紙を書く者。光の速さで投函し、自分が消えた後に届くこと、読むのが君でないかもしれないことを承知の上で書く。

**Aメロ**
```
いま 星に 手紙を 書く
光の 速さで 届けと
着く頃 僕は いないけど
読むのは 君でも ないかも
```
（各11〜12拍。4行目で「宛先の不確かさ」まで開ける。）

**サビ**
```
光は 届く それでも
僕は 君に 届かない
届く頃には 君は もう
僕の 星を 見て いない
```

**対比・Bメロ断片**（近い光／欲しい光）
```
帰り道の 街灯は すぐ
僕まで 届く くせに
いちばん 欲しい 光だけ
何万年も かかる
```

### (3) テーマ軸（一文）
光が届く頃には送り手も受け手ももう「昔の人」に変わっている——愛は届いた瞬間に変質するもので、その到着の遅れ＝ずれこそが愛の実体であり、届かないと知りながら伸ばす手だけが僕と君を結ぶ唯一の線である。

### (4) サビ核とリズムの骨子
- **核の反復節**: 短い「光は届く」（7拍）と、それに続く「それでも僕は届かない」。サビを繰り返すたびに「届く頃には」の後の語を変えて、1番「君はもう」→ 2番「僕ももう」→ 大サビ「誰もいない」と収束させる。
- **拍数**: 4行×10〜11拍。1行目を7拍+4拍のブレスで宙に浮かせ、3行目から沈む。
- **母音の響き・脚韻**: 行末を「も(o)→い(i)→う(u)→い(i)」。2行目「届かない」と4行目「いない」の **-ai 韻** で「届かない」が歌の答えとして帰ってくる。1行目・3行目は「届く」の **u 音** で止め、光がまだ着いていない浮遊感を出す。
- **声の扱い**: 「届かない」は息で弱く、締めの「いない」は伸ばさず切る。感傷は音にせず、間（ま）に落とす。
