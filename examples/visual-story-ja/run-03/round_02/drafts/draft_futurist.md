# 草案（Futurist）

**核心的主張**
『白地図』の真の主役は灯でも澪でもなく、世界法則の一項「記録は記憶ではない」であり、その帰結である「解像度＝記憶の帳簿」という機構こそが本体である。昇華版が「帳簿機構への過剰依存」をリスクとして抑制したのは逆で、母娘の喪失ドラマは餌にすぎない。時間とともに価値が増すのは感情の叙情ではなく、全記録時代の存在論を冷徹な法として記述する文体——今は市場に見向きもされない、その文体こそが5年後の本体価値である。

**根拠**
- 生成AIは既に「訓練データの密度＝解像度」で場所を復元しており、忘れられた場所＝低解像度＝白紙という本作の法は、5年以内に隠喩ではなく視覚体制そのものの記録文学へ変わる——幻想が技術に追いつかれる、稀有な逆転が起きる。
- 世界は写真とストリートビューで飽和しながら実効的記憶は急速に薄れており、「写真・記録は解像度に一切寄与しない」という最も残酷な一項は、今は非情として捨てられ、やがて全記録時代の墓碑銘として最も引用される一行になる。
- デジタル死者復元（グリーフボット・AIの死者）が常態化するほど、「記憶も忘却も死者には届かない」という本作の拒否は陳腐化せず、技術の無謬信仰への数少ない異議として過激さを増す。

**前提**
記録技術の総量が増えるほど人間の実効的記憶は希薄になる、という逆説的趨勢がこの先も止まらない。
