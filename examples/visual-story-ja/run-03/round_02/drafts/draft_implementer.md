# 草案（Implementer・実装の観点）

**核心的主張**

この企画は世界法則を「解像度の帳簿」として設計した時点で、小説・映像として実装不能である——解像度という概念は読者に視認できず、必ず説明に転落する。実装可能な形は、会計機構を全廃し、「灯が一歩歩く→一区画が蘇る→直前のページで確立した記憶が一つ消える」という一対一交換だけを因果装置にすることである。主題「記憶も忘却も死者には届かない」は結末の台詞ではなく、全頁に張り巡らせた「交換できない財」の作動としてのみ届く。

**根拠**

- 小説は1ページ単位で注意を拘束する因果機械であり、人数×鮮明度の加算式は主人公に無限の選択肢を与えて決断の場を弛緩させ、読者が追えるのは「見える取引」だけである。
- 「娘の写真＝フォトリアル一点」は設定ではなく唯一の交換不可財＝物語の通貨であり、灯が失うものは毎ページ、直前に色を持った具体的な何かでなければ代価を読者に感じさせられない。
- 「語り直し自体が世界を塗り戻す」メタ構造とシリーズ展開（場所→時間→言語→文明）は第一巻完成前に切るべき過剰設計で、映像化可能性は「歩く・塗る・忘れる」の三動詞反復で骨が閉じているか否かのみで決まる。

**前提**

この作品は設定を楽しむファンタジーではなく、一人の女の「差し出せないもの」を目撃する叙情小説であり、読者に渡すのは世界の説明書ではなく、1ページずつ輪郭を失う灯の顔である。
