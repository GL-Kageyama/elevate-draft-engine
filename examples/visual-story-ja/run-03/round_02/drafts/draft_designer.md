# 草案（Designer改修版）— 『白地図』

**核心的主張**——《白地図》の生死は、テーマにも会計にもなく、「色が白を喰い戻す」という一文の感覚を読者の眼球と指先に実装できるかに懸かっている。世界法則は設定ではない、**文体**である。文体が法則を再現しないなら、この小説は書かれるべきではない。

---

**1) タイトル（候補＋意図）**
- **《白地図》単独**——忘れ（白）と覚え（地図）という二つの質感を二文字に圧縮し、副題で説明しない。余白がそのまま作品の余白になる。（選定）
- 《塗り戻す人》——動詞を据え、「読むこと＝塗ること」の同型を予告する。
- 《澪の色》——娘の名と世界の質感（朱・群青・黄土）を一語で結び、死んだ者の名が色として残る逆説を予告する。
- 《地図は忘れない》——覚えている主体を「人」から「場所」へ反転させ、読者の触覚を先に掴む。

**2) キャッチコピー（候補＋選定理由）**
- **「歩くたび、色が白を喰い戻す。」**（選定）——理由：本作が他と違う唯一の点は「世界の質感」であり、読者が最初に掴むべきは娘の喪失（概念）ではなく濡れた縁（感覚）。現行の「覚えているだけでは娘は戻らない」はテーマを先出ししすぎ、感覚を殺す。
- 「町は覚えられて色を持つ。私は覚えて、色を失う。」——人と場所の非対称を対句で質感化。
- 「娘の顔だけは、地図になれない。」——結末の「様式の破れ」を予告する、最も個人的な一行。

**3) あらすじ（三幕）**
- **発端**：灯は澪ノ町を歩く。覚えている範囲だけ路地が手彩色に浮かぶ——朱の鳥居、藍の暖簾、金の祭灯。境界は濡れたインクの縁で、歩くたび色が白を喰い戻す。彼女は塗り戻すたび「何か」を失うが、最初に失ったのは「失うことの自覚」で、だから彼女は気づかない。
- **転回**：二十年前、町が最初に白紙化した夜、住人たちは「皆で忘れよう」と約束した。その中心に、誰より多くを覚え、ゆえに最初に消えた「覚えすぎた者」がいた。灯は知る——復元の代価は「情景」ではなく「関係」（恋人の声、母の手、本名）だった。そして、自分が塗り戻す町の名が死んだ娘・澪の名であることに気づく。覚えても戻らず、忘れても解放されない。彼女は娘という「人」を、町という「場所」の論理で救おうとしていた。
- **結末**：灯は町を白に還す。塗り戻された世界の中央に人型の空白が穿たれる。残るのは一枚の写真——娘の顔——だけ。手彩色の地図とフォトリアルな写真、二つの様式が一枚の画面で衝突し、その「様式の破れ」が世界法則の穴として静止する。読者は「町の色は、娘ではなかった」を、説明される**前に見る**。

**4) 世界観と設定（適用と限界）**
- **適用**：法則はただ一つ。「場所は、それを覚えている者の記憶の合計の解像度でしか存在せず、忘れられた場所は白紙に戻る」。覚えられた世界＝手彩色の古地図（朱・群青・黄土、絵の具の盛り上がり、金彩の微光）、忘れられた世界＝純白の紙に薄い鉛筆グリッドのみ。境界＝濡れたインクの縁。解像度は人数×鮮明度で加算され、白紙化は低解像度の細部から進行。復元の代価は「情景」ではなく「関係」に宿る。
- **限界**：法則は場所にのみ働く。人は覚えられずとも存在する。写真・記録は解像度に一切寄与しない（記録は記憶ではない）——「ここにいた」とだけ言い、何も復元せず、何も約束しない。ゆえに写真は色と白の対立の外側に位置する唯一の様式であり、娘の顔の一点だけが地図の世界にフォトリアルの穴を穿つ。
- **Designer補強**：この法則は**文体の上にのみ成立する**。地図の場面の文章は絵の具の盛り上がりと金箔の微光を持ち、白紙の場面の文章は鉛筆グリッドの冷たさを持つ。読む速度＝色が白を喰い戻す速度。これを設定の説明で終わらせた瞬間、世界は死ぬ。

**5) 主人公（欲望・欠落・変化）**
- **欲望**：娘・澪を「取り戻す」こと——ただし町という場所の論理を通じて。
- **欠落**：灯自身は誰にも鮮明に覚えられていない。復元のたび「関係」を失い、輪郭は白紙に近づく。最初に失ったのは「失うことの自覚」。
- **変化**：最後に手放すのは娘の顔でも町でもなく、「娘の存在は私が覚えていることに依存している」という誤認そのもの。誤認を手放した後も「一枚の写真だけは残す」という非対称を引き受ける。

**6) 独自フック（一文）**
記憶ファンタジーの全系譜が「覚えるか、忘れるか」の二択を説いたのに対し、本作はその二択を読者の眼球の前で一度「塗り戻す」という身体行為に溶かし、地図と写真という相容れない二つの様式を一枚の画面で衝突させることで、「どちらを選んでも死者には届かない」を説明ではなく視覚として焼き付ける。

**7) リスクと回避**
- ① 法則が「設定」に留まり眼球に実装されない → 冒頭の一文で、論理の説明なしに「色が白を喰い戻す」映像を描き切る。説明はその後しか許さない。
- ② 二様式が絵の具の質感に甘えて「綺麗」に堕ちる → 朱・群青・黄土に記憶の温度の符号を固定し、白紙のグリッドを「冷たい線」として対置。美しさに甘えさせない。
- ③ 「人型の空白」がテーマの説明に落ちる → 空白を語らず、静止画として最後に置き、読者が見てから理解する順序を守る。

**8) シリーズ展開（各巻の軸）**
単位と「様式」を同時に拡張する。第1巻・**場所**（解像度＝色、手彩色 vs 白紙）→ 第2巻・**時間**（解像度＝質感、覚えられた時間だけが触れる）→ 第3巻・**言語**（解像度＝音、覚えられた言葉だけが声を持つ）→ 第4巻・**文明**（解像度＝光、覚えられた文明だけが照らされる）。毎巻の底に「人の死」——その単位の論理の及ばない事実——を据え、法則の外に「人」がいることを反復する。

**9) 想定読者（属性と共感点）**
- **属性**：物語の「意味」より「手触り」を先に掴む読者。手彩色の古地図・銀塩写真・絵の具の盛り上がりといった「物質の記憶」に体が反応する人。郷愁を無条件に信じないが、郷愁の質感（色・音・温度）には体が覚えている人。
- **共感点**：「誰かを抱えている」ことの重みと、「抱えるものの解像度が自分自身を削っていく」という非対称。覚えていることの重圧と忘れることの罪悪感を、同じ一枚の画面の表裏として見る感覚。
