# 構想家（ビジョナリー）草案

## 1) 核心的主張

「忘れられた場所は白紙に戻る」を、消滅ではなく**解放**と読め——白紙こそ場所の原初にして唯一の「本物」であり、記憶とは場所の上に他人の像を塗りつける捏造である。ならば灯が澪ノ町を塗り戻すのは愛ではなく、娘を「忘れれば消える場所」へ固定し続ける加害であり、塗るほど本物の町と娘は遠ざかる。この物語の終局は復元の完成ではなく**塗る手を止めること**であり、それは「覚え続けることが愛だ」という死者祭祀の人類的前提そのものを裏切る。

## 2) 根拠

- 世界法則は「記憶が場所を作る」のではなく「記憶が場所を覆う」のであり、解像度が上がるほど復元物は皆の記憶の平均像＝偽造品へ収斂し、本物から遠ざかる。
- 町が娘の名を冠するのは、娘が「人」から「場所」へ変換された証であり、場所にされた者はその瞬間から「忘れられれば消えるもの」になる——愛は相手を消し得るものへ変える殺人へと反転する。
- 「顔だけは差し出さない」灯の固執こそ娘を地図の一点に釘付けにし続ける行為であり、死者への唯一の愛は、覚え続けることではなく、何も残さず塗る手を止めることである。

## 3) 前提

場所は誰かに覚えられる以前に固有の存在を持ち、記憶はそれを損なうのみである、という形而上学に依拠する。
