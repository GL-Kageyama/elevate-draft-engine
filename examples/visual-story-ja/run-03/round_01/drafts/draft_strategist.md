# 草案：《白地図》—— Strategist の視点

**核心的主張**
《白地図》をファンタジーとして売るな。この物語の買い手はファンタジー読者ではなく、認知症・介護の当事者とその家族——日本の老老介護・認認介護という膨張し続ける市場だ。「場所は記憶の合計の解像度でしか存在しない」という法則は彼らにとって幻想ではなく、親が忘れていく現実そのものの直喩である。したがって販売軸は「涙」ではなく「承認」——介護で自分を削る者に「その削り取りは美しい」と名指す物語は、現在の文芸・エンタメ市場に一切存在しない。ここに独占的な席がある。

**根拠**
- 40〜70代女性は日本の書籍購買の最大の塊であり、同時に介護の第一当事者——需要と購買力が同じ人物に重なる、稀有な一致市場である。
- 「歩くたび色が白を喰い戻す」という作動は、高精細CGより手彩色テクスチャのほうが安価に美しく映像化でき、アニメ・実写化の制作費対効果で競合に構造的に勝てる。
- 「忘れられた下町の復元」は実在のシャッター街・過疎商店街の活性化事業と構造が一致し、自治体タイアップという他作品にない収益ラインを開く。

**前提**
買い手は「幻想の新奇さ」にではなく、「自分自身の記憶の映像化」に金を払う。

---

**タイトル候補**
1. 《白地図》— 文芸棚と終活・介護棚のどちらにも置ける無色の中立性が強み。現行維持の最良解。
2. 《あなたを覚えている》— 認知症介護の現場で最も言われない台詞の商品化。贈答（親へ・介護者へ）動機を直接誘発する。
3. 《塗り戻す》— 「守る＝削られる」という購買動機の動詞化。当事者への最短距離だが、陳腐化リスクあり。

**キャッチコピー**
- 候補A:「忘れられていく人のぶんだけ、覚えている人が白くなっていく——それでも、あなたは塗り戻す。」（**選定理由**: 介護の代償構造を購買層の罪悪感に直結し、物語を「買うこと＝自分の経験の承認」にする。涙でなく承認を売るため。）
- 候補B:「この町は、覚えている者の記憶の解像度でしか、存在できない。」（没。世界法則の説明に過ぎず、購買動機にならない。）

**あらすじ（三幕）**
- 発端: 下町・澪ノ町が加速的に白紙化する中、唯一町を覚える灯が、歩いて思い出すたび店・路地・祭の音を彩色して蘇らせる——そのたび自分の記憶（恋人の声・母の手・本名）を差し出す。
- 転回: 町が最初に白紙化した二十年前の「皆で忘れようと約束した事件」を追うほど、復元と自己消滅が同一直線上にあると判明。中心に「覚えすぎて最初に消えた者」がいる。
- 結末: 灯は娘の顔の記憶だけは差し出さずに最後の一区画を塗り戻す——復元の完成と引き換えに、世界には「自分自身」の白い人型の穴だけが残る。

**世界観と設定（適用と限界）**
- 適用: 場所は「覚えている者の記憶の合計の解像度」で存在。覚えられた分＝手彩色（朱・群青・黄土、金彩の微光）、忘れられた分＝純白＋鉛筆グリッド。境界は「濡れたインクの縁」として動く。
- 限界①: 世界を支えるのは記憶の「量（合計の解像度）」であって「真偽」ではない——大勢の薄い記憶より、一人の濃い記憶のほうが町を鮮明にする。
- 限界②: 記憶が他人と共有されない私的なものに留まる限り、場所は公共の世界では白紙のまま＝一人の内面にしか存在しない。フォトリアルな「娘の顔の写真」はこの法則の穴（共有されずに存在し続ける唯一の像）であり、彼女の固執そのもの。

**主人公（欲望・欠落・変化）**
- 欲望: 消えかけた澪ノ町を最後の一区画まで塗り戻し、忘れ去られる者たちの存在を世界に留める。
- 欠落: 塗り戻すたびに自分の記憶（声・手・本名）を差し出し、自身の輪郭が白紙に近づく。
- 変化: 「全てを覚えて守る」から「娘の顔だけは守るため、復元を完成させない」へ——守る対象を町（外部）から愛（内面）へ逆転させる。

**独自フック（一文）**
認知症・介護という市場最大の語られない痛みに、「場所は記憶の解像度でしか存在しない」という幻想の形を与え、読者一人ひとりの記憶を自動着色する変換器になっている点——世界観が読者ごとに異なる像を結ぶ、唯一の物語。

**リスクと回避**
- 破綻①: 「美しい介護賛歌」に回収され、当事者の現実の苦痛を矮小化して背信・炎上。→ 代償の消失を感傷でなく「痛み」として冷徹に描き、結末を人型の空白（未回収の喪失）にする。美しさと残酷さを同居させ、感動商法に落とさない。
- 破綻②: 棚割りの谷間——ファンタジー棚では介護層に届かず、終活棚ではファンタジー層が逃げる。→ 売り場を「文芸棚と介護・終活棚の境界」に据え、装幀・帯を両方に読める二重表記にする。これは棚の奪い合いではなく、唯一その境界に立てる商品としての独占。

**シリーズ展開（各巻の軸）**
- 形式: 連作（各巻独立・どの巻からでも読める）——ターゲットの介護当事者はシリーズを追わない。単巻で完結し贈答しやすい形式こそ市場に合う。
- 1巻《白地図》: 復元の代価。灯と澪ノ町。誰かのために覚える＝自分の何かを忘れる構造の提示。
- 2巻《忘れる者たちの街》: 「忘れようと約束した事件」の全貌と、忘れることで得をする者の経済を描く。
- 3巻《覚えすぎた者の地図》: 最初に消えた「覚えすぎた者」が、自分を覚える者を探して白紙の街を歩く。記憶される側の苦痛＝法則の裏面。

**想定読者**
- 属性: 40〜70代女性、介護当事者・経験者、終活・家族小説層。書籍購買力と介護の第一当事者が同一人物に重なる、需要と購買力の一致した塊。
- 共感点: 「大切な人のために自分を削り続ける」経験の承認——この物語がその削り取りを「美しい」と名指すこと自体が、罪悪感の救済として購入動機になる。
