# Designer草案——《白地図》

**核心的主張**
《白地図》は「読む」物語ではなく、指先で触れる一枚の紙である。物語・人物・感情のすべてを「手彩色の顔料」と「純白の紙」という二つの素材のどちらに属するかだけに還元し、その境目の触感——絵の具の盛り上がり、乳剤の膜、濡れた縁の冷たさ——が唯一の語り手であれ。この企画の成否はプロットの巧拙ではなく、ページをめくるたびに「色が白を喰い戻す」質感を読者の指が確かめられるか、ただ一点にかかる。

**根拠**
- 世界法則は視覚＝触覚の物理（記憶の解像度＝顔料の密度）であり、地の文に「思い出す」と書くより「朱が滲む」と書くことが、この法則の唯一の正しい翻訳だから。
- タイトル・キャッチ・キャラ名（白地図・灯・澪ノ町）は既に紙の素材系で統一されており、これを物語的比喩へ逃がした瞬間、世界の手触りが死ぬから。
- 独自フックは「忘れると白紙」という設定ではなく、白と色の境界を紙の繊維レベルで描く、他作品が決して持てない質感の一貫性にのみ宿るから。

**前提**
読者の涙は「悲しい」からではなく「紙が冷たい」から流れる——感情の説明より触覚の伝達を信じる、という前提。
