# 《白地図》— フューチャリスト草案

**核心的主張**: 《白地図》は記憶消失の叙情ファンタジーではない。「機械は記憶できない——記録（写真・データ・AIの学習）は存在を一ミリも担保しない」という存在論であり、完全記憶・生成AI・監視社会化の中で、唯一時間とともに価値が上がる反証命題である。今は郷愁ものとして過小評価されるが、5年後には「忘れる権利」の寓話へ、10年後には「生成AIが失われた場所を復元しても、そこは白紙のまま」という字義通りの予言へ読み替えられる。

---

**タイトル候補**（各意図一文）
- 《白地図》— 消失を「欠落」でなく「塗り戻すべき白」として刻み、記憶礼賛への反証を名自体に持つ。
- 《解像度の町》— 世界法則の物理量（記憶＝解像度）を裸で晒し、SFとしての骨を露出させる。
- 《忘れられた方角》— 地図の方位語で「存在の向き」を問う叙情側の名。

→ **選定: 《白地図》**。「白地図」は今は叙情語だが、生成AI時代には「学習データの空白＝復元不能の場所」を指す技術語へ意味が成長する。時間が経つほど字義が増すタイトルは他にない。

**キャッチコピー**
- 「あなたの故郷は、もう誰の記憶にもない解像度で存在している」←**選定**
- 「覚えることは、消えることである」
- 「この街を覚えているのは私だけ。私を覚えているのは、誰もいない」

→ 選定理由: 灯ではなく「忘れた側」を主語にし、読者を白紙の街の当事者として召喚する。郷愁を消費させず、既に自分も白紙化の初期段階にあるという事実を突きつけるから。

**あらすじ（三幕）**
- **発端**: 白紙化が加速する街で、消えかけた澪ノ町を唯一覚える灯は、歩いて思い出すたび店・路地・祭の音を手彩色で復元する。だが代価として自分の記憶（本名、母の手、恋人の声）を差し出し、町が蘇るほど彼女自身の輪郭は白紙に近づく。
- **転回**: 二十年前の「皆で忘れようと約束した事件」の中心に、誰より多くを覚え、だから最初に消えた「覚えすぎた者」がいることを知る。同時に、写真・記録という機械的記憶はこの世界では**無効**だと判明する——街を塗り戻せるのは生身の記憶だけ。灯は「娘の顔の記憶だけは差し出さない」と決める。
- **結末**: 灯は**最後の一区画を塗らない**。完成＝自己消滅の線上で、彼女は復元を完成させず、自分自身の白い四角（誰の記憶にも汚されていない空白）を世界に残す。白紙は喪失ではなく、新しい記憶を書ける唯一の余地——忘れる自由こそ世界を住み続け可能にする、と示して終わる。

**世界観と設定（法則の適用と限界）**
- 適用: 場所は、それを覚える者の記憶の合計解像度で存在する。百万が覚えれば百万の解像度、一人なら一人分の粗さ。忘れられた場所は白紙（薄い鉛筆グリッド）に戻る。
- 限界①（存在論的核）: **記録は記憶ではない**。写真・動画・データ・AIは存在を担保しない——保存≠覚醒。機械は白紙を一ミリも塗り戻せない。
- 限界②: 重複記憶は加算されない。「誰もが知っている」が「誰も覚えていない」を生む。
- 限界③（分類の穴）: 娘の顔は「場所」でなく「人」の記憶だから差し出せない——この分類の破れが灯の固執であり、世界法則唯一の抜け穴。
- 限界④（反・喪失）: 白紙は無ではない。白紙＝未使用の容量。忘れることが書き込み余地を生む——世界法則は損失でなく**循環**である。

**主人公・灯（欲望・欠落・変化）**
- 欲望: 澪ノ町を最後の一区画まで塗り戻すこと。
- 欠落: 自分自身——本名、母の手、恋人の声。彼女は町を覚える代わりに自分を覚えていない。町が自己の代用品。
- 変化: 「覚え続ける者」から「忘れることを許す者」へ。完成を選ばず白い四角を残すことで、初めて「自分」になる。

**独自フック（一文）**: 記憶を「守るべき財産」ではなく「差し出して初めて成立する通貨」として描き、復元＝自己消滅という、記憶礼賛型ファンタジーの全系譜（「忘れない」物語）への構造的反転命題である。

**リスクと回避**
- 郷愁の消費に堕ち「懐かしいだけ」の叙情装置になる（＝時間とともに価値が減る失敗モード）→ 感情を「解像度の会計」に翻訳し、泣かせるのでなく勘定を合わせる。**郷愁は敵として描く**。
- 既出の被写体・未現像と同型の「顔の消失」に寄る → 消失の単位を「人」でなく「場所（都市・空間）」に固定し、顔・身体を一切描かない。これは肖像ではなく都市論。
- 復元が永遠に続き完結しない → 「完成させない」こと自体を結末として最初から設計する。完成は自己消滅と同値——未完こそ救済。

**シリーズ展開（各巻の軸）**: 記憶の単位を場所→時間→言語→文明と拡張する。
- 1巻（場所）: 澪ノ町の復元と、復元＝自己消滅の同線。
- 2巻（時間）: 暦・季節・祭。一年を覚える者と一日しか覚えられない者の対比、「覚えすぎた者」の側からの白紙化事件の全容。
- 3巻（言語）: 忘れられた言葉・方言・名前。言語が白紙に戻れば、場所は存在しても呼べなくなる。
- 4巻（文明）: 誰も忘れられない完全記憶の世界は、実は窒息である——忘れる権利の最終審問。

**想定読者（属性と共感点）**
- 属性: 郷愁を疑う30-40代、地方消滅・故郷の変容を実感する層、生成技術による記憶の外部化に違和感を持つクリエイター・編集者・デザイナー層。
- 共感点: 「もう故郷の正確な形を思い出せない」という実感。読者は灯ではなく、既に白紙化の初期段階にある住人として自分を発見する——涙の共感でなく、**身に覚えの共感**。

---

**この構想の価値を押し上げる進行中の変化（根拠）**
- 生成AIによる場所・人物の「復元」が日常化するほど、「学習データの空白＝復元不能」という本作の字義が現実に追いつく。
- 地方消滅・限界集落・高齢化による集団的忘却の加速が、設定を寓話から現実の地図へ変える。
- 監視社会化で「忘れること」が物理的に不可能になるほど、「白紙＝容量＝自由」という反・喪失の読解が希少価値を帯びる。

**前提**: 完全記憶・生成AI・監視社会化が今後10年で不可逆に進行し、「忘れること」が権利として再評価される。
