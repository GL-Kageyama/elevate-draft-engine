# 出力形式（OutputFormat）

- 成果物種別: 小説企画書
- 説明: 《白地図》を一つの作品に絞り、そのまま執筆・映像化に移せる完成度で、指定された全項目が具体的かつ一貫した企画書として成立していること。
- 出力長の範囲: 1800〜4000 字
- 成果物そのもの: いいえ（成果物についての分析）

## 草案の形式指示（draft_guidance）

各草案執筆者は、与えられた止揚の基盤（「場所は、それを覚えている者の記憶の合計の解像度でしか存在せず、忘れられた場所は白紙に戻る」という記憶×消失の世界法則）だけを材料とし、材料を超えた推論を加えずに、企画書の構成要素を断片として具体化せよ。タイトルは候補を複数挙げ各候補の意図を一文で添え、キャッチコピーは候補＋選定理由、あらすじは三幕の骨子（発端・転回・結末）、世界観と設定は上記法則の適用と限界を記述、主人公は欲望・欠落・変化の三要素、独自フックは他作品と差別化される点を一文、リスクと回避は想定される破綻とその対処、シリーズ展開は各巻の軸、想定読者は属性と共感点をそれぞれ明示すること。

## 最終化の形式指示（finalize_guidance）

最終成果物は「小説企画書」形式の本文で、以下の見出しをこの順に全て含めよ。1) タイトル（確定1案） 2) キャッチコピー 3) あらすじ 4) 世界観と設定 5) 主人公 6) 独自フック 7) リスクと回避 8) シリーズ展開 9) 想定読者。汎用の Target/Value/Risk/Opportunity は、それぞれ「想定読者（Target）／独自フック＝作品の価値（Value）／リスクと回避（Risk）／シリーズ展開＝市場機会（Opportunity）」に対応させる。各節は止揚の基盤である「記憶の合計の解像度」と「忘れられた場所は白紙に戻る」という法則に一貫して紐づけ、基盤に無い設定（魔法体系の拡張・新たな世界法則など）を勝手に付け足さないこと。タイトル・キャッチコピー・あらすじ・世界観・主人公・フックの間に矛盾がなく、読者が企画書だけで作品の映像を想起できる明瞭さを保つこと。
