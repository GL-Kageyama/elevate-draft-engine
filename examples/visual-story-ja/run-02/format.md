# 出力形式（OutputFormat）

- 成果物種別: 小説企画書
- 説明: 「未現像」一作品を、そのまま執筆・映像化へ移せる完成度で具体化した、タイトルから想定読者までの全要素を網羅した小説企画書。
- 出力長の範囲: 2500〜7000 字
- 成果物そのもの: いいえ（成果物についての分析）

## 草案の形式指示（draft_guidance）

創作系の企画書のため、個々の草案執筆者は作品の「断片と骨子」を提出せよ。具体的には、(1) タイトル候補とその含意、(2) キャッチコピーの候補と狙い、(3) あらすじ（起承転結と核心のどんでん返し）、(4) 世界観と設定——特に「撮られなかった瞬間こそ未露光フィルムに最も真実の像として現像される」という世界法則の運用ルール・限界・代償、(5) 主人公の人物像・内面葛藤・動機、(6) 独自フックの具体例を示すこと。提示された止揚の基盤（暗室×記憶の犯罪サスペンス、世界法則）を超えた新設定は付け加えず、与えられた材料を過不足なく具体化すること。

## 最終化の形式指示（finalize_guidance）

最終成果物は一作品に絞った企画書とし、以下の見出しを必ずこの順で持たせよ。各節は箇条書きでなく具体性のある本文で書き、汎用の Target/Value/Risk/Opportunity の枠組みは以下の構造に置き換えること。1) タイトル（決定案1本＋読み・意味）、2) キャッチコピー（1本＋意図説明）、3) あらすじ（読み手を惹き込み核心の真相に触れる起承転結）、4) 世界観と設定（世界法則の定義・発動条件・限界・代償・暗室の意味）、5) 主人公（属性・内面葛藤・物語を通じた変化）、6) 独自フック（この作品だけの差別化点と読者を引き込む仕掛け）、7) リスクと回避（設定破綻・陳腐化等のリスクとその回避策）、8) シリーズ展開（続編・映像化を見据えた拡張性）、9) 想定読者（具体的な読者層と訴求理由）。
