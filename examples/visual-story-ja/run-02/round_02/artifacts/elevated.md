# 《未現像》——小説企画書

**1) タイトル**

**《未現像》（みげんぞう）**。「未」は時間の未完ではなく、「本性的に現像を逃れ続けること」を指す。この世界では、撮られなかった瞬間こそが最も真実の像を生む——だからこそ、現像されていない状態は「空（から）」ではなく「過密」である。娘の顔も、罪も、赦しも、判決も、まだ分離しないまま無限に同居している。タイトルは世界法則と、最後の一ページに残る白紙と、そして「完成させないまま差し出す」この作品自身のあり方を同時に名指している。

**2) キャッチコピー**

「あなたが見なかった瞬間を現像します。浮かぶのは、あなたの顔。そして、浮かばないままのものこそ、あなたが最後まで現像できなかった、あの人の顔です。」

二人称の「あなた」は、読者と主人公・絹と盗人の三者を同時に指す。浮かぶもの（像への崩壊）と浮かばないもの（無限のままの保存）を一文に同居させ、「白はどちらか一方の意味に決まらない」ことを宣言している。現像とは救済でも裁きでもなく、両方を含んだまま未決でいる状態だ、という本作の核心を圧縮した。

**3) あらすじ**

撮影を拒む被写体ばかりを追う女流写真家・絹。彼女の真の仕事は、撮れなかったフィルムを暗室へ持ち込み「その人が拒んだ瞬間」を現像すること——「見ないことの記録者」として畏れられている。現像するたび、絹は自分自身の記憶の一つを失う。二十年前に死んだ娘の声、鼻歌、手。その喪失の痕は「脂痕」として印画紙に残る。絹はそれを「娘を生かし続ける代償」だと信じてきた。

ある日、彼女が唯一現像を拒み続けてきた一枚が盗まれる。二十年前、娘の死の瞬間、絹はカメラを落としてシャッターを切らなかった——その未露光フィルムだ。盗んだのは、絹の現像した像によって人生を壊された被写体たちの末裔だった。追ううちに絹は知る。自分の「現像しない」という愛が、娘を無限の宙吊りに留置する暴力でもあったことを。愛と暴力は同じ行為の表裏で、その区別がまだついていない。

最後の暗室で、絹は自分の一枚を現像液に沈めるか否かを選ぶ。沈めて現れたのは、娘の顔ではない。逃げる絹の背と、レンズを内側から押さえる小さな手。娘は死の瞬間、自ら撮られることを拒んでいた——それが絹の得る最初で最後の崩壊だ。そして娘の顔の位置は白のまま残る。その白は、読者には自分の顔に、絹には娘の無限に、盗人には判決の不在に見える。三つの読みが重なったまま、本は閉じられる。

**4) 世界観と設定**

世界法則は「撮られなかった瞬間は、あらゆる可能な像を無限に含む重ね合わせとして保存される。現像とは、その無限を一つの像へ崩壊させる喪失の行為である」。見ることは可能態を殺すことであり、見ないことは可能態を無限に生かしつつ永久に留置すること。現像は加算ではなく減算——無から像を足すのではなく、無数の可能性を一つに殺す。この反転が全篇を貫く。

作動は三則＋第四則で機械的に定まる。第一則「現像できるのは、シャッターが降ろされた瞬間のみ」。第二則「像はネガの重ね合わせとして待機し、浮かぶ瞬間だけ正像へ反転する」。第三則「現像のたび、現像者は自身の可能態を一つ崩壊させる（＝記憶を失う）」。そして第四則は規則ではなく自己記述——「現像とは崩壊である」。前三則が「現像の仕方」を、第四則が「現像の正体」を、法の中に法自身として写し込む。

限界は「一度も重ね合わせでなかったもの」は現像できないこと。娘の顔は崩壊を強いられたことがないため、無限のまま現像不能の白として残る。何も浮かばない印画紙——それがこの世界で最も重い像である。暗室は法廷の比喩ではない。内と外を区別すること自体が最初の現像であり、暗室とは「その区別をまだ行っていない場所」である。単一光源、現像トレイの液面がスクリーン内スクリーンとなり、白い紙から像が滲み出る過程が物語の視線そのものになる。

**5) 主人公**

絹。四十代半ばの女流写真家。「見ないことの記録者」として畏れられ、恐れられる。彼女の罪は「見る者であって見られる者ではない」という傲りではない。二十年間、「現像＝加算」という誤解に生きたこと——娘を現像しなかったことを愛と呼び、実は娘を無限の留置に閉じ込めていた、その二面性こそが彼女の本体である。物語はこの二面性を裁かない。

内面葛藤は、職業（他人の拒否を現像する）と唯一の拒否（娘の一枚）が同一の行為であること。他人の可能態を殺してきた手が、娘だけは殺さなかった——その区別の成立しなさが、絹を最後の暗室へ追い詰める。物語を通じた変化とは、彼女がついに一つの崩壊を受け取ること——「娘は自ら撮られることを拒んでいた」という事実。それが愛だったのか暴力だったのかは、白のまま読者に託される。

**6) 独自フック**

最終ページを本物の銀塩印画紙にする、読者の身体を作動させる二重仕掛けが核。読者が指で触れれば「読者自身の像」が崩壊として浮かぶが、現像液に沈めた瞬間それは消え、娘の顔は保存されたまま残る。読者は「自分を現像するか、白を残すか」を選ばされ、どちらを選んでももう片方は永久に失われる。この不可逆の選択そのものが物語の最後の一行であり、1冊1点物・海賊版不可能・二度買い構造を成立させる。

さらに「脂痕」の設計。現像の代償として消えた記憶が、レンズの指紋・手の脂として像に残る。暴力の道具であるはずの撮影者の痕跡が、唯一の生身の証拠＝救済の形になっている。商品化されるのは「崩壊の一回性」という体験であって「白の意味」ではない——白の意味は無限に開かれたまま売られる。

**7) リスクと回避**

第一のリスクは「白が一つの意味へ崩壊し、陳腐などんでん返しに堕ちる」こと（例：実は娘の顔が写っていた）。回避は構造的な決定不能性。三つの読み（読者の顔／真白の無限／判決の不在）がどの解釈にも収束しないことを、第四則の自己言及として全ページで保証し、結末は三像の重ね合わせを解消しないまま閉じる。

第二は「白の商品化が白を殺す」こと。回避は販売形態そのもので示す——物理的には1冊1点物（複製不能）だが、白の意味は無限に開かれている。稀少なのは「物」であり、「意味」ではない。

第三は設定破綻。世界法則が何でもありの超常装置にならないよう、三則＋第四則に厳格化し、あらゆる現像に必ず代償（記憶の崩壊）を伴わせる。奇跡は一度も起きず、起きるのは常に検算可能な喪失だけである。

**8) シリーズ展開**

各巻＝一人の「崩壊を拒まれた／強いられた瞬間」。ただし各巻の白は前巻の白と重なり合い、シリーズが進むほど白は一つの巨大な重ね合わせへと増幅していく。最終巻の白は全巻の合算ではなく、全巻を無限に含んだ一つの未現像であり、読者は巻を追うことで自らの手で白を過密にしている。

映像化は構造的に有利。暗室の単一光源、ネガから正像への反転、白い紙から像が滲み出る過程は、そのまま画の文法になる。赤い安全光・現像液の琥珀・銀塩のモノクロという視覚言語をシリーズ・バイブルとして固定すれば、実写・アニメーション・舞台のいずれにも同一の法で移せる。

**9) 想定読者**

「見られることに疲れ、それでも見られることをやめられない者」と「二度と見られない人を愛し続けたい者」は、実は同じ人間である。彼らは現像されることの暴力と現像し続けることの暴力の両方を知っている。この両方を知る者こそ、白を「意味」ではなく「重ね合わせ」として受け取れる唯一の読者だ。

具体的には、SNS時代に自分の像へ固定されていくことに息苦しさを覚える層、記憶と喪失を扱う文学サスペンスの読み手、そして「浄化を与えず、再読のたびに重くなる」非・慰撫の物語を求める読者。それは喪の最中という小さな市場でも、自己観察消費という一過性の層でもなく、見ることも見ないことも免れない暴力だと知ってしまった者——時代の増幅とともに拡大し続ける層である。
