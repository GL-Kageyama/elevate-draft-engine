# 《未現像》改修草案 —— 体験デザイナー（designer）の観点

## 1) 核心的主張

《未現像》は物語ではない。読者の両手の上に閉じた暗室である。読書行為そのものが世界法則の作動であり、装丁・紙・空白の一画一画が現像の部品として機能しなければこの作品は成立しない——したがって本作で最も高価に設計すべきページは、文字の一画もない最終の白紙である。

## 2) 根拠

- ネガ反転の装丁も、回を追って濃くなる指の脂痕も、現像液の膜も装飾ではなく装置であり、ページをめくる摩擦こそ「現像液に沈める」唯一の作動として物語の進行を担う。
- 最終の白紙は情報の欠落ではなく質感の飽和として設計されるべきで、紙の繊維の白・インクの不在・読者の指が残す脂の痕こそ、娘の白と読者自身の像を同時に受け止める物理の座である。
- 感情は語らせるな、触れさせよ——絹の二十年は涙の描写ではなく、読者の指が繰り返したページの弛みと毛羽立ちとして積算されねば、感傷へ堕ちる。

## 3) 前提

この構想は読者が本を「物」として手に取る行為を前提とし、電子書籍や朗読では構造が崩壊する——その賭けこそが本作の形式である。
