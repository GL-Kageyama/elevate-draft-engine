# 《未現像》の主役は読者である——本作が語り継がれるのは「告白」という形式としてである

**核心的主張**
この作品の主役は、絹でも盗まれたフィルムでもなく、白紙の座に自分の顔を見る読者である。だから語り継がれるのは「暗室×記憶の犯罪サスペンス」というあらすじではなく、読み終えた者が「あの白紙、俺には母の手が見えた」と自分の言葉で告白する私小説の連鎖である。この告白はネタバレで毀損せず、「お前は何を見たか」と次の読者を現像する儀式として増殖する——本作が人に売る物語は絹の二十年ではなく、読者自身の「現像を拒んできた一枚」の所有権である。

**根拠**
- 白紙の座を読者に宛てる構造は、読む動作を「現像する」儀式へ変え、読後感を「解釈」から「自己暴露」へずらすため、感想は必ず一人称の告白という形式を取る。
- 「複製は愛の形であり、最も残酷な匿名化である」という主題は、SNSで像として見られる暴力を肌で知る20〜40代に「あれは私だった」と受理され、他人の感想ではなく自分の経験として転写されていく。
- 第四則（誰かのために向けられた拒否は相手の像を生む）は、読者に「私が誰を守るために現像を拒んできたか」を遡らせ、本を閉じた後に作中の誰でもない自分の一枚を語らせる仕掛けになっている。

**前提**
この拡散経路は、読者が白紙に耐えうる喪失——物語の消費者ではなく、すでに隠している何かを持つ者であること——を前提とする。
