# 《未現像》改修草案（構想家・Visionary）

## 1) 核心的主張

前回の昇華版はなお、無意識の前提を温存している——「見る者（絹＝現像する者）と見られる者（娘＝被写体）」が別の人間だという前提だ。だがこの世界法則が本当に暴くのは、その分離こそ最大の虚構であること。**「現像する」行為の主体と、「現像される」像の客体は、同一人物である。** ゆえに絹が二十年、娘の一枚を現像しなかったのは愛でも保護でもなく、彼女自身を「喪失を選ばなかった母」という像へ、最も長く露光し続けた自己現像だった。そして読者もまた、物語を現像していると信じるその瞬間に、物語によって現像されている——暗室の外に立つ者など、この世界には一人もいない。

## 2) 根拠

- 第三則（撮影者の痕跡）は「撮る者」も毎回フレームに焼き付くことを定めており、見る暴力の加害者である絹は最初から被写体だった。
- 第四則は「隠す自己のない純粋な拒否は拒否した者の像を生まない」——これは法の穴ではなく、むしろ法の完成形であり、「見ない」が娘を守ったのではなく絹を現像したことの証明である。
- 二人称の語り手（＝フィルム）は冒頭から「あなたが現像している」と読者を主語に据えており、最終の白紙は読者の顔が「待っている」のではなく、読者がすでに現像されてしまった跡である。

## 3) 前提

人間は「見る側」と「見られる側」に分かたれ、少なくとも一方に留まることができる——という、私たちが自己理解の足場にしてきた暗黙の前提そのものを、この物語は被写体として現像にかける。
