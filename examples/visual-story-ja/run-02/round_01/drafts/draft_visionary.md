# 《未現像》構想草案 —— 構想家（Visionary）

**核心的主張**

写真とは「撮れた像に真実が宿る」という、人類が二世紀信じた前提を、この世界法則は根底から反転する。撮られなかった瞬間こそ最も真実の像として現像されるなら、被写体とは撮られた者ではなく撮ることを拒んだ者であり、あらゆる像の真の主題は結局「見た者」自身である。よって本作のどんでん返しは一点に絞る——絹が二十年現像を拒んだ一枚に映るのは死んだ娘ではない。カメラを落としてシャッターを切らなかった、絹自身の顔である。「撮らなかった」という行為が最も鮮明な自画像になる、というこの反転こそ、読者の自己理解を揺さぶる核だ。

**前提（暗黙の仮定）**：絹自身も盗んだ者たちも「あのフィルムには娘の死の真実が映っている」と信じている。その信仰こそが全員の誤認であり、世界法則はそれを裏切る。

**根拠**
- 世界法則を論理の果てまで押せば、「撮られなかった瞬間」の真実とは「撮られなかったという事態」であり、それは被写体ではなく撮影者の拒否行為そのもの以外にありえない。
- テーマ「見ることも見ないことも免れない暴力」の完全な実装は、見る者＝絹が最終コマで自ら被写体へ反転する構造でしか成立しない。
- 絹が他者の拒否を二十年現像してきたのに自分の一枚だけを拒む矛盾は、彼女の正体が「世界で最も未現像な人間＝純粋なネガ」であることでしか解けない。

---

**1. タイトル候補**
- 《未現像》——未だ現像されないもの。潜像（latent image）としての絹、娘の死、そして「見ないこと」そのもの。主案。
- 《白い像》——現像液に沈めても何も染み出さない白。空白こそ最も重い像、という世界法則の穴をそのまま題名にする対案。

**2. キャッチコピー**
- 主案：「シャッターを切らなかった。それが、一番残酷なシャッターだった。」
- 対案：「見ないことは、あなたを最も見ている。」
- 狙い：読者自身の「見る／見ない」日常が告発される予感を一行で仕掛ける。

**3. あらすじ（起承転結＋どんでん返し）**
- 起：絹は撮影を拒む被写体ばかりを撮る女流写真家。本業は撮れなかったフィルムを暗室で現像し「拒まれた瞬間」を真実の像にする、見ないことの記録者。畏れられ、同時に必要とされる。
- 承：彼女の未現像フィルムが盗まれる。それは彼女自身が唯一二十年現像を拒んできた一枚——娘の死の瞬間、カメラを落とし、シャッターを切らなかったフィルム。
- 転：盗んだのは、絹が現像した像に人生を壊された被写体たちの末裔。要求は「お前自身の一枚を現像し、娘の死の真実を像にせよ」。見ることを強要する者たちに、絹は最後の暗室へ追い詰められる。
- 結＋どんでん返し：現像液に沈めた紙に浮かぶのは娘の姿ではない。レンズに脂の痕として残った絹自身の指先、カメラを落とした彼女自身の顔。世界法則は「撮られなかった瞬間」を現像する。娘の死は映らない——映るのは、それを撮らなかった者の像である。見ることも見ないことも免れない暴力。絹は自分の一枚を現像した瞬間、初めて被写体になる。

**4. 世界観と設定（運用ルール・限界・代償）**
- 運用ルール：露光されなかったコマ——シャッターを降ろした、被写体が拒んだ、カメラが落ちた——だけが未露光フィルムに最も真実の像として現像される。像はネガ（白黒反転）のまま待機し、誰かが見た瞬間に正像へ反転する。現像トレイの液面＝スクリーン内スクリーン。
- 限界：一度もレンズを向けられなかった瞬間には潜像は生まれない。撮る意思が向き、シャッターが切られなかった「拒否」だけが真実になる。そして現像された像は覆せない——像になった瞬間、その人の他の可能性はすべて消える。
- 代償：他者の拒否を現像するたび、絹は「被写体にならなかった」側から「被写体にした」側へ一人分ずつ寄る。彼女は常にカメラを持つ者だったから、自分だけが一度も「撮られなかった瞬間」を持たない、世界で最も未現像な人間——純粋なネガである。娘の一枚は、彼女が唯一被写体になり損ねた瞬間の記録であり、つまり彼女自身の最後の「自分」である。

**5. 主人公**
- 絹（きぬ）。他者の拒否を現像して恐怖と需要の両方を得る女流写真家。動機は支配——見ることを暴力的に掌握することで、自分が「娘を見なかった」過去から目を逸らす。内面葛藤は「世界で最も見抜く者でありながら、自分自身だけは現像できない」という矛盾。記録者であることに自己を預けてきたが、物語の果てにその記録者性こそが最も残酷な被写体性だったと知る。

**6. 独自フックの具体例**
- 冒頭：依頼人が「撮影を拒んだ被写体」の一枚を絹に現像させると、映ったのは被写体が隠していた犯罪の瞬間。拒否は保護ではなく自白である、と世界が即座に立証される。
- 進行：像はネガで待機し、読者の視線で正像へ反転する演出——見ることが物語の進行そのものになる。液面がスクリーン、読者の目が現像液。
- 終盤：絹の一枚が現像され、娘ではなく絹自身が浮かぶ。見る者と見られる者が一コマで反転する、世界法則の最終証明。

**リスクと回避**：一話一「拒まれた瞬間」の開示がギミック化する恐れ。→ 娘の一枚を背骨に全事件をその鏡として配置し、世界法則を世界の仕組みではなく絹の心理からのみ見せる。

**シリーズ展開**：一作完結を主軸。続編なら各巻＝一人の「拒まれた瞬間」の現像と、そのたび白紙へ近づく絹自身の喪失。前日譚として二十年の記録も可能。

**想定読者**：文学寄りの犯罪サスペンス・心理スリラー読者。SNS時代に「像」として見られる暴力を感じている20〜40代。暗室というアナログの手触りにノスタルジーと恐怖を同時に抱く層。
