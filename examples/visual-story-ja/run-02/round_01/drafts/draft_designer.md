# 草案 —《未現像》断片と骨子（Designer／体験デザインの観点）

**核心的主張**: 《未現像》は「暗室の美を描写する小説」では死ぬ。読む行為そのものを現像液にせよ——ページをめくるたび像が浮き、読了の瞬間、読者自身が最後の「未現像の像」になる。この体験的一貫性こそ唯一の価値であり、プロットの整合も暗室描写の写実もすべてこの体験に隷属させる。世界法則は「語られる」たびに死に、読者の体に白黒反転として「起こる」たびにのみ成立する。

---

**(1) タイトル候補と含意**

《未現像》——これ以外は却下する。《暗室》《ネガ》《降ろした手》はどれも「対象を名指す」が、《未現像》だけが状態であり、読者自身を「まだ現れていない像」の位置に置く。この作品は絹の物語を読むのではなく、読者が現像液になる体験でなければならない。含意は「見ることの暴力は、読者が『像を見た』と安心した瞬間に完了する」——だからタイトルだけは永遠に完了させない。装丁では三文字をネガ（白黒反転）で刷り、帯に正像を重ねる。買った瞬間、現像は始まっている。

**(2) キャッチコピー**

「シャッターを、降ろした。それが、一番はっきり写る。」
狙い: 世界法則を読者の体に刻む一文。凡庸なサスペンス広告は「真実が明かされる」未来完了を予告するが、本作の体験は逆回し——「撮らなかった」という否定が「最も写る」という肯定へ反転する瞬間こそ、本編の最初の現像である。このコピーはページを開く前に、読者に一度ネガ→正像の反転を体験させる。副案「あなたが見なかった瞬間を、誰かが見ている」——こちらは読者を観客席から現像トレイの被写体側へ引きずり込む。

**(3) あらすじ（起承転結＋どんでん返し）**

**起** 女流写真家・絹は、撮影を拒む被写体ばかりを撮り、撮れなかったフィルムを暗室で現像する「見ないことの記録者」。彼女の像は被写体をその瞬間に固定し、人生を壊してきた——見ることは痕跡を残す暴力である。
**承** 彼女が唯一現像を拒んできた一枚——二十年前、娘の死の瞬間にカメラを落としシャッターを切らなかった未露光フィルム——が盗まれる。盗んだのは彼女の像に人生を壊された被写体たちの末裔。犯人は追い詰めない。絹の手法を完璧に模倣し、「あなたの見ないことの記録を、私が見る」と告げる。
**転** 最後の暗室。犯人が娘のフィルムを現像液に沈めようとする。絹は初めて「見られる側」に立つ。赤い安全光の下、いま現像されつつあるのはフィルムではなく彼女自身の顔だと気づく。
**結（どんでん返し）** 未露光フィルムが最も真実の像として現像するのは、死んだ娘ではない。**シャッターを降ろした撮影者——目撃を拒否した絹自身の、その手の暴力の像**だった。犯人が欲したのは復讐ではなく、絹に「被写体」を経験させること。沈めるか否か——その選択を見つめる絹の顔を、犯人は撮り続けている。最終ページは真っ白の印画紙。読者自身が、現像されていない最後の像である。

**(4) 世界観と設定——法則の運用ルール・限界・代償**

- **ルール**: シャッターを降ろした瞬間／被写体が拒んだ瞬間のみ、未露光フィルムは像をネガで「待機」させ、現像液に触れて正像へ反転する。像は常に被写体が隠したかったもの、本人すら見なかったもの——耐え難いものだけを写す。光は単一光源のみ。二つの光が同時に立つ瞬間、世界は停止する（絹だけが知る暗室の禁忌）。
- **限界**: 現像された像は「真実」として世界に固定され、取り消せない。被写体の人生を壊すのはこの固定性。また、現像を拒み続けたフィルムも時間とともに滲み、二十年放置した絹のフィルムはすでに半分浮かんでいる（＝キービジュアル「液面の発生」）。**現像しない、という選択すら永遠にはできない。**
- **代償**: 現像した者の指の脂がレンズに痕として残る——見ることは必ず痕跡を残す。絹の脂の痕は、彼女が現像した全像の隅にある。そして最大の代償——絹は一度も誰かに撮られていない。この世界で唯一、法則の被写体側に落ちたことのない者。犯人が彼女を撮り始めたとき、世界法則は初めて彼女を噛む。

**(5) 主人公・絹**

四十代。銀塩しか使わず、デジタルを「像を真実にしない装置」と軽蔑する。指先に現像液の薬液負け。他人の人生を現像し尽くしてきたのに、娘の死以後、自分の人生は未現像のまま誰にも撮られていない。笑わない——冷酷さではなく、被写体が拒む瞬間こそ最も美しいと本気で信じているから。彼女にとって「撮らないこと」は最大の敬意だった。それが暴力だと知るまでの物語。**葛藤**: 見ないことが愛だと信じたい絹と、見ないことも暴力だと知ってしまった絹の衝突。娘の死にカメラを落としたのは、見たら死が「真実」になってしまうから——だが見なかったことで、娘の死は二十年、彼女の内側で未露光のまま現像され続けている。**動機**: 現像をやめたら、次に現像されるのは自分自身のフィルムだと知っているから、やめられない。盗難は、彼女が逃げてきた「自分が被写体になる日」を強制する。

**(6) 独自フックの具体例**

- **語りの罠**: 物語は絹の三人称で始まるが、中盤で読者は気づく——この語り手は、犯人が絹を撮ったフィルムの現像過程そのものだった。読者は無自覚のうちに、被写体を覗く現像液の位置に置かれている。
- **本文のネガ反転**: キービジュアルの場面に差し掛かると、ページの文字そのものが白黒反転する。読者は物理的にページを「現像」している。
- **最終章の空白**: 最後の数ページは本文のない印画紙の白紙と、一滴の現像液の染みだけ。読者が本を閉じる＝シャッターを降ろす。読者自身が未現像の像になる。

**前提**: 物語体験は「受け取る」ものではなく「起こる」ものであり、読者は常に画面のこちら側ではなく、その中に置かれなければならない——という体験デザインの信条。
