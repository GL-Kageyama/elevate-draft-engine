# タスク

映像（動画）でも静止画でも映える"ルックのいい物語"の小説企画を考える。ただ見た目が派手なだけの物語ではなく、物語としての深み（テーマ・人間の真実）とエンタメ性（面白さ・続きが気になる）を両立させながら、世界観と画面に強い視覚的コンセプト（色彩・質感・構図・象徴的な場面）を持ち、どの場面を切り取っても一枚の絵になる物語企画を2〜3本出すこと。各企画は【仮タイトル】【ルック（世界観と画面の質感・色彩・構図のコンセプト）】【テーマ（深み）】【骨子（あらすじの要約）】【キービジュアル（静止画・動画で最も映える象徴的ショットを2〜3点、絵としてどう映えるか）】で構成する。ジャンルは問わないが、映像化・ビジュアル展開を前提とし、既存作品の焼き直しにならない独自のルックとフックを持つこと。
