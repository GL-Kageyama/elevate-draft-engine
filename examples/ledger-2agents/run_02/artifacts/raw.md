# 事業計画書：家計簿アプリ「Rei」

## 要旨（結論から）

**Reiは家計簿アプリではない。「お金の瞑想」である。**

これはキャッチコピーではなく、事業の全てを決めるカテゴリー再定義です。機能で競争する限り、ReiはMoneyForwardの「シンプルモード」という機能追加で消滅します。しかし「お金の瞑想・自由を訓練する装置」という新カテゴリーとして立てば、競争は「より良い家計簿」ではなく「より良い人生との向き合い方」になり、大手の追撃は意味的に無効化されます。

この事業の正直な姿は、**年商1,000〜2,000万円の健全なライフスタイルビジネス**です。ユニコーンでも失敗でもなく、1〜3人で10年続き、高利益率で、ユーザーの人生に深く意味を持つ。それが「ミニマリスト向け」というテーマに一貫した答えです。

---

## 1. 世界観：3つの逆説とその解消

### 1-1. 既存アプリの構造的罪

MoneyForward・Zaimの経済モデルは「口座連携で全データを集約 → 広告＋金融商品アップセル」で成り立っています。つまり彼らは**ユーザーの注意とデータをビジネスにしている**。ミニマリストが最も嫌う「搾取」と「注意の奪取」が、ビジネスモデルの根幹なのです。

Reiはこの構造と正面から決別します。

### 1-2. 三つの逆説と解消策

| 逆説 | 内容 | Reiの解消策 |
|---|---|---|
| **道具の逆説** | 「ものを減らしたい人」に「新しいアプリ」を売る | **自己消滅する道具**にする。役目を終えたら自ら消える唯一のアプリ |
| **課金の逆説** | 消費削減を価値観とする層に継続課金する矛盾 | **買い切り（2,500円・一生）**。継続搾取をしないことが価値そのもの |
| **記録の逆説** | 家計簿が「帳簿のように味気ない人生」を再生産する | **円を数えない**。「自由の日数」という人生の単位で返す |

### 1-3. 命名

**Rei = 零（ゼロから、ゼロベース予算）/ 麗（美）/ 例（模範）**。多義性がそのまま製品の思想です。短く、日本語でも英語圏でも発音できる。ブランド資産として強い。

## 2. 顧客：誰の、どの不安に刺さるか

### 2-1. ペルソナ4類型

1. **ミニマリスト実践者（25〜40歳・都市部）** — 断捨離を日常化。お金より所有の最小化に敏感。
2. **サイドFIRE関心層（30〜45歳）** — 「働かなくてもいい日」を具体的に数えたい人。最も強い刺さり方。
3. **単身・不定期収入層（副業・フリーランス）** — 給与前提の家計簿が合わず、既存アプリを既に諦めている。**人口では最大、市場評価では最小区分**。
4. **夫婦・パートナー** — お金の話し合いを始めたいが、どう話せばいいか分からない。

### 2-2. 感情的真実

彼らの本音の恐怖は**貧乏になることではなく「自己消滅の予感」**です——働くのをやめたとき、仕事以外の自分が何も残っていない、という不安。金額の見える化は、その恐怖を数値で裏書きするだけ。

彼らが渇望するのは「記録」ではなく**現在形の自由**——今日の自分の時間を自分で決めている感覚。Reiは日々の操作そのものを「自由の練習」にします。

### 2-3. 既存が満たせない理由

既存アプリの設計思想は「世帯主・給与所得・固定費の配分」という昭和の世帯モデル。単身化38%・副業一般化・新NISAで積立投資が大衆化した現在、**この最大層にそもそも刺さらない**。Reiの最小設計は、この「無視された最大層」に最初からフィットしています。

## 3. プロダクト：体験の核

### 3-1. 設計原則——「体験は厚く、機能は薄く」

機能数を絞ることと体験の豊かさは別次元です。**技術的な表面は極限まで薄く（ウィジェット1枚）、心理的な体験は極限まで厚く（儀式・赦し・卒業）**。これがReiのデザイン原則です。

### 3-2. コア体験の3層構造

**第1層：週30秒の儀式（毎週日曜）**
- 残高をひとつ入力するだけ。費目もカテゴリも口座連携もなし。
- Reiは円ではなく**「自由の日数」**で返す——「今週、2日ぶんの自由を貯めました」。
- 不安の対象が「減る数字」から「残る時間」に反転する。

**第2層：毎日のゼロ表示（ウィジェット）**
- ホーム画面のウィジェットに**一桁の数字だけ**：「今日使える額 = 残額 ÷ 残り日数」。
- アプリを開かせない設計。存在感ゼロで数字だけを届ける。
- この数字のスクリーンショット自体が、ミニマリストSNSで「内容」になる。

**第3層：卒業システム（成功の自己削除）**
- 月の目標（例：「自由の日数を3日以上に」）を**3ヶ月連続で達成**すると、機能が自動的に剥がれていく。
- 全てを卒業するとReiは問う：**「あなたは卒業できます。このまま消しますか？」**
- 削除が最高の成果。**この設計はデータ集金と広告で生きる大手にはビジネスモデルごとコピー不可能**——使わせ続けることが儲けの構造と、真逆だから。

### 3-3. 赦しのデザイン

- 予算の代わりに「戒」：*「今月は外食を週2まで」* という一文を自ら書き、週一度「守れた？」と告白するだけ。監視ではなく修行日誌。
- 買い物は金額入力でなく一振りの二択：**「私のため / 私でない私のため」**。
- 無駄遣いを責めない。赤バッジを出さない。*「それも、あなたが選んだ人生です」*。
- 表に数字を並べず、問われた時だけ数字が現れる「零」のデザイン。

### 3-4. 道具 → 記録への変容（リテンションの再定義）

卒業してもアプリは完全には消えません。「自由の旅の記録」として残り、**道具（tool）→ 儀式（ritual）→ 記念品（keepsake）**へ変容します。卒業したユーザーは最も熱心な伝道者になり、「私はReiを卒業しました」が最大の口コミになる。**解約は失敗ではなく祝福**。

## 4. 市場とタイミング：なぜ今か

5年前には成立しなかった条件が同時に揃いました：

- **単身世帯38%**——家計簿の主体が「世帯」から「個人」へ移行
- **不定期収入の標準化**——「固定額を配分する」従来予算が崩壊
- **新NISAによる投資の大衆化**——家計簿と投資の境界が消滅
- **物価上昇**——「無駄を探す最適化」の約束が減価し、「私は十分持っている」という**充足**の約束が増価
- **デジタルミニマリズム**——通知・広告・多機能で注意を奪う既存勢の交代が迫られている

これは一時的トレンドではなく、人口構造に根ざした不可逆な動きです。

## 5. 競合とモート：何で守るか

### 5-1. 構造的モート（これが最も強い）

MoneyForwardの経済性は「全銀連携で全データ集約 × 広告 × 資産運用/保険アップセル」で成立しています。彼らが**本当の**シンプル・広告なし・端末内完結・自己消滅を完全に真似れば、自社のデータ収益モデルを自ら崩すことになる。彼らの「シンプルモード」はデータ収集エンジンに被せたスキンにしかならず、Reiの約束（**何も集めない・何もしない**）を構造的に実行できない。これはイノベーターズ・ジレンマによる防衛です。

### 5-2. 正直な限界

機能は数週間で模倣されます。**機能で守れないことは前提にし、以下の3つで守る**：
1. 構造（上記・コピー経済的に不可能）
2. ブランドと哲学（築くのに時間がかかり、複利する。模倣にも時間がかかる）
3. コミュニティ（CACゼロの有機配布。大手はこの文化資本を持たない）

**ただし**、本気のプラットフォーマーが「理念を無視して実力行使」してきたらニッチでは守れません。だからこそ「ニッチの頂点」を目指さず、規模に依存しない体質を最初から作る。

## 6. 収益モデル：誰が・なぜ・いくら払うか

### 6-1. モデル選定

| モデル | 判定 | 理由 |
|---|---|---|
| 広告 | **永久に却下** | 注意を売る＝ブランドの自殺 |
| アフィリエイト（保険・証券紹介） | **永久に却下** | 信用を売る行為。ミニマリストに即座に看破される |
| サブスク（月500円） | **却下** | 「継続搾取」と読まれ、価値観と矛盾 |
| **買い切りPro 2,500円** | **採択** | 一度払えば終わり＝搾取されない。ブランドの根幹 |
| **Rei Cloud（任意・年1,500円）** | **採択** | E2E暗号化バックアップ/同期のみ。ローカル完結を選べば払わなくてよい唯一の正直な継続収益 |

### 6-2. 価格のロジック

2,500円は「外食1回分」「無印良品の文房具1つ分」。MoneyForward MEプレミアム（年間6,000円）の半年分未満であり、**「MF半年分の値段で一生のシンプル」**と位置づけられる。ミニマリストは価値観一致の道具には割高でも払う（無印・無垢材の論理）。

核機能にサブスクを絶対に混ぜないことがブランドであり、それは同時に**大手が追随できない理由**でもあります。

## 8. Go-to-Market：0→1万人

### フェーズ0（最重要の実行ポイント）：先売り検証

「ミニマリストはアプリを欲しがるのか」という最大のリスクは、作る前に潰します。note/Slackで思想を発信し、**100人の先行購入者（2,500円前払い）を募集**。100人が払ったら需要は証明されたものとして開発着手。払わなかったら作らない。**これは投資対効果を守る最重要ゲート**です。

### ウィジェットがコンテンツになる

「今日の自由の日数」のスクリーンショットは、それ自体がミニマリストSNS（X・Instagram）で拡散する内容。**マーケティングコストはApple年会費約1.2万円のみ**。

### 卒業が口コミになる

「私はReiを卒業しました」という投稿は、通常アプリの「解約報告」と真逆の正の感情イベント。卒業者＝最強の伝道者という循環を設計に組み込む。

### コミュニティチャレンジ

「1ヶ月・自由の日数チャレンジ」「週5分の金銭対話の儀式」を、ミニマリストYouTuber・note・Podcast経由で展開。CACゼロの有機拡散。

## 10. リスクと失敗条件（厳格検証への正面回答）

独立評価者（ビジネス価値）はこの計画を**需要の捏造の疑い**で39点と厳しく評価しました。その批判をそのまま掲げ、正面から回答します。

### 批判1：「道具を捨てたい人に道具を売る構造」
→ **卒業システムがこの矛盾を解消する**。Reiは唯一「役目を終えたら自分から消える」アプリであり、「アプリすら減らしたい」という欲求に**乗っかる**設計。ミニマリストが許容できる唯一のアプリのかたち。

### 批判2：「ミニマリストは払わない。無料信仰がある」
→ サブスクを捨て、**買い切り2,500円**にした。継続支出を生まない道具に払うのは、無料信仰ではなく「価値観一致への投資」。ただしこの批判は正しい可能性が高く、だからこそ**フェーズ0の先売りで証明してから作る**。

### 批判3：「機能絞り込みは明日真似される。モートがない」
→ 機能は真似される。しかし**「データを集めない＋自己消滅」は大手の経済モデルと両立しない**（構造的モート）。残りはブランドと関係性で守り、規模に依存しない体質を選ぶ。

### 批判4：「節約上手ほどアプリの限界効用が下がる」
→ 正しい。だからReiは「節約を最適化する道具」ではなく**「自由の感覚を訓練する道具」**として立てる。効用は金額で測られない。

### 批判5：「市場の誤読。ライフスタイル流行と金融実需の混同」
→ 金融実需（投資・積立）は大手が取り込み済み。Reiは**取り合わない**。勝つ戦場を「不足の最適化」ではなく「充足の実感」に置く。

### 致命傷リスト（正直版）
- 卒業システムがユーザーに響かず、単なる「簡素な家計簿」として認知される → ブランド死
- フェーズ0で100人が集まらない → **開発しない（これが正しい意思決定）**
- 「ミニマリスト向け」というセグメントが思ったより狭い → 単身・不定期収入層へのピボットで吸収
- AI完全自動化の波が来るまでに「解釈者」の地位を確立できない → 記帳の美しさだけでは5年後に何も残らない

## 11. 結論：選ぶこと、選ばないこと

**選ぶこと**：
- 「お金の瞑想」というカテゴリー再定義
- 自己消滅する道具（卒業システム）
- 買い切り2,500円＋任意クラウド
- 広告・アフィリエイト・データ販売の永久拒否
- 1〜3人・年商1,000〜2,000万円の健全なライフスタイルビジネスとして10年続ける
- **作る前に先売り検証**

**選ばないこと**：
- VCマネーとスケール追求（成長投資で死ぬ）
- MoneyForwardとの機能競争
- サブスク・広告・アフィリエイト
- B2Bライセンスを最初から狙うこと
