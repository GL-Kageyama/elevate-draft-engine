## 提案: `ato`（跡）—— 自己疎外メーター

**① ツール名と一行キャッチコピー**
**`ato`（跡）** —— 機械の平均に飲まれるあなたを、鏡のように映す。

**② 解消する課題と対象ユーザー**
AI時代の本物の痛みは「AIがバレること」ではない。**自分の文章に、自分の声ではなく機械の平均が静かに混ざり始めること**だ。人間はLLMの出力をコピペし、読み、影響され、いつのまにか「自分らしさ」を侵食される。既存のAI検出器は「他者を告発する」道具だが、告発は確率的に破綻する——出力はどちらも同じ分布から生まれるから。`ato`は告発をやめ、問いを**「これはAIか」から「これはあなたか」へ**変換する。対象は、AI出力と自分の原稿を往復する編集者・研究者・プログラマー——声を失う不安を抱えるすべての人。

**③ 主要機能**
```
$ ato learn --git .            # 自分の過去の文章から声の指紋を学習
learned: 1,204,913 trigrams → ~/.ato/me.json

$ ato score draft.md           # あなたらしさを比率で映す
you: 72%  machine-avg: 41%  → 声は健在

$ ato diff my.txt ai.txt       # 自分の原稿とAI直しの「声の距離」
distance: 0.84 | あなたらしい語彙が3箇所、機械語に置換されています

$ ato ghost src/               # リポジトリから機械の声が染みた箇所を炙る
src/parser.rs  you-ness 11%  ← 機械の声が強い

$ ato drift                    # 声の経年変化——機械に似ていく自分を警告
2026-06: 84% → 2026-08: 61% | あなたは平均に近づいています
```

**④ Rustを選ぶ理由**
声の指紋はn-gram頻度ベクトルに過ぎないが、学習対象はGB単位のコーパスへ膨らむ。RustのハッシュとI/OはGC停止なしに全コアを絞り尽くし、指紋は**単一ファイル・単一バイナリ**としてローカルに完結する。声という最も私的なデータをクラウドに送らず、静的リンクされた一つの実行ファイルだけで守る——プライバシーこそ本ツールの倫理だから。

**⑤ シンプルさの根拠**
外部クレートは**ゼロ**。`std`のみで実装し、CLI解析も自前。コアは約400行の純関数の連鎖——テキスト→文字trigram→`HashMap`→L1正規化→コサイン距離だけ。サーバーもDBもモデルも持たず、**すべての判断が推論ではなく距離計算**で尽きる。だから誰でも中身を検証でき、自分の指紋を覗ける。

---

**前提**: 「あなた」の定義は、あなた自身の過去の書きぶりに置かれる——指紋なき者の声は、機械と区別できない。
