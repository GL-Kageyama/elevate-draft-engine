# 『明け渡しの深さ』——AI体感モーションプラットフォーム設計

## ① コンセプト

**体感の定義（一文）**：体感とは、乗員が自分の身体の制御を台に明け渡す深さ **σ** を、台が3軸回転として返し、乗員の前庭（耳の奥にある平衡感覚の器官）が答え合わせをする過程である。σには二重性がある——姿勢・支持・拘束として外から見える **σ_out** と、筋緊張・重心動揺・把持力・呼吸として本人にも正確にはわからずAIが推論するしかない **σ_in**。**この二つのズレがゲームの全体である。**

| | レーシング／フライトシミュレータ | 本機 |
|---|---|---|
| 体感の種類 | 実加速度の再現。視覚と前庭を**一致**させる | 前庭のみに与え、**予測と実際のズレそのもの**を商品にする |
| 操作の主体 | 乗員が操る（入力装置あり） | **操作機器ゼロ**。AIがσ_inを推論して動かす |
| 失敗の意味 | クラッシュ・タイムロス＝操作の巧拙 | **読み違え**。σ_outとσ_inの不一致＝「違う」という身体感覚 |

根拠：視覚一致型の体感は既存100タイトルが占有済み（資料7章）。本機は非競合カテゴリを選ぶ。

| 項目 | 値 |

| 可動域 | **20°** |

## ③ AI核の構成

| 層 | 入力信号 | 処理内容 | 出力（世界の変化／難易度／応答） |
|---|---|---|---|
| **知覚** | カメラ（姿勢・表情）、ロードセル、マイク、把持力 | **σ_in の実時間推論**。身体を持たないものが身体を仮定する | **難易度**＝予告量（＝σ_in推論の自己申告）。σ_inが低い乗員には予告を情報として与え、高い乗員には予告の不在を委ねた甲斐として与える |
| **生成** | σ_in推定とその軌跡、σ_outの選択、叫ばれた単語 | 仮定した身体を運動指令へ変換（仮定は必ず外れる） | **世界の変化**＝3軸運動そのもの。外れは前庭にトルクとして直達する |
| **適応** | 推論精度の自己評価、会場のσ分布 | σ上限を推論精度に比例させる。飽きの検出 | **応答**＝「降りる」の宣言。持ち出しデータ（σの軌跡）の生成 |

## ④ 公共遊具としての成立条件

**安全**
- 物理非常停止**3箇所**（乗員手元・周囲・床上）。**ソフトを経由せず中央へ戻す経路**を独立に持つ。
- **上位ガバナ**：σ非依存のハードリミット（220〜803クランプ、スルーレート、ウォッチドッグ対応常時ストリーム、異常終了時512復帰）。**AIの自信を一切参照しない**。下位AIはその内側でのみ動く。
- ファームは範囲を検証しない——**制限を守る責任はホスト側にある**（資料5章）。これを設計原理とする。
- 起動時はσ=0。台は動かない。いきなり飛ばさない。
- 年齢体格：σ_in 推論が最も難しい相手が子ども。**σを浅く制限してはならない**（差別になる）。代わりにAIが「自分はあなたを読めていない」と開示する。不確かさがゲーム内容になる。

**運用**
- 1回の所要時間：**σ=0で60秒が静かに終わる**構造が上限を保証する。
- 順番待ち：画面は**終了後のみ**（紙またはQR）。搭乗中に画面を要さないことが回転率を生む。
- 説明ゼロ秒：**何もしないと始まらない**という一点のみが説明である。開始の主権は人間に、終了の主権はAIにある。
- 故障時：中央512へ復帰。
- 清掃：汗・髪・肌が触れる支持部は交換可能に。

**不特定多数への公平性**
- スコアは**σ_outとσ_inの一致度**。操作でも耐久でもないから**体格非依存**——正規化が不要になる。
- ランキングは1つではない。**σの深さごとの連続層**。
- 深さは観客にも見え（沈む／力んでいる）、次の人のσを決める。**σの分布がその日の会場の性格になる。**

## ⑤ 遊戯体験の設計

- **習熟曲線**：上達＝σ固定のまま精度を上げる。**深化＝σを変える＝ルールを改変する**。深化が次の来場理由になる。
- **子どもと大人の同居**：同じ台で、深く預けたい人と浅くしか預けられない人が、それぞれに最適な体験を得る。σの層がそのまま共存の機構である。
- **リピート動機**：一回性（同じ軌道は二度と出ない）は反復を殺さず駆動する。駆動するのは「飽きない」からではなく、**σを変えて再挑戦できる**からである。
- **持ち出し**：σの軌跡がJSON／QR／紙で手元に残る。自分が書いた一行が次回の台の動きになる。**作るとはAIに身体を与えることである**——文法不要で、一行から始まる。

## ⑥ 差別化の明示

- **家庭用VRとは体感の種類が違う。** VRは前庭に**何も来ない**。本機はトルクが身体に直結する唯一の装置である。
- **レーシング／フライトシムとは商品カテゴリが違う。** あちらは視覚と前庭の**一致**を売る。本機は前庭だけに与え、**不一致を売る**。
- **既存の体感アトラクションとは体感の種類が違う。** あれらは乗り物のシミュレーション（受動の再現）であり、身体感覚を**他の目的**に使う事例は、ローラーコースターを除いてほとんど存在しない。
- **操作機器ゼロは設計宣言である。** 入力装置を持たないことが、レーシング／フライトとの断絶を一行で証明する。
- **AIの扱いが違う。** AIを難易度調整や見た目生成に使うのは、構想が批判する「AIがゲーム開発に影響していない」状態そのもの。本機は**AIの身体性の欠如そのものを唯一のルールにする**。

## ⑦ 未解決の設計課題

1. **σ_inの実時間推論**がPi5＋5060ti級で実用水準（目標±1cm）に達するかは**未検証**。カメラ姿勢推定＋ロードセル＋把持力の融合は実機計測を要する。
2. **σ上限をAIの自信に結合する設計は安全性が未証明**。上位ガバナの設計次第で、自信に依存しない固定マージンへ後退しうる。
3. **σの伝染は仮説**。会場のσ分布が実際に時間変化するかは未確認。
4. **0.7G T / 0.5G L のT/L定義が未確認**のため、σの物理スケーリングの最終形は確定できない。
5. **運営主体が未決**。公共性＝拒否可能性を貫くなら、「乗りたくない人が乗らずに済む」だけでなく「**貸したくない人が貸さずに済む**」ことを保証しなければならない。その条件は導出できていない。
6. 実装はルートA（有料ライセンス非依存）を前提とするが、**H3は1日2〜3時間想定の機体**であり、公共での連続稼働（1000Wピークの発熱・摩耗・騒音）は本来の想定を超える。耐久の実測が必要である。
