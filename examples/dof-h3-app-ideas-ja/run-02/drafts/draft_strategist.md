# 草案：『重力の感じ方の帰属』——台の商品はゲームではなく、他人の身体である

**核心的主張**
① この台が売るのはゲームではない。**他人の「重力の感じ方」**である。3軸指令の時系列（身体テープ）を、AIが体格差ごと別の身体へ移植できること——レースシムにもコースターにも原理的に真似できない唯一の堀。
② ゆえに払うのは乗り手ではない。**他人の重力の感じ方を1分100円で買う観客と遠隔者**、そして二桁大きい予算を持つ**公民館・学童・自治体**だ。プレイ料金100円は入口にすぎない。
③ 台の上に操縦も速度もない。競うのは速さではなく**いま自分の重力の感じ方が誰のものか**——「操縦して速さを競う」を語彙ごと置換する。

**(1) 遊戯体験の核（45秒＋15秒リセット）**
0–10秒、台は静止。カメラが姿勢、マイクが呼吸を読み、乗り手の「重力の感じ方のクセ」（重心の左右差・呼吸周期）を測る。10–40秒、AIが重力の感じ方を毎秒1〜2°の低速で回す。乗り手が無意識に傾けて戻そうとする補正を画像から読み、**その補正を打ち消す向きに台を動かす**——合わせるのではなく、合わせを外し続ける。待機列はスマホから「重力の感じ方」に投票でき、その集団状態が軌道パラメータになる（待ち時間が体験に変わる）。40–45秒、AIが「重力の感じ方を見失った瞬間」を検出し、その身体テープと短い動画をQRで渡す。これが土産であり商品見本である。

**(2) AIが核である必然性**
核は**移植**だ。25kgの子が90kgの大人の重力の感じ方を着る——質量・身長・反射遅延を推定して軌道を再合成して初めて成立する。生テープ再生はただの揺れで、商品ではない。加えて癖のリアルタイム認識、列の集団状態からの軌道生成、失敗（重力の感じ方を見失う）のスコア化。一つでも欠ければ動かない。難易度調整と見た目生成にしかAIを使わない企画はここで死ぬ。

**(3) 機構**
3軸（pitch/roll/yaw・リアトラクション）、可動20°、86°/s、0.7G、耐荷重150kg、1000Wピーク。**並進は使わない。低速域の滑らかな軌道が主戦場**——20°は欠如ではなく「重力の感じ方」への特化である。搭乗者は**非拘束の座位**（簡易シート＋股下ベルトのみ、上半身自由）。自由な上半身が補正動作を生み、それがAIの入力になる。座面高20cm以下・足は常時接地・可動部にシリンダーガード。クランプ初期値220〜803、スルーレート制限、100msハートビート、起動時原点復帰、異常時中央復帰、物理非常停止は独立系統2個・誰でも届く位置。

**(4) 公共空間での成立**
体格差はAIが再合成で吸収（軽い身体ほど反応が速く、子どもは有利に設計できる）。60秒/人＝1時間60人。1人乗り、観客は投票者。スコアは台横の縦長画面とQRへ——画面は主役ではなく**記録の出口**に限定。座面は撥水・交換式。ヘッドホン不使用。1000Wピーク対策で60秒中20秒を強制休止。設置は安全域込み約2m×2.5m＋列、1台1回路（100V/15A概算）。故障時は中央復帰、電源断はフリー化優先（要検証）。スタッフ1人で3台。

**(5) 差別化（入力・出力・体験）**
- 入力：レース系はホイール＝**手で操縦**。本機は**姿勢・呼吸・列の投票**。手を使わない。
- 出力：レース系は加速と旋回のGを**乗り物の動き**として返す。本機は**重力の向きそのもの**を返す。返るのは速度ではなく重力の帰属。
- 体験：レース系は上達と競争。本機は**下手なほど高得点**（重力の感じ方を何度書き換えられたか）。リトライ動機は「もっと崩れたい」。持ち帰るのは記録ではなく他人の身体。

**前提**
「AIが3軸指令から体格と癖を推定し、別の体格へ再合成できる」の一点に全体が依存する。実機で検証できなければ、ただの揺れる椅子に戻る。
