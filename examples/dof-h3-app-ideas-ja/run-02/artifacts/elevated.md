# 『シタオリ』設計書 — 重力の感じ方の閉ループ

## ① コンセプト名と呼称
**『シタオリ』**（「重力の感じ方」を織り、また読む、の重義）。子どもがそのまま口にできる。一言の体験定義——**「あなたの『重力の感じ方』を、AIが読んで、織り直す」**。呼称は「ゲーム」ではなく**「重力の感じ方の測定器」／「身体の工作室」**とする。遊具でありながら制作装置であるため、どちらにも寄せられない。この宙吊りが法的にも体験的にも正しい位置である。

## ② 遊戯体験の核
1プレイ**90秒・3相**。
- **相1「読まれる」0–30秒** — 座るだけ。台は±3°で微動。AIが姿勢・呼吸・補正から「あなたの重力の感じ方」を推定する。**何もしない**。
- **相2「織られる」30–75秒** — AIが重力の感じ方を書き換える。**抗ってもよく、委ねてもよい。抗いは補正として、委ねは順応として読まれ、どちらも入力である。**
- **相3「返る」75–90秒** — 中央へ。BODY TAPE と、モデルの一行（「あなたは右に0.18秒先回りする」）が返る。

**これはレーシング／フライトシミュレータではない。** ハンドルも速度も順位もない。人は車を操作せず、**ループの一部**である。ヒーブ／サージ／スウェイは使わない。扱うのは**「どちらが下か」の変調のみ**。画面は台の動きを説明せず、結果の一行だけを出す——**世界を偽装するのではなく、重力の感じ方が偽装可能であることを露呈させる。**

## ③ AIの中核
- **読む**：姿勢・呼吸・筋緊張から「あなたの重力の感じ方」の予測ホライズンを個別推定（体格同定＝ループの初期条件）
- **織る**：閾値直下のゲインで重力の感じ方を書き換える（ずらし＝書き換えの振幅）
- **翻訳**：失敗＝「重力の感じ方を見失った瞬間」を検出し、報酬へ変換（恥の外部化）
- **蓄積・移植**：ループ出力を BODY TAPE として保存し、別の身体でループを再開する
- **圧縮**：モデルを一行に畳んで返す

**AIを除けば、台はただの揺れる椅子である。** 「なぜ私の重力の感じ方はこの形なのか」という不可解さ——観察者を生み、設計者を生む非対称——が消える。

## ④ モーションプラットフォーム機構
| 項目 | 設計 |
|---|---|
| 軸・自由度 | 3軸（ピッチ／ロール／ヨー＋リアトラクション）。**並進なし** |
| 範囲 | ゲーム内上限**±15°**、実使用**±3〜15°**。20°は体験範囲ではなく**非拘束の人間が載るための安全マージン** |
| 駆動 | モーションボックスへ直接シリアル（500,000 baud・5バイト固定長・0〜1023／中央512）、pysmc3（Apache-2.0）。**ライセンスフリー・SRS不要** |
| 拘束 | 座位・**骨盤のみ拘束・上半身非拘束**・足は常時接地・低座面。抗いを残し、立位転倒を捨てる |
| 安全 | クランプ初期値220〜803／スルーレート制限／100msハートビート（15秒ウォッチドッグ）／起動時原点復帰／例外時中央復帰／**物理非常停止は複数箇所・独立系統**／電源断用手動リリース |
| 体格適応 | AIが体重・体格を同定し角度スケーリングで同一知覚量を狙う（**⑦-3で要検証**） |
| 熱 | 90秒中、実運動は約45秒。**デューティ50%以下**を設計値とする |

## ⑤ 公共空間での成立条件
- **回転率**：90秒＋15秒リセット＝**1時間約34人**。これは制約であり目的ではない
- **説明ゼロ**：座るだけで相1が始まる。誰でも押せる非常停止
- **同時参加**：搭乗1人＋観客。出力は台横の記録板とQRに限定。**降りた人の一言を書き残す場所**を置く（計測ではなく蓄積。次に乗る人の入力になる）
- **参加の列**：25kgの子の重力の感じ方も90kgの大人の重力の感じ方も**同じ列に並ぶ**。所有ではなく列挙
- **衛生**：汗・髪・肌が触れる面は清掃可能素材
- **騒音・連続稼働**：H3は本来1日2〜3時間のホビー想定。**公共連続稼働は想定外**——保守周期の実測が要る
- **故障時**：中央復帰、手動リリース
- **場**：まず期間限定の会場、将来は公民館・学童へ

| | レーシング／フライト体感 | 『シタオリ』 |
|---|---|---|
| **入力** | ハンドル・連続操作 | **抗う／委ねる身体**（選ばなくても成立） |
| **出力** | 人工物の再現 | **自分の重力の感じ方のモデル一行＋BODY TAPE** |
| **体験** | 世界を偽装する（錯覚を作る） | **世界が偽装可能であることを露呈させる** |
| **人の位置** | ループの外（人が機械を操作） | **ループの内（人がループの一部）** |

既存事例はほぼ全て「乗り物のシミュレーション」である。本機は動詞が逆——**人間の身体という自然物を、人工物として扱えるようにする**（リバース・シミュレータ）。

## ⑦ 未解決事項（実機で決着）
1. **±15°・座位・骨盤拘束・上半身自由**で「抗い」が安全域に収まるか。破綻すれば相2は縮小を強いられる
2. **「抗う／委ねる」がAI入力として分離可能か**（筋電・重心・呼吸）。未検証
3. **体格差の再合成が「同じ知覚量」になるか**。ここが崩れれば揺れる椅子に戻る——**最優先の実験**
4. **電源断時に中央へ戻らない問題**。手動リリースは必須要件
5. **ウォッチドッグ15秒・クランプ220〜803**は単一情報源。実機で追測
6. **デューティ50%以下で発熱・摩耗が公共運用に耐えるか**。保守周期の実測
7. **風営法上の呼称、安全基準、コスト**（台¥680,000〜¥815,800＋PC。「Raspberry Pi 5＋5060ti単体で動く」が最低技術目標）、および有料ライセンス非依存での再現性確保

**完成形は、台の上で遊ぶことではない。台を降りて、自分の重力の感じ方を書き始めることである。**
