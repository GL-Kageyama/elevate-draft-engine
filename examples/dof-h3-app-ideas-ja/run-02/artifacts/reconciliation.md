# 弁証法的止揚 — 『シタオリ』：重力の感じ方の閉ループ

## 序 — 八草案は何を争っていたのか

八草案は表層では驚くほど一致している。**台が主役・画面は補助・操作を捨てる・出力は「重力の感じ方」・AIは個別化**。この一致は本物である（run-01の二つの判定——「重力の感じ方」への特化と「画面は台の貧しさの補償」——が生きている）。

しかしその一致の下に、四つの断裂がある。そして止揚の素材はこの断裂にしかない。

| 断裂 | 一方の極 | 他方の極 |
|---|---|---|
| ① **能動性の席** | 立位・抗い・転倒＝designer, storyteller | 座るだけ＝implementer, humanist, visionary |
| ② **個別化の目的** | 公平化＝humanist, implementer | 交換・移植＝strategist, futurist |
| ③ **上達の可否** | 上達不能（AIが境界を更新）=visionary | 語り・一回性＝storyteller, designer |
| ④ **成果の測り方** | 回転率＝implementer, designer | 確率・語り＝humanist, storyteller / 収益＝strategist |

ここで注意すべきは、断裂②③④が**同一の矛盾の三つの顔**だということだ。後に示す。

---

## I. 否定 — 各立場の「一面的真理」を限定する

**designer（シタオリ）を否定する。** 「転倒は設計に含める」「抗わず身体の直しに任せる」——この洞察は正しい。だが立位・非拘束・転倒許容は、**150kgの大人と軽い子どもが同じ台に乗り、スタッフが常時付かない公共空間では、体験設計ではなく事故設計である**。台高15cmのマットは、子どもが2人で乗った瞬間に無効化される。転倒の快は「恥の統制」なしには公共で成立しない。**designerは体験の強度を、公共性のコストに無自覚に転嫁している。**

**differentiator（重力の感じ方の簒奪）を否定する。** 「今のは機械か、自分か」の申告は鋭い。だがこれは**問いを二者択一に閉じている**。身体の帰属は二値ではない——「自分の補正が機械に混ざった」中間状態こそが本機の主戦場であり、二択にするとその中間が消える。申告ボタンは、体験を判定課題に縮減する。

**futurist（公共平衡楽器）を否定する。** 「蓄積する資産はBODY TAPEだけ」「他人の重力の感じ方を借りる」——方向は正しい。だが**「楽器」という比喩は設計ではない**。楽器には演奏者がいる。本機に演奏者はいない。「5年後に別の誰かの重力の感じ方として再生される」は美しいが、そのために何をいつ誰が支払うのかが空白である。

**humanistを否定する。** 「回転率ではなく、見知らぬ一人が『私の身体は面白い』と呟く確率で測る」——規範として正しい。だが**測定不能な指標は運営の意思決定に一度も登場しない**。予算・シフト・保守周期のどれもこの確率を参照しない。良い規範が、実装から排除される。

**implementerを否定する。** 「公共で最初の1年、確実に回るのは座るだけの非操作型のみ」——これは正しい。だが**正しすぎて、能動性をゼロにする**。座るだけの台は、体験として「振動装置」に収束する（designerが正しく警告した通り）。生存条件の追求が、存在理由を空洞化させる。

**storytellerを否定する。** 「語り継がれるのは得点ではなく『あの時、重力の感じ方が真横だった』」——核心を突いている。だが**語りは結果であって設計ではない**。語りを設計目標に据えると、設計者は語りを捏造し始める（「感動的な台」を作ろうとする）。それは構造的に失敗する。

**strategistを否定する。** 「売るのはゲームではなく他人の重力の感じ方」「他人の重力の感じ方を1分100円で買う観客」——堀の同定として鋭い。だが**他人の身体を商品化する構造は、搾取の文法を持つ**。子の身体記録が大人の娯楽として売られる。これは構想の倫理（後者は税金のように扱う）と衝突し、公共施設の設置審査で確実に止まる。

**visionaryを否定する。** 「AIが境界を更新し続けるため原理的に上達しない」——最も純粋なAI核の定式化。だが**上達不能なゲームは、消費者を閉じ込める**。そして構想の最終目的は「遊んだ人が自分でも作りたいと思うか」である。上達不能は、作りたいを生む方向と逆を向いている。**ここに八草案最大の隠れた矛盾がある。**

## II. 保存 — 捨ててはならない真理の核

否定は破壊ではない。各立場から、**全体の真理を僭称できない形で**核を救出する。

1. **designerから**：*失敗は報酬でなければならない*。成功の報酬だけの遊具は、失敗した者を静かに排除する。この規範は公共でこそ必要である。
2. **differentiatorから**：*能動性には最小の席が要る*。それは手ではなく、**「抗うか、委ねるか」を選べること**。選ばなくても成立するが、選べることは残す。
3. **futuristから**：*重力の感じ方は個人に閉じない*。記録は身体を離れ、別の身体で再生されうる。これは比喩ではなく機構の性質である。
4. **humanistから**：*体験の質を回転率で測ってはならない*。これはKPIではなく**設計原則**として保存する（回転率は制約、質は目的。混同が失敗を生む）。
5. **implementerから**：*公共での生存条件は譲れない*。座るだけ・説明ゼロ・誰でも止められる。この三つは体験の強度より優先される。**強度で生存条件を買ってはならない。**
6. **storytellerから**：*持ち帰られる一言こそがプロダクト*。体験は消費されて消えるが、語りは複製される。**この台の成果物は体験ではなく語りである。**
7. **strategistから**：*体格差を越えた再合成*こそが模倣不能な機構。ただし「他人の重力の感じ方を売る」ではなく、**「他人の重力の感じ方と並べる」**として保存する。
8. **visionaryから**：*予測ホライズンの個別推定*は、AI核の最も純粋な形。難易度調整でも見た目生成でもない。**AIがあなたについて、あなたが知らないことを知っている**——これが本機のAI核の定義である。

## III. 高次化 — 『重力の感じ方の閉ループ』という一段高い枠組み

### III-1. 八草案が共有していた、見えていない前提

八草案はすべて**「重力の感じ方」を所有物として扱っていた**。自分の重力の感じ方・他人の重力の感じ方・重力の感じ方の帰属・重力の感じ方の簒奪・重力の感じ方を手放す。**この所有の枠組み自体が、レーシングシムの「誰が速いか」という所有＝優劣の枠組みの焼き直しである。** 速度を重力の感じ方に置き換えただけで、構造は同じだ。

所有の枠組みを脱すると、機構の正体が見える。

### III-2. 本機の唯一の機構：閉ループ

レーシングシムは**開ループ**である。
```
ハンドル → 車の物理 → モーション。人は車を操作する。人はループの外にいる。
```
本機は**閉ループ**である。
```
身体が「重力の感じ方」を主張する（姿勢・補正・呼吸・ためらい）
    → AIがその主張を推定する（読む）
    → AIが主張を書き換える（織る）
    → 身体が再主張する
    → …
```
**この閉ループが本機の唯一の機構であり、レーシング／フライトとの決定的差である。** ここで「操作」という概念そのものが溶解する。人は操作対象ではない。**人はループの一部である。**

八草案のAI役割は、すべてこの一つのループの異なる断面にすぎなかった：
- designer「ずらし」＝書き換えの振幅
- differentiator「閾値直下」＝書き換えのゲイン
- visionary「予測ホライズン」＝読みの時間幅
- strategist「移植」＝ループを別の身体で再開する
- humanist「失敗の翻訳」＝ループの誤差を報酬に変換する
- implementer「体格同定」＝ループの初期条件
- futurist「蓄積」＝ループの出力を保存する
- storyteller「一言」＝ループの出力を圧縮する

**八つの真理は、一つのループの八つのパラメータである。** これが高次化の第一段。

### III-3. 高次化の第二段：リバース・シミュレータ

シミュレータは**人工物を人間の身体に正しく感じさせる**装置である（車・飛行機・コースター——既存事例はすべてこれ）。

本機は動詞が逆である。**人間の身体という自然物を、人工物として扱えるようにする装置**。読む・書く・送る・移植する。これを**リバース・シミュレータ**と呼ぶ。

これが「画面が主役の企画は台の貧しさの補償」の、より深い定式化である。画面は世界を偽装する。本機は**世界が偽装可能であることを示す**。前者は錯覚を作る。後者は**錯覚の存在を露呈させる**。20°の狭さは、この露呈のための解像度である——広ければ世界に見える。狭いから、これは世界ではないと分かる。

### III-4. 高次化の第三段：上達不能の矛盾の溶解

断裂③の矛盾——「AIが常に上回るから上達しない」vs「作りたいを目覚めさせる」——は、**上達の対象を取り違えていた**ために生じた。

- ループ内（プレイ中）の上達は、AIが境界を更新する限り**原理的に不可能**。正しい。
- しかしループの**外**にある対象——**「自分の重力の感じ方のモデル」そのもの**——は、毎回解像度が上がる。

つまり本機に上達はない。**あるのは解像度の上昇である。** プレイヤーはゲームを攻略しない。**自分の重力の感じ方の輪郭が、毎回少しだけ鮮明になる。**

そして解像度が閾値を越えた瞬間、人はゲームを続けることをやめ、**モデルをいじり始める**。これが「作りたい」の発生点である。発生させるのは面白さではない。**不可解さ**——「なぜ私の重力の感じ方はこの形なのか」。AIが自分について知っていることを、自分は知らない。この非対称が、観察者を生み、観察者が設計者になる。

**これが構想の中心命題——「AI自身の性質をゲームデザインに反映する」——の唯一の非トリビアルな解である。** AIの性質とは、生成でも個別化でも一回性でもない（それは表層）。**AIの性質とは、本人にも見えないパターンを見つけ、説明できないまま提示する能力**である。本機はその能力を、身体という最も説明不能な媒体を通して漏らす。ガチャ（System1の搾取）との差はここだ——本機は、System1（前庭・反射）を使ってSystem2（自分の身体のモデルを推論する）を成立させる。構想の言い方をそのまま設計に写すと、これになる。

### III-5. 高次化の第四段：統合された遊具仕様の骨格

以上の止揚から、設計判断が自動的に確定する。

**名称**：**『シタオリ』**（「重力の感じ方」を織り、また読む、の重義）。読む（推定）と織る（生成）が同一ループであることを名が示す。

**1プレイ 90秒（3相）**：
- **相1「読まれる」0–30秒** — 座るだけ。台は±3°で微動。AIは姿勢・呼吸・補正から「あなたの重力の感じ方」を推定する。プレイヤーは**何もしない**。ここで「自分が読まれている」ことを知る。
- **相2「織られる」30–75秒** — AIが重力の感じ方を書き換える。プレイヤーは抗ってもよく、委ねてもよい。**抗いは補正動作として読まれ、委ねは順応として読まれる。どちらも入力である。** ここで断裂①が溶解する：能動性の席は手ではなく「抗うか委ねるか」にあり、しかも選ばなくても成立する（implementerの生存条件を保存）。
- **相3「返る」75–90秒** — 台は中央へ。BODY TAPE と、AIが読んだモデルの一行（「あなたは右に0.18秒先回りする」）が出力される。

**機構の確定事項**：
- 座位・骨盤のみ拘束・上半身非拘束（designerの「抗い」を残し、立位転倒を捨てる）。座面高は低く、足は常時接地。
- ゲーム内上限±15°、実使用±3〜15°。**20°は使う範囲ではなく、非拘束の人間が載るための安全マージンとして消費する**（visionaryの定式化を採用）。
- クランプ初期値220〜803／スルーレート制限／100msハートビート／起動時原点復帰／例外時中央復帰／物理非常停止は複数箇所・独立系統。
- 1000Wピーク対策：三相合計90秒のうち、実際に運動するのは約45秒。デューティ50%以下を設計値とする。
- 出力は台横の記録板とQRに限定。**画面は台の動きを説明しない。結果の一行だけを出す。**

**移植の再定義**：BODY TAPE は別の台で再生できる。ここで strategist を保存しつつ否定する。**「他人の重力の感じ方を買う」のではなく「他人の重力の感じ方と並べる」。** 25kgの子の重力の感じ方と90kgの大人の重力の感じ方が、同じ列に並ぶ。所有ではなく**列挙**。

**成果指標の再定義（humanistの規範を実行可能にする）**：回転率は制約として扱い（90秒＋15秒リセット＝1時間約34人）、目的指標は**「降りた人が何と言ったか」の記録**とする。台の横に、降りた人の一言だけを書き残す場所を置く。これは計測ではなく**蓄積**であり、次に乗る人の入力になる（futuristの「列が遊びの一部になる」の実装）。

**失敗の扱い**：転倒は設計に含めない。代わりに**「重力の感じ方を見失った瞬間」を検出して記録に残す**。designerの「失敗＝最高の喝采」を、痛みと恥から切り離して保存する。失敗が身体の外に記録され、他人に渡せる形になる——**恥の外部化**。

**呼称**：本機は「ゲーム」ではなく**「重力の感じ方の測定器」／「身体の工作室」**として提示する。これは構想が抱えていた風営法上の呼称問題に対する、止揚から導かれる回答である。ゲームセンターに置かれるが、ゲームと呼ばない。**遊具でありながら制作装置であるため、呼称をどちらにも寄せられない**——この宙吊りが、法的にも体験的にも正しい位置である。

## IV. 超越的視点 — 対立ですらなかった次元

八草案は「**誰の重力の感じ方か**」を争っていた。自分の重力の感じ方（designer, differentiator）／他人の重力の感じ方（strategist, futurist）／重力の感じ方の帰属（storyteller）／重力の感じ方を手放す（visionary）。

**だが重力の感じ方は、そもそも誰のものでもない。**

前庭系が受け取る「重力の感じ方」は、身体が環境から借りている暫定解にすぎない。回転する部屋に入れば数分で書き換わる。無重力では消える。重力の感じ方は身体の内側にあるのではなく、**身体と環境のあいだに一時的に成立している合意**である。

だとすれば——「重力の感じ方の簒奪」「重力の感じ方の帰属」「重力の感じ方の移植」は、**存在しない所有権をめぐる争い**だった。台がやっているのは簒奪ではない。**重力の感じ方が借り物であることを露呈させること**である。

この次元に立つと、もう一つの対立が溶ける。**AIと人間の対立**である。

AIは学習データという他人の重力の感じ方を借りて動いている。人間は環境から借りた重力の感じ方で立っている。**両者は同じ構造を持つ。** 八草案は「AIが人間の重力の感じ方を読む」という非対称を前提にしていたが、その非対称は実在しない。AIがやっていることを、人間の身体で再演しているだけである。

だからこの台は、**AIの性質をゲームデザインに反映する**という構想の命題に対して、最も文字通りの答えを出す——**AIがやっていること（他人の重力の感じ方を借り、パターンを見つけ、説明できないまま出力する）を、人間が自分の身体でやってみる場所**。ここでは設計者と被設計者、所有者と被所有者、AIと人間の区別が同時に溶解する。

そして最後に残るのは、この一文である。

**この台の完成形は、台の上で遊ぶことではない。台を降りて、自分の重力の感じ方を書き始めることである。**

「作りたい」を目覚めさせる、という構想の最終目的と、ゲーム設計が、ここで初めて同一になる。

## V. 後続工程への申し送り（未確定・要検証）

止揚は結論の一部を未確定のまま残してよい。以下は実機で決着すべき点である。

1. **非拘束の人間が±15°で転倒しないか** — 座位・骨盤拘束・上半身自由の組み合わせで、相2の「抗い」が安全域に収まるかは実機試験を要する。ここが破綻すれば相2の設計は縮小を強いられる。
2. **「抗う／委ねる」がAI入力として分離可能か** — 補正動作と順応は筋電・重心・呼吸から分離できるという前提。未検証。
3. **体格差の再合成が「同じ知覚量」になるか** — strategistの堀の主張は、この一点に全体が依存する。実機で検証できなければ、ただの揺れる椅子に戻る。角度スケーリングの同定は最優先の実験である。
4. **電源断時に中央へ戻らない問題** — visionary が指摘した通り。手動リリース構造は必須要件として設計に含める。
5. **ウォッチドッグ15秒・クランプ220〜803** — 単一情報源。実機で追測する。
6. **デューティ50%以下で発熱・摩耗が公共運用に耐えるか** — H3は本来1日2〜3時間の個人ホビー想定。公共連続稼働は想定外であり、保守周期の実測が要る。
