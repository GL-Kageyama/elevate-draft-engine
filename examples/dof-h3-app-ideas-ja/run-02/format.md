# 出力形式（OutputFormat）

- 成果物種別: コンセプト設計書（遊具・体験設計仕様）
- 説明: AIを核とした体感ゲーム用モーションプラットフォームを、公共空間で子どもを含む不特定多数が安全に遊べる遊具として成立させ、かつレーシング／フライトシミュレータの焼き直しではない独自の遊戯体験として、機構・AIの役割・運営条件まで一貫して具体化した設計文書。
- 出力長の範囲: 1800〜6000 字
- 成果物そのもの: いいえ（成果物についての分析）

## 草案の形式指示（draft_guidance）

草案は以下の要素を、思いつきの羅列ではなく相互に整合する設計として書く。(1)遊戯体験の核：プレイヤーが何をし、何が身体に返ってくるか（1プレイ30〜90秒程度の描写で）。レーシング／フライトの「操縦して速さを競う」構図を明確に否定し、何を代替するのかを一文で言い切る。(2)AIが核である必然性：AIがリアルタイムに何を生成・認識・適応しているか（例：プレイヤーの動きの癖の認識、他プレイヤーや観客を含む集団の状態に応じた難易度・展開の生成、失敗の面白さへの変換）。AIを外したら成立しない理由を明示する。(3)モーションプラットフォームの機構：可動軸、自由度、可動範囲、駆動方式、プレイヤーの拘束／非拘束、転倒・挟まれ・可動域外への対策。数値は根拠の伴う範囲で置く。(4)公共空間での成立条件：子どもの体格差への適応、順番待ちとターン設計、一人用か複数同時か、観客の巻き込み方、衛生、騒音、設置面積、電源、連続稼働とメンテナンス、故障時の安全停止。(5)差別化の明示：既存の体感アトラクション（レーシング／フライト系）との差を、入力・出力・体験の三点で対比する。草案段階では複数の体験案を出してよく、各案に「AIが担う中核」「身体に返る感覚」「公共空间での成立条件」を必ず添えること。

## 最終化の形式指示（finalize_guidance）

最終成果物は一枚の設計書として、以下の見出しをこの順で備える。①『コンセプト名と呼称』——遊具として子どもが口にできる名前と、一言の体験定義。②『遊戯体験の核』——プレイヤーの行為と身体に返る感覚を、1プレイの時間経過に沿って描写。レーシング／フライトの焼き直しではないことを、この節で明示的に否定形で述べる。③『AIの中核』——AIがリアルタイムに行う認識・生成・適応を箇条書きで列挙し、AIを除いた場合に何が成立しなくなるかを一文で示す。④『モーションプラットフォーム機構』——可動軸・自由度・可動範囲・駆動方式・拘束方式・安全機構（非常停止、挟まれ防止、可動域制限、体重・身長適応）を、数値または数値の置き方の根拠とともに記述。⑤『公共空間での成立条件』——子どもの体格差への適応、順番待ちとターン設計、同時参加人数、観客の関与、衛生、騒音、設置面積・電源、連続稼働、保守、故障時の挙動。⑥『差別化』——入力・出力・体験の三点で既存の体感アトラクションと対比する表または対比記述。⑦『未解決事項』——実現に必要な検証項目（安全基準、コスト、技術的前提）を列挙。全体を通じて、材料として与えられた止揚の基盤のみを用い、それを超える推論は加えない。断定できない箇所は断定せず、検証項目として⑦に送る。
