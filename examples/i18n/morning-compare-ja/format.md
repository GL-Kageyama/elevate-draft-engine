# 出力形式（OutputFormat）

- 成果物種別: 朝のルーティーン設計書
- 説明: 個人の生活スタイルに合わせて実行可能な朝のルーティーンを、具体的な時間割と目的・効果とともに提示した実用的なプラン。
- 出力長の範囲: 500〜1500 字
- 成果物そのもの: いいえ（成果物についての分析）

## 草案の形式指示（draft_guidance）

草案執筆者への指示：朝のルーティーンの各要素（起床時刻、水分補給、運動、瞑想、朝食、計画立てなど）を列挙し、それぞれに理由と期待効果を添えて。さらに、想定する生活パターン（仕事開始時刻、通勤時間、家族の有無など）を仮定し、時間割形式で草案を作成。余裕を持たせるためのバッファ時間や、休日／平日の別、失敗した日のリカバリー案も含める。

## 最終化の形式指示（finalize_guidance）

最終化工程への指示：最終成果物は以下の構成を満たすこと。(1) タイトル「朝のルーティーン設計」と対象読者の想定、(2) ルーティーン全体の目的（例：心身の安定、生産性向上）を明確にした導入、(3) 具体的なタイムスケジュール（例：6:00起床 → 6:05ストレッチ → 6:15水分補給 → 6:30瞑想 → 7:00朝食 → 7:30計画立て → 8:00出発）を表形式または箇条書きで提示し、各ステップに所要時間・内容・効果を明記、(4) 継続のための調整ポイントや代替案（例：時間がない日は短縮版）、(5) 注意点（無理のない設定、睡眠時間の確保）。全体を読みやすく前向きなトーンでまとめ、500字以上1500字以内とする。
