# 朝のルーティーン設計——「初期条件」を整えて、一日の著者になる

**対象読者：** 朝を「こなすだけ」で終わらせたくない、忙しい社会人。

## 目的
朝は「何をするか」の時間配分ではなく、その後の一日全体を決める「初期条件」を設定する時間です。身体の安定、行動の焦点、意味づけの三つを調律することで、ゆらぎがあっても地に足の着いた一日になります。

## 基本設計（1時間30分コース）
朝の三つの位相――身体、行動、意味――を調整します。どの位相を優先するかは、毎朝の状態診断で変えます。

| 時間 | 内容 | 効果 |
|---|---|---|
| 6:30 | **起床・状態診断（1分）** ①睡眠・疲労 ②今日外せない締切 ③「意味」の衰えを確認し、優先位相を決める | その日の朝を機械的にせず、メタ判断力を働かせる |
| 6:31 | **生理的調整（15分）** カーテンを開けて光を浴び、白湯を飲み、全身をゆるめる軽いストレッチ。スマホはまだ見ない | 神経系の安定、水分と血流の回復 |
| 6:46 | **余白（5分）** 何もしない。窓辺で外を見る、座って呼吸を感じる | 設計しきれない受容性。言葉にならない「世界がある」感覚 |
| 6:51 | **作用的調整（10分）** 今日の「高レバレッジな唯一のこと」を一つ選び、いつ・どこで・何のためにやるかまで決める | 注意資源の集中、意志力の節約 |
| 7:01 | **物語的調整（5分）** 「今日は〇〇の一日」と一行書く。完璧でなくても、著者として選んだ感覚を確認 | 一日が体験としての厚みを持ち、逸脱も物語の変奏になる |
| 7:06 | **朝食（20分）** ながら食べをやめて、噛むことに集中 | 消化と満足感、マインドフルネス |
| 7:26 | 身支度・出発 | ゆとりを持って一日を始める |

## 短縮版（10分）
時間がない日は、罰としての縮小実行ではなく「現在地から再診断」します。

1. 状態診断（1分）
2. 白湯を飲む（2分）
3. 今日の「唯一のこと」を決める（5分）
4. 「今日はこんな一日」と心の中で言う（2分）

これだけでも行動と意味の位相は回復します。

## 継続のための調整ポイント
- 睡眠不足の日は、生理的調整と余白を優先。行動・物語は軽く。
- 締切が迫っている日は、作用的調整を最優先。物語は後でもよい。
- 「何のために生きているのか分からない」日は、物語的調整を最優先し、「唯一のこと」を丁寧に選ぶ。
- 毎日同じ時刻でなくてよい。目覚めたときが、その日の朝です。

## 注意点
- 睡眠時間を削らない。起床時刻は就寝時刻を先に決めて逆算する。
- 最初から完璧を目指さない。1日1モジュールでも、続けば十分。
- 失敗した朝は、縮小版を「罰」としてやらない。10分使えるなら短縮版、それすら無理なら全放棄して、いまの状態から再調整する。
- 朝の激しい運動や情報摂取は神経系の過剰な刺激になるため、基本は行わない。

朝のルーティーンは「同じことの反復」ではなく「選択の錬磨」です。毎朝、自分を診断し、いま必要な位相を選び直す。それ自体が、充実した地に足の着いた一日を生む土台になります。
