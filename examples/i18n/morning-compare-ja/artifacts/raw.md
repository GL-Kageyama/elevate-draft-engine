# 朝のルーティーン設計

**対象読者**: 社会人・学生、毎日をなんとなく過ごしてしまう人、朝から集中したい人

## 目的

朝のルーティーンは、心身を整え、その日一日の「軸」をつくる時間です。朝のうちに自分をケアすることで、ストレスがへり、集中力・判断力が高まります。さらに、小さな成功体験を積み重ねることで「今日もやれる」という自信につながります。無理のない範囲で続けることで、地に足の着いた充実した一日をつくりましょう。

## タイムスケジュール

| 時刻 | 所要 | 内容・効果 |
|---|---|---|
| 6:00 | 5分 | 起床。カーテンを開けて自然光を浴びる。体内時計がリセットされ、目が覚めやすくなる。 |
| 6:05 | 5分 | 水分補給。コップ一杯の水を飲む。胃腸と脳が目覚め、代謝がアップする。 |
| 6:10 | 10分 | ストレッチ。肩・首・腰をゆっくり動かす。血流が促され、体が軽くなる。 |
| 6:20 | 5分 | 瞑想・深呼吸。背筋を伸ばし、呼吸に意識を向ける。不安や雑念を手放し、集中力が高まる。 |
| 6:25 | 30分 | 朝食。卵・ヨーグルトなどのタンパク質と野菜や果物をとる。血糖値が安定し、午前中のエネルギーになる。 |
| 6:55 | 25分 | 身支度。服を選び、身だしなみを整える。気持ちが切り替わり、「今日のモード」になる。 |
| 7:20 | 10分 | 計画立て。今日やることを3つ書き出し、優先順位をつける。迷いや無駄な時間がへる。 |
| 7:30 | 30分 | 余白。時間に余裕をもって出発準備をする。心の余白も生まれ、予想外の出来事にも対応しやすくなる。 |
| 8:00 | - | 出発。 |

## 継続のための調整ポイント・代替案

- 前日夜に服や鞄の準備をしておくと、朝は余裕が生まれます。
- 時間がない日は「短縮版」を用意しましょう。起床→水分補給→軽いストレッチ→深呼吸→朝食だけでも15分でできます。
- 瞑想の代わりに、朝散歩を取り入れるのもおすすめです。外の光と空気を浴びると、リフレッシュ効果があります。
- 最初から完璧にやろうとせず、「ひとつだけ取り入れる」ことから始めましょう。
- 自分の生活リズムに合わせて、時刻や順序は自由に入れ替えてOKです。

## 注意点

- 睡眠時間を削らないこと。就寝時間も固定し、6時間以上の睡眠を確保しましょう。
- 無理のない設定にすること。早起きがつらい日は、起床時間を少し遅らせてください。
- できなかった日があっても、落ち込まず、翌日にまた戻れば大丈夫です。

朝を整えると、一日の質は大きく変わります。あなたらしい無理のないルーティーンを育てていきましょう。
