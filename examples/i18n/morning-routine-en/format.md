# Output format (OutputFormat)

- Deliverable type: morning routine plan
- Description: A structured, chronological morning routine with specific time blocks, activities, and purposes designed to create productivity and emotional groundedness for the day.
- Output length range: 1200–3500 chars
- Deliverable itself: yes (output_is_direct)

## Draft format guidance (draft_guidance)

Write 3 rough skeleton variants of the routine as fragments: each with a working title, a rough timeline (e.g. 6:00–8:30), the main activity blocks (wake, hydrate, center, move, plan, eat), and a one-sentence thesis for why that variant grounds and energizes. For each variant also note one specific grounding cue and one key productivity anchor.

## Finalization format guidance (finalize_guidance)

Select one skeleton and finalize it as a complete morning routine. Include these sections: (1) Overview — the time range and core intention of the routine; (2) The Routine — a step-by-step list with time, duration, action, and the purpose of each step (include wake, water, mindfulness/breath, movement/stretching, reflection/gratitude, priority planning, and nourishment); (3) Grounding Elements — specific practices that keep you calm and present; (4) Productivity Tools — how to set the day's top priorities before starting work; (5) Make It Work — tips for adapting the routine to real life, such as flexible start times and minimal versions for busy days. Use present tense, direct commands, and a calm yet energizing tone.
