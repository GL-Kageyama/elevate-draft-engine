# 朝のルーティーン再設計——「前夜の自分を信じろ」プロトコル

## 核心的主張
朝の目的は一日を特別にすることではない。「選ばなくても動ける平凡な一日」にすることだ。朝に「今日はどんな自分として生きるか」を宣言するな——午前11時には嘘になっている。夜に決めた「最初の一手」を、朝の自分は黙って引き受けるだけでよい。

## 根拠
- 朝の自己宣言は「今日の自分」のつもりで、かっこいい自己物語であり、現実の資源（睡眠・血糖・家族）と衝突する。
- 意志力は朝から有限で、朝に選ぶほど昼に選べなくなる。
- 地に足が着くのは固定だからだ。ルーティーンは足場の固定装置である。

## 前提
朝の判断力は夜より低いので、夜に済ませた判断を引き継ぐのが朝の唯一の仕事である。

## 草案

「充実した地に足の着いた一日」とは、こなした量が多い一日ではない。**朝に選択を消耗せず、夕方に「外せないものを外さなかった」と確認できる一日**。起床時刻は固定しなくてよい。固定するのは前夜の「最初の一手」だ。

### 要素
1. **両足接地**（1分）: ベッドの上で呼吸するな。立ち上がり、素足で床の温度を感じる。覚醒は姿勢の問題。
2. **前夜の預金の確認**（2分）: 前夜に手書きで決めた「最初の一手」を開く。気分で書き換えない。
3. **水分と光**（3分）: 水を飲み、窓を開けて光を浴びる。カフェインより先に身体を物理的に起こす。
4. **外せない約束の確認**（2分）: カレンダーで今日の締切・約束を確認する。充実は外せないことに足を取られて生まれる。
5. **最初の着手**（10〜30分）: 要素2の一手を頭を使わず開始する。意図の宣言より、開始が一日の質を決める。

### バリエーション
- **通勤のある平日**: 1〜4を7分で済ませ、5を10分だけやる。スマホは駅まで触らない。
- **在宅・余裕のある朝**: 1→3のあと、前夜に決めたコースを15分散歩し、2→4→5と続ける。ゆっくりするほど選択肢を減らす。
- **家族がいて計画が崩れる朝**: 個人の静寂を守ると失敗する。水と背伸びを家族と共有し、「最初の一手」も前夜に家族へ宣言しておく。崩れても、水を飲んで前夜ノートを開けばいい。朝が弱いほど夜の自分に頼れ。
