**目的**
朝を「内側への折り返し」と「世界への折り返し」という二重の始発の場にする。外的成果と内的充実を対立させず、一日の主体を自分に取り戻し、地に足の着いた一日を立ち上げる。

**前提と準備**
- 前夜5分で「明日の主契約」＝今日の物語の一章を一つ決め、その「最初の一手」をノートに書いておく。
- ノートは枕元に置き、スマホは視界に入らない場所で充電する。

**手順（通常版・合計17分）**

| 時間 | 行動 | 目的 |
|---|---|---|
| 1分 | 呼吸3回・素足で立つ | 姿勢と呼吸で身体の軸を確立する |
| 2分 | 水を飲み、窓を開け、光を浴びる | 生理を外界のリズムに同調させる |
| 1分 | ノートに「今の感情」を一言書く | 内省を「判断」でなく「観察」にとどめ、意志力を温存する |
| 2分 | 主契約を読み、「今日の題名」を書く | 前夜の決定を今朝の状態で再解釈し、一日を統一する |
| 10分 | 主契約の最初の一手を開始する（完了は目指さない） | 前進を朝に置き、後の時間をその延長線上に変える |
| 1分 | 予定表で主契約の位置を確認し、家族と一言交わす | 世界と接続し、実行可能性を確かめる |

工程1〜4が「内側への折り返し」、5〜6が「世界への折り返し」。折り返しの順序が骨格であり、時間の長さは日々変えてよい。

**調整のためのヒント**
- 平日・時間がない朝（約10分版）：各工程を短縮し、着手を4分に。順序だけは必ず守る。
- 休日（約60分版）：内側の折り返しを散歩・瞑想・読書に20分、外側の折り返しを主契約に45分。題名を決めてから動くと、一日全体が一つの章として味わえる。

**よくある障害と対処**
- 寝坊した→10分版で十分。「時間量」より「二つの折り返しを完了したか」が基準。
- 気分が乗らない→着手は「開始」でよく、10分でやめてもよい。
- スマホを触ってしまう→別室充電など物理的距離を作る。ノートは枕元へ。
- 家族の急病などで崩れた朝→題名を「回復」に変え、主契約を「家族への最初の一手」に再定義する。折り返しが逆転しても、構造は揺るがない。

**心構え**
朝は「今日を誰が演じるか」を定める儀式である。世界の側に立つのも、自分に閉じこもるのも偏りだ。両者の軸を一度、まっすぐに立て直す。それだけで、その日はすでに地に足が着いている。
