# 朝のルーティーン：地に足を着けて、一日を自分のものにする

## フルバージョン（約60分）

**ブロック1: 静寂の3分**（起床直後・3分）
布団の中で目を閉じたまま、呼吸を3回だけ深くする。「今日は自分のペースで始める」と心で唱える。
→ 情報が入る前の「無」を確保し、起き抜けを他人の音や通知に奪われない。自分の内側から始まる感覚が、一日の土台になる。

**ブロック2: 水分と光**（5分）
コップ一杯の水を飲む。カーテンを開けて、太陽の光を浴びる。
→ 体の水分を補い、体内時計をリセットする。光が入ることで部屋の空気が変わり、「今日は今日だ」という現実への接地が起きる。

**ブロック3: 身体を動かす**（10分）
ストレッチ、腕立て、スクワットなど、好きな動きを10回×3セット。テンポよく、呼吸を止めない。
→ 血流が回り、心拍数が上がる。身体が目覚めることで「考えすぎる頭」から「今ここにある体」に軸が移る。不安は身体が動けば消える。

**ブロック4: 散歩or日光浴**（15分）
外に出て、歩く。天気や風を肌で感じる。近所の景色を片っ端から見る。
→ 外の空気は「世界は相変わらず回っている」という安心感をくれる。太陽の光でセロトニンの土台を作れば、午後の気分が安定する。

**ブロック5: 手帳を開く**（10分）
紙の手帳に「今日の予定」「やりたいこと3つ」「手放すこと1つ」を書く。スマホではなく、紙に書くこと。
→ 思考が言葉になり、言葉が文字になる。「充実」は見える形にするとはじめて現実化する。手放すことを明確にすると、一日の心の負担が減る。

**ブロック6: 意図の表明**（7分）
鏡の前で、今日の最小ゴールを口に出して言う。「今日は〜をする」と決める。
→ 声に出すことで、脳はその命令を「実行するもの」として認識する。人生の主導権を自分に戻す瞬間。

**ブロック7: 朝ごはん**（10分）
きちんと噛んで食べる。味わって。スマホは見ない。
→ 食べ物が身体に入っていく感覚に集中すると「生きている」という実感が持てる。一日に一度は「ただ食べる」ことに全霊を注ぐ行為が、精神を落ち着かせる。

## ミニバージョン（時間がない日・15分）

1. **水を飲みながら窓を開ける**（2分）：部屋に空気と光を入れる
2. **スクワット10回＋ストレッチ**（5分）：血流を回し、身体を起こす
3. **手帳に「今日の3つ」を書く**（5分）：予定・やりたいこと・手放すこと
4. **朝ごはん＋コーヒー**（3分）：一口目を味わって食べる

### 早起きできた日のおまけ
散歩の代わりに、公園のベンチで5分ぼーっとする。何もしないことは「生産性の敵」ではなく「心のスペースの確保」だと理解すること。ぼーっとする時間から、後で大切なアイデアが出てくる。
