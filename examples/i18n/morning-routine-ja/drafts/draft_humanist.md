# 朝のルーティーン「自分に戻る朝」

朝は「やることを詰め込む時間」ではなく、**あなたが今日を生きるための土台を育てる時間**。完璧にやる必要はない。でも、この順番をなぞるだけで、心が静かになり、体が目覚め、今日が「なんとなく流される一日」ではなくなる。

---

## 5〜7の行動ブロック

### 1. 静寂の2分（2分）
- **行動**: 目が覚めたら、スマホに手を伸ばさず、そのままベッドで2回、ゆっくり呼吸をする。手を腹に置いて、体の存在を感じる。
- **時間の目安**: 2分
- **なぜ**: 起床直後、脳はまだ夢と現実の境界にいる。この静寂が「今日はここから始まる」と体に教え、1日の中で最初の選択を自分の意志で行えるようにしてくれる。

### 2. 水分と光（3分）
- **行動**: コップ一杯の水を飲み、カーテンを開けて日光を取り込む。
- **時間の目安**: 3分
- **なぜ**: 水は寝ている間に渇いた体を目覚めさせ、光は体内時計に「昼だ」と知らせる。体が物理的に「起きる」ことで、気分も自然と地表に戻ってくる。

### 3. 体をゆらす（5〜10分）
- **行動**: 伸びをする、その場で足踏みをする、肩を回す。気持ちいいと感じる範囲で、無理なく体を動かす。
- **時間の目安**: 5〜10分
- **なぜ**: 激しい運動は朝には必要ない。血流を穏やかに回し、「ああ、ちゃんと体がある」と感じることが大切。これは思考に先立って、自分の存在を地に足の着いたものにする。

### 4. 心の書き出し（5分）
- **行動**: ノートに、今頭に浮かんでいることをとにかく全部書く。不安でも、とりとめがなくてもOK。書き終えたら、その中から「今日、一番気になっていること」に丸をつける。
- **時間の目安**: 5分
- **なぜ**: 頭の中にあるモヤモヤは、外に出さない限りずっと同じ場所で回り続ける。書き出すことで、感情を「自分の一部」ではなく「見たもの」として扱えるようになり、心に余白が生まれる。

### 5. 今日の「軸」を決める（3分）
- **行動**: 「今日は何をするか」ではなく、「今日はどうありたいか」をひとつ決める。例:「焦らない」「よく聴く」「ひとつのことに丁寧に向き合う」。
- **時間の目安**: 3分
- **なぜ**: To-Doリストは行動を縛るが、軸は行動を自由にする。予定が崩れても、軸さえあればあなたは迷わない。これが「充実した一日」の正体。

### 6. 温かいものと朝の空気（10分）
- **行動**: お茶かコーヒーをゆっくり飲みながら、窓を開けるかベランダに出て、外の空気を吸う。
- **時間の目安**: 10分
- **なぜ**: 温かい飲み物は体の内側からほぐし、外の空気は頭の中をリセットする。今日という一日が、自分ひとりのものではないことをふと思い出させてくれる。それが、ちょうどいい距離感を生む。

### 7. その後の流れを確認（2分）
- **行動**: 今日の予定をカレンダーで見て、最初の予定までに何をすればいいかを「次やること」だけ決める。
- **時間の目安**: 2分
- **なぜ**: 一日の全体像を把握すると不安が減る。「最初にやること」だけ決めておけば、朝のうちから「これから何をすればいいんだっけ？」という迷いで消耗しなくて済む。

## 代替案

### 時間がない日のミニバージョン（10分）
1. 深呼吸 → 水を飲む → カーテンを開ける（2分）
2. 体を大きく伸ばす（3分）
3. ノートに「今日の軸」だけ書く（3分）
4. 最初の予定を確認（2分）

→ 短くても、**静寂 → 体 → 心 → 方向**という順番は崩さない。これが崩れると、またスマホに飲み込まれる一日になる。

### 早起きできた日のフルバージョン（60分）
- 静寂の5分 → 水分と光 → 近所を20分歩く → 書き出し10分 → 軸を決める → ゆっくり朝ごはん → 読書5分

→ 時間がある日は、**体を動かす時間と、心を満たす時間を多めに**。頑張る日の朝ではなく、充電のために使う朝。これは贅沢ではなく、必要な整備である。

---

朝を制するのではなく、朝に戻ってくる。それが、一日を充実させ地に足を着けるためのいちばん誠実な方法だ。
