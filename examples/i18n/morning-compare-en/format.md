# Output format (OutputFormat)

- Deliverable type: morning routine plan
- Description: A concrete, actionable morning routine that sequences grounding and productivity practices into a timed schedule.
- Output length range: 900–3000 chars
- Deliverable itself: yes (output_is_direct)

## Draft format guidance (draft_guidance)

Brainstorm fragments: 3–5 candidate activities for grounding (e.g., meditation, journaling, stretching, gratitude) and 3–5 for productivity (e.g., planning, deep work block, exercise, reading). For each candidate note its purpose and rough duration. Sketch 2–3 possible orderings, including a coherent flow from wake-up to start of workday, with buffer time.

## Finalization format guidance (finalize_guidance)

Present the final routine as a structured schedule with clearly labeled sections: 'Core Principle' (one sentence), 'The Routine' with time blocks (e.g., 6:30–6:40 Hydrate & Sunlight, 6:40–7:00 Mindfulness, 7:00–7:30 Movement, 7:30–8:00 Planning & Priorities, 8:00–8:30 Breakfast, 8:30 Start Work), each block naming the activity, its grounding or productive purpose, and a quick 'why it works'. Include an 'Adaptations' section for busy days/weekends and a 'Non-negotiables' list of 2–3 elements that must remain even in a shortened version.
