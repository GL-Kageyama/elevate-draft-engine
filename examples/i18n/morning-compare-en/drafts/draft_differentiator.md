**Core:** No phone for first 30–45 minutes; order by day's heaviest task, not habit-stacking.

**Brainstorm fragments**

Grounding:
- No phone (0–30m): stop input
- Box breath (3m): lower arousal
- Regret rehearsal (5m): imagine worst case; name regret
- Cold-water face (3m): snap out of anxiety

Productivity:
- Lump task block (25–45m): hard work before email
- Plan/reject (10m): choose one aim, one refusal
- Eat frog (5–10m): dreaded call/email first
- Movement snack (10m): blood flow, not gym

Orderings:
1. Deep-work day: wake → no phone → breath → lump 25m → movement 10m → plan/reject 10m → breakfast → 15m buffer → start.
2. Hard-talk day: wake → no phone → regret 5m → eat frog 10m → cold water 3m → plan one outcome 5m → breakfast → 15m buffer → start.

Premise: You control the first 45 minutes; otherwise no routine, only reaction.
