## Brainstorm Fragments

**Grounding candidates**
- **Meditation (10 min)** — settle attention; reduces reactivity.
- **Journaling (5 min)** — clarify emotional state; externalize noise.
- **Stretching / mobility (10 min)** — release sleep stiffness; body awareness.
- **Gratitude list (3 min)** — resets perspective; lowers anxiety.
- **Breathing exercise (5 min)** — quick nervous-system regulation.

**Productivity candidates**
- **Planning (10 min)** — choose top 1–3 priorities; set intention.
- **Deep work block (90 min)** — high-cognitive output before decisions drain you.
- **Exercise (20–30 min)** — energy, focus, discipline.
- **Reading / learning (15 min)** — input before output; mental activation.
- **Cold shower (5 min)** — wakefulness and mental toughness.

## Possible Orderings

**A. Grounded-First Flow**
- 6:30 wake · hydrate
- 6:35 breathing (5)
- 6:40 meditation (10)
- 6:50 journaling + gratitude (8)
- 6:58 stretch (10)
- 7:08 breakfast / shower
- 7:30 plan (10)
- 7:40 buffer / commute
- 8:00 start workday

**B. Deep-Work-First Flow**
- 6:00 wake · hydrate
- 6:05 light movement (5)
- 6:10 plan (10)
- 6:20 deep work block (90)
- 7:50 breakfast / shower
- 8:15 meditation (10)
- 8:25 buffer / review
- 8:45 start workday

**C. Energy-Builder Flow**
- 6:15 wake · hydrate
- 6:20 exercise (25)
- 6:45 shower / cold rinse
- 6:55 gratitude + journal (5)
- 7:00 breakfast
- 7:20 reading (15)
- 7:35 plan (10)
- 7:45 buffer
- 8:00 start workday

**Recommended default:** B if you have a high-cognition job; A if you tend toward anxiety or rushing; C if you need physical activation to feel awake. Add buffer after any transition — never plan to the minute.
