# 『Maru』标语候选

1. **海を、履いて走る。**  
  意图：把「海岸回收PET」变成一双脚上的具体画面，材料不再抽象，而是可穿、可跑、可炫耀。

2. **一足の靴になるために、海を漂ってきた。**  
  意图：为这双鞋赋予前世今生的故事，让消费者能对着朋友说：「你知道吗，这双鞋曾经是大海里的塑料瓶。」

3. **拾った海が、今度はあなたを運ぶ。**  
  意图：从「我们捡起海里的垃圾」到「鞋子承载你去跑步」形成转折，把守护与使用纳入同一条循环的故事线。

4. **海を守るって、走ることでもできる。**  
  意图：直接把品牌价值变成一句平视的行动口号，把环保从沉重义务转化为跑步这件小事，便于在社交平台引用。

5. **速いだけじゃ、海は守れない。**  
  意图：与功能强悍但环保薄弱的竞品划清界限，让「有意义的速度」成为可被转述的态度宣言。
