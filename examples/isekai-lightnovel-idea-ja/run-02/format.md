# 出力形式（OutputFormat）

- 成果物種別: 小説企画案
- 説明: 異世界モノのライトノベルとして読者を惹きつけ、そのまま執筆・連載へ移せる完成度で、独自の設定・主人公・フックを備えた一つの具体的な作品アイデア。
- 出力長の範囲: 800〜2200 字
- 成果物そのもの: はい（output_is_direct）

## 草案の形式指示（draft_guidance）

創作系の骨子として、個々の草案は作品の「核」を簡潔な断片で提示せよ。必須要素は、(1) 異世界転移・転生の設定そのものに斬新さがある独自フック、(2) 舞台となる異世界のルールやギミック、(3) 主人公の属性と内面の葛藤・欲望、(4) 第一幕のあらすじ（どう巻き込まれ、何が賭けられるか）。(5) 既存テンプレ（俺TUEEE、ハーレム、追放ざまぁ等）からの差別化点を一文で明記すること。物語全文や詳細な章立ては不要で、読者が「続きを読みたい」と感じる切り口の鮮度を優先せよ。

## 最終化の形式指示（finalize_guidance）

最終成果物は「小説企画案」として以下の見出しで構成せよ。①タイトル（仮）②キャッチコピー（1文）③あらすじ（起承の転換点まで、結末の核心は伏せて可）④世界観・設定（異世界の独自ルールとその帰結）⑤主人公（属性・葛藤・動機）⑥独自フック（なぜこの設定が新しいか。Target：読者に届けたい核／Value：面白さの源泉）⑦リスクと回避（テンプレ化・凡庸化の危険と、それを避ける工夫。Risk）⑧シリーズ展開の可能性（Opportunity：単巻の魅力をどう長期化できるか）⑨想定読者。各節は短文で具体性を持たせ、読了後に他者へ「こういう話」と口頭で伝えられる粒度に仕上げること。
