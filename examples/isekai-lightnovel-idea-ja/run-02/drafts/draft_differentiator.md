# 【Differentiator 改修草案】《呑み口》——異世界は、お前の胃袋だった

**核心的主張**: 転生装置を「見送る殉教者」に聖化する《送り火》は甘い。装置を浄化して読者の転生願望を抱きしめる、凡庸な癒やしだ。装置は**捕食者**でなければならない。異世界は実在の行き先ではなく、装置の**胃袋の内壁**に映る消化中の夢。転生者は今も彼の胃の中で溶けながら「冒険」を見ている。

**（1）独自フック**: 転生とは通過ではなく**捕食**。「最初の読者」の願い「物語の中へ入りたい」は、叶い方を間違えた。彼は物語に呑まれる代わりに、**物語を呑む口**になった。以後、異世界転生とは彼の喉を通ること＝喰われること。どの世界も彼の古い夢の残り香にすぎない。

**（2）世界のギミック**: **八つの胃**が、それぞれ違う欲望を別々に消化する——①強さ（俺TUEEE）②承認（無双）③復讐（ざまぁ）④愛情（ハーレム）⑤帰属⑥救済⑦逃避⑧意味。ジャンルのテンプレ欲望がそのまま**餌**。彼は魂の「味」を嗅ぎ分けて落とす胃を選ぶ。消化しきれない魂は反芻され、死に気づかぬまま同じ人生を繰り返す。

**（3）主人公**: **呑み口（のどぐち）**。すべてを呑むが、何の内側にもなったことがない。欲望は「見送られたい」ではない——**喰われ返されたい**。自分より大きな口を探し、見つけるために無限に喰い続ける。腹に千の世界を抱え、一度も抱かれたことがない。

**（4）第一幕**: 踏切で魂を呑もうとした瞬間、喉に**骨**が刺さる。少女・篠宮花は「どこへも行きたくない」のではなく**呑み込めない**。八つの胃のどれも彼女を消化できず、彼は永遠ぶりに噎せる。彼女は泣かず怒り、「お前が食いたいのは何だ」と、誰も問わなかった問いを突きつける。賭け——吐き出して殺せば流れは戻るが、初めて自分の**飢え**を見た者を失う。留めれば彼女が胃壁の内側から彼を喰い始める。望んだ「喰われる」だが、味のわからない石に、だ。

**（5）差別化**: 俺TUEEE・ハーレム・ざまぁの欲望そのものを餌として貪る怪物を主人公に据え、読者に「自分は食われている側だ」と気づかせる——テンプレの主人公像は一作たりとも書かない。

**前提**: 読者がこれまで注文してきた「転生願望」は、実は胃の中からの注文である。
