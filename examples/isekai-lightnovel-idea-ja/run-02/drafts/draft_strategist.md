# 《送り火の値段》——転生に値段を付ける男

**核心的主張**：前回の抒情（「見送られる側になりたい」）は市場で売れない。送り火の最大価値は、転生を「値段を付け、契約し、確実に送る」商売に転化することだ。誰が払うか——死にゆく魂が、記憶・未練・残り時間という最後の財産で払う。これが全巻の満足を担保する。

**(1) 独自フック**：異世界転生は無料の事故ではない。魂は送り屋に査定され、契約を結び、支払って初めて旅立てる取引であり、踏切はその屋号、八つの目は査定・仲介・決済・見届けの機能である。値段が付けられない死（査定不能の「無価値な死」）が来たとき、システムは初めて機能不全を起こす。

**(2) 舞台のルール**：世界と世界の間の「送り市」。魂に数字が浮かび、その数字がそのまま旅券になる。一話＝一件の査定案件（案件もの）。払い過ぎた魂は転生先で身を削り、支払えない魂は永遠に間で腐る——数字の厳密さが毎巻のカタルシスを生む。

**(3) 主人公**：送り屋。冷徹な査定人。過去に一度だけ値段を付けられなかった客＝彼自身の死という未回収債権を抱え、自分の死にだけ数字を付けられない。欲望は「値段なしで見送られること」であり、八つの目は他人の価値を測る器で、自分の価値だけは測れない。

**(4) 第一幕**：査定不能の少女・篠宮花が「どこにも行かない」と値段を拒否して現れる。契約外の客に巻き込まれた送り屋は、商売の根幹「すべての魂には値段がある」の崩壊を賭け、「値段を付けない見送り」という不可能な仕事を始める。

**(5) 差別化**：俺TUEEE・ハーレム・ざまぁの「無料の転生装置」を逆転し、転生に値段と契約を付け、毎巻「誰の死をどう売るか」で読者を満足させる、ジャンル唯一の転生葬儀屋もの。

**前提**：読者が異世界ラノベに払うのは抒情ではなくカタルシスであり、終活・葬儀・供養という実在の巨大市場は物語の外にそのまま金を動かす。
