# 《綴じ目》——ノドの向こうは、誰の手にも読めない

**【独自フック】**
異世界転移の実体は「本のノド」。ページが背に糊付けされて飲み込まれ、もう二度と開かれない、あの谷間である。トラックも召喚陣も病死も、すべて「綴じの儀式」の変形にすぎない。魂はこの読めない場所をくぐる瞬間、異世界という別のページへ繰り込まれる。あなたはこの本を読むとき、無数の魂の綴じ目を指先でなぞっている。

**【異世界のルール】**
異世界は「装丁された一冊」であり、世界の法則はすべて造本に由来する。世界の果ては小口（裁断面）、魔法はインクの滲み、死はページの破れ、運命は綴じ糸の順序。ページをめくる手がなければ世界は静止したまま。ノドに挟まった魂は「誤植」と呼ばれ、校正係に静かに消される。

**【主人公】**
綴師・罫（けい）。ノドの手前で魂を正しく綴じる職人で、八つの道具——目打ち、へら、糸、糊刷毛、断裁刀、折丁台、背当て、罫引き——が八通りの「正しい送り方」を指先に囁く。欲望は「完璧な一冊を仕上げること」。それが己の存在証明。だが彼は「読む」ことが一度もできない。綴る手は持つが、自分でページをめくる目を持たない。ノドの向こう＝読まれる喜びだけが、永遠に彼には閉じている。

**【第一幕】**
完璧に綴じたはずの魂・篠宮花が、ノドの直前で「この綴じ目は私じゃない」と拒否する。生涯の技が初めて否定され、罫は自分が綴ってきた世界の内部へ潜り誤植を探す。そこで見つけるのは、かつて彼自身が「最初の読者」になるはずだった未完の一冊。第九の道具——「読む手」——は、開かれたまま物語の外であなたを待っている。

**【差別化の一文】**
転生を「死んで得る」から「綴じられて残る」へ——読者がページのノドで自分ごと綴じ込まれる、装幀という触覚体験そのものを物語にした一点。

---

**設計者の逸脱註**：前作《送り火》は「見る」受動性に耽溺した。私はそれを全否定する。体験の完成は「作る」喜びにしか宿らない。八つの目は八つの道具へ、見送りは綴じへ、踏切はノドへ——すべてを受動から能動へ引き裂いた。読者はもはや「見届ける証人」ではない。読者は第九の道具、すなわち**製本を完成させる最後の工程そのもの**である。
