# 《迎え火》——世界と世界の間で、君が八回、僕を捨てる

**核心的主張**
異世界転移は救済ではない、殺人である。転移の瞬間、現世の「自分」は死に、逃げた「自分」だけが異世界へ届く——この物語は、誰も語らなかった「捨てられた側」から、逃げた者へと突きつける唯一の異世界モノである。

**根拠**
- 異世界モノの読者の欲望の本質は「現世の自分を捨てて別の自分になる」ことであり、ジャンル全体が「捨てた自分」への罪を抑圧してきた。
- 転移の「行き」だけが描かれ、「残された人生」は一度も語られない。ここに未踏の鉱脈がある。
- 読むこと自体が現世からの逃避である以上、読者はこの物語の加害者として作中に組み込める——読書体験そのものを倫理の舞台にできる。

**前提**
「転移」とは魂の移送ではなく、一つの人生の分岐＝捨てる行為である。

**独自フック**：魂は転移のたびに「残る自分」と「逃げる自分」へ分裂する。異世界とは、その「捨てられた自分たち」が積み重なった堆積層である。

**世界のルール**：異世界の街も住人も魔物も、誰かが捨てた「なりそこねた人生」の成れの果て。転移者が異世界で最強になれるのは、異世界が捨てた者への補償装置だから——強くなるほど、現世に積み上がる残骸（捨てた自分）が増える。

**主人公＝迎え火**：無数の転移者が捨てた「残された自分」が互いを繋いで生まれた集合意識。欲望は「一度でいいから、捨てた側に『捨てた』と認めさせること」。だが真の飢えは「自分こそ、一度は誰かに迎えてほしかった」——彼もまた、捨てられ側の傷を一人で抱える。

**第一幕**：踏切で死ぬはずの女子高生・篠宮花の足を、トラックの代わりに「残された自分」が掴む。門は開かず、迎え火が立ちはだかる。「逃げるな」。花は、逃げること＝自分の人生を殺すことを初めて突きつけられ、捨てた自分を回収して留まるか、迎え火ごと捨てて異世界へ逃げるかを賭けられる。

**差別化（一文）**：俺TUEEE・ハーレム・追放ざまぁの根底にある「現世を捨てて別の自分になる」という救済幻想そのものを加害として逆転する——強くなるほど罪が積み重なる、反異世界モノである。
