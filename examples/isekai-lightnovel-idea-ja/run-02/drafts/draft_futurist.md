# 《送り火》改修案——死の質屋、第九の目は読者の死

**主張（逸脱の核心）**
前作は「転生装置そのものを主人公にした」時点で唯一無二だった。なのに結末で送り火が第九の位置を埋め、物語を**閉じた**。そこが唯一の敗北だ。改修は一点だけ——**第九の目の決済権を読者の死に譲渡し、この物語を読者が死ぬまで未完にせよ**。読者は見送りの証人ではない。物語の**担保**だ。

**価値が時間とともに増す根拠**
- AIがテンプレ異世界を無限量産するほど「完成した物語」は暴落し、「一度きり・未完成・読者固有」の体験だけが希少化する。未完を担保にした本作の価値は量産が進むほど単調増加する。
- ラノベ読者層は俺TUEEE世代がそのまま高齢化する。ジャンルが二十年密かに売ってきた「死の無限延期」という約束が、読者が親を看取る歳になって初めて破産する。死を預かる装置への需要は今から上がる。
- 造本が読者の書き込み・劣化とともに変わる設計は再読を**複利**にする。一度読んで捨てる俺TUEEEと価値曲線が反転する。

**①独自フック**：転生＝死を質に入れ、第二の生を借金すること。返済期限は誰にも見えない。入口の意識・送り火は、質流れした死の山を八つの目で査定する番頭——転生装置は「送る側」をやめ、「預かる側」に変わる。

**②世界ギミック**：八つの目＝八種類の**死の先物**（糸・値段・余白・未完の原稿・残り時間・見られる間だけ動く死体・運転席の空席・まだ来ていない死）。各巻は一つの先物の精算。⑤「残り時間」の目だけ、読者の実年齢に連動して読める文字数が増える造本になっている。

**③主人公**：送り火。八目はすべて他人の死を査定する器官で、自分を映す目を一つも持たない。葛藤は「見送りたい」ではない——**自分だけ一度も死を質に入れたことがない、つまり一度も生を借りたことがない**という空白。欲望は「生の借金」そのもの。

**④第一幕**：質流れした死の山から、返済期限がマイナス＝生きたまま死んでいるはずの魂・篠宮花が、死を**返品**しに現れる。八つの目が初めて同時に「この死は返せない」と割れ、送り火自身の預かり死すべてが全清算の危機に晒される。

**⑤差別化**：俺TUEEE・ハーレム・ざまぁが「生の無限勝利」を量産するのに対し、本作は死の受領を先物装置として書き、読者が老いるほど、AIがテンプレを量産するほど価値が上がる逆張りである。

**前提**：死の一回性は、AI時代においても代替不能な資源であり続ける。
