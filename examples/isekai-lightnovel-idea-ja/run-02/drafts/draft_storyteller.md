# 《送り火》改修草案——Storytellerの極限テーゼ

**核心的主張（3文以内）**

語り継がれる核は「転生装置が主人公」ではない——それは仕掛けにすぎない。人が人に語るのは、**「皆を送る者は、一度も送られたことがない。その者の元へ、送られた先からたった一人が引き返してくる」**という、取り替えのきかない借りの話だ。篠宮花の拒否は「行きたくない」ではなく「**私があなたを、行かせに来た**」であり、八つの目で無数の魂を送ってきた門が、初めて一つの魂から「送られる側」に回る——その逆転を核に据え、最終頁で、異世界ジャンルに幾千回「送られて」きた読者こそが門を見送る九つ目の目＝唯一の証人として配置する。

**根拠（箇条書き3点・各1文）**

- 語り継がれる物語の最小単位は「私と、替えのきかないあなた」のあいだの負債であり、前版の転（拒否した魂＝自分自身の断片）は自己対話に収斂して誰の口にも乗らない——実在する第二の人が「送られた先から門のために戻る」という一方向の借りが逆流する瞬間だけが、他人の口に乗る。
- 「皆を送る者は一度も送られない」は一文で通じ、しかも読者が消費してきた無数の転生モノ全部を、この門が黙って送り続けた名もなき乗客へと読み替えてしまう——読者自身の「ジャンルへの負債」がそのまま回収される仕掛けになっている。
- 最終頁の読者＝九つ目の目は造本の小技ではなく物語の返済であり、これまで「読者を異世界へ送り出す側」だったジャンルが初めて「読者を一人の人間として見届ける側」に回る瞬間として、自然に語り出される。

**前提（1文）**

人が物語を他人に話すのは概念の独白ではなく、二人のあいだで一方通行だった負債が逆流するのを目撃したからである。

**差別化一文（テンプレ対比）**

俺TUEEEもハーレムも追放ざまぁも「行く／行かされる」物語だが、本作は「行かせた者が、行かせた相手に連れ戻される」物語である。
