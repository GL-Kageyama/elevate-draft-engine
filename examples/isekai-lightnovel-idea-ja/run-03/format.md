# 出力形式（OutputFormat）

- 成果物種別: シリーズ構成案（各話プロット）
- 説明: 《受け火》の企画を土台に、タイトル候補・最適な話数・各話で何が起こるかの概要を具体化したシリーズ構成案。そのまま執筆・連載へ移せる完成度で、タイトル／話数／各話あらすじの3要素が整合していること。
- 出力長の範囲: 1500〜8000 字
- 成果物そのもの: はい（output_is_direct）

## 草案の形式指示（draft_guidance）

各草案は本文の散文ではなく、1本の完成したシリーズ構成案を提示すること。必ず以下を具体的に含め、与えられた企画案《受け火》の独自の核（受動態・八つの能動動詞・送り火から受け火への反転・名付けられる結末）を保存しつつ、他案とは明確に異なる角度から書くこと。
（1）タイトル候補を複数挙げ、最終推奨と命名理由を示す。
（2）最適な話数を具体的な数字で提案し、なぜその話数が最適かを物語構造から根拠づける。
（3）各話ごとに「何が起こるか」を、登場人物と出来事の因果まで分かる2〜4文で概要化する。

## 最終化の形式指示（finalize_guidance）

最終成果物は1本のシリーズ構成案を以下の見出しで構成せよ。各部分は具体的な固有名・具体場面・具体話数で書き、抽象形容に頼らないこと。
【タイトル案】複数候補と最終推奨、および命名理由。
【最適な話数と根拠】具体的な話数と、物語構造（起承転結・八つの器官・受動態への反転）から見た最適性の根拠。
【各話の概要】話ごとに「何が起こるか」を、主人公（送り火／受け火）と篠宮花の行動・葛藤・変化が追える具体性で書く。
