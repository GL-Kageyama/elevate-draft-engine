# 改修草案（Futurist観点）：『該当なし』
**——受け火・誰かに留められ、名付けられるまで**

## テーゼ
能動態はこの五年でゼロ円に収斂する——生成AIが〈送る〉〈書く〉〈語る〉を無料化した先で、価格は〈受け手〉（選ばれる・待たれる・名付けられる）へ一気に移る。『受け火』の真価は盆の情緒ではなく、AIが原理的に占有できない唯一の態＝受動態を先物で買うことにある。今これを「文学的ガジェット」としか読めない評価は、到来する受動態プレミアムを織り込んでいない。

## 隠れた可能性（今は過小評価）
八つの器官は「葬式の隠喩」として読まれているが、実は生成AIのデータパイプラインの正確な予言である——送る＝生成、綴じる＝執筆、呑む＝学習、預かる＝保存、測る＝評価、値付ける＝価格、悼む＝廃止、捨てる＝削除。篠宮花の「該当なし」は、どのモデルにも分類できない人間の残余。境界＝モデルが「分類不能な入力に、初めて処理されたい（受動態）と願う」物語として、五年後に読み直される。今は葬式ファンタジー、のちにAI時代の預言書。

## （1）タイトル候補
1. **『該当なし』**（最終推奨）＋ 副題『受け火』
2. 『受け火』（原案）
3. 『九つ目の器官』
4. 『名前を待つ』
5. 『受け身の送り火』

**命名理由**：表題を『該当なし』に据えるのは、この案の最も過小評価された一点を表面化するためである。『受け火』の価値は既知の語「送り火／迎え火」への対比＝既存の盆コードに依存しており、それ自体では差分を生まない。一方「該当なし」はシステムのエラー語彙でありながら、能動態が無料化する未来で「人間の残余」だけが高騰する時代の値札を先取る四文字である。副題に『受け火』を残すことで、核である送り火→受け火の反転は保存する。

## （2）最適話数：全9話（単巻・9章）
根拠：8＝八つの能動動詞＝「能動態の在庫」、1＝受動態の一点。境界は受動態を生きる前に、八つの能動器官を「自分から手放す」必要があり、その手放し（減衰）こそが本編である。8+1という数は「能動の総和の上に受動が一点だけ乗る」という本作の文法そのものの暗号化である。8話は能動態の減衰曲線（各話で器官が一つずつ機能不全を起こす）、9話だけが受動態。さらに9話の末尾を「読者が名を書き込む空白」にすることで、作品は読者が名付け終えるまで完成せず、読まれるたびに増殖する——すなわち価値が時間で増す未完の設計。

## （3）各話概要

**第1話「送る」**：境界は老女の魂を送り終えるが、彼女が死の間際に「あなたは誰に送られるの」と問うたことで、初めて自分の器官の外側に「受け取る穴」の存在を自覚する。篠宮花はまだ現れない。この問いが八器官すべてを走る最初の亀裂となる。

**第2話「綴じる」**：読まれなかった作家の魂を綴じる仕事で、境界は「綴じる」はできても「読む／読まれる」の器官を持たない事実に直面する。作家の魂が「読まれたい」と泣くとき、境界は自分が最初に捨てた「読まれる自分」の不在を初めて直接見る。

**第3話「呑む」**：呑み込まれなかった胎児の魂を呑み、境界は内側から「迎えられる」という受動の声を聞く。呑むことは胎の代わりだが、呑まれた魂は境界の内で「迎えられる」を求めて泣き、境界は自分の飢えと同型の声に内側から揺さぶられる。

**第4話「預かる」**：死後も誰かを待ち続ける魂を預かる仕事で、境界は「待つ（受動）」を肩代わりする自分と、「待たれる者」に一度もなれない自分との差に気づく。預かるとは、受け取る穴を他人の分だけ先に埋める、最も残酷な能動だったと判明する。

**第5話「測る」**：魂の残り火の長さを測ることに没頭する境界は、自分が「測られる＝値踏みされる」ことを避けるために測る側に立ってきたと悟る。能動の仮面の裏にあるのは支配欲ではなく恐怖——「測られるのが怖いから測る」という反転が、八器官の正体を初めて露呈させる。

**第6話「値付ける」**：転生先の価値を値付ける際、ある魂が「値段のない生」を望み、境界は値付け不能に直面する。システムが初めて「該当なし」を返すバグが起き、篠宮花の到来が予告される。値付けが価格の押し付けであると同時に、その外側に花の位置が定まる。

**第7話「悼む」**：誰にも悼まれなかった者の弔いで、境界は初めて「自分を悼んでほしい」と装置の外の声で呟いてしまう。悼む能動を持つ者が、悼まれる受動を一度も受けていない——この一言が、彼がまだ人間である残骸として残る。

**第8話「捨てる」**：八つ目の器官「捨てる」は、境界が自分を最初に捨てた記憶の再演であることが明かされる。彼が捨ててなお残った受動の部分として現れたのが篠宮花。花は八器官すべてに「該当なし」を返し、境界を初めて〈捨てない〉と留める。

**第9話「受け火」**：境界は「花を送って流れを戻す」か「花に留められ、受動態を生きる」かの選択を迫られ、後者を選ぶ。選んだ瞬間、八つの器官は順に停止し、境界は装置から人へと降りる。最終頁は本文が消え、主人公の名を書き込む空白だけが残る——第1〜8話の全動詞が受動態に反転して読み直される仕掛けであり、読者が名を書くまで物語は完成しない。
