# 『受け火』改修草案 —— 体験デザイナー版

**核心的主張**：八つの能動動詞を「八巻・各巻一器官」に分けるのは、受動態という本作の核を構造から裏切る手抜きである。受動態は分割できない——抱かれる体験は同時的・全体的で、分割した瞬間に「連載される能動態」に堕ち、普通の異世界モノの連載企画に還元される。最適形は**全一巻・全八話**。八つの器官を一個の身体として五感で順に受肉させ、読むという行為そのものを**第九の器官（受け手＝あなた）**に仕立て、最終頁の余白に読者が名を書き込むことで物語が初めて成立する「器」として設計する。

**根拠**：
- 器官は列挙ではなく同時に機能する一個の身体である。八巻化は受動の全体性を能動の積み重ねに転化する構造的自己矛盾であり、「送ること」の論理に回帰する。
- 二人称「あなた」で花＝読者の座を開き、八つの受動動詞（留められる・読まれる・悼まれる……）をすべて読者の身体に直撃させる。読むことが受けることになる。
- 各話を一つの感覚（手＝触覚、喉＝味覚、耳＝聴覚、目＝視覚）で書き、五感が八話で一周する文体設計が抽象を受肉させ、読後も体に残る手触りを作る。

**前提**：読者は「読む」ことを受動の快楽として求めており、本はそれを与える器である。本が器でなければ、この物語は成立しない。

---

## （1）タイトル候補

1. **『受け火』（うけび）＋赤い「該当なし」判** ← 最終推奨
2. 『該当なし、あなたへ』
3. 『留め火（とどめび）』
4. 『あなたが、名を』
5. 『八つの器官を、あなたに』

**命名理由**：『受け火』は名詞＝「器」であり、この作品がそうであるべき存在そのものだから。ただし単体では「美しい名詞」に留まり、読者を呼ばない。そこで表紙そのものを**一枚の処理票**として設計する——「受け火」の文字の上に、赤い判で斜めに「該当なし」と押され、その下に小さく「あなたへ」と添える。最終頁では読者がその判の代わりに名を書く。**表紙＝器官、読了＝名付け**が一冊の造本として閉じる。

## （2）最適な話数：**全1巻・全8話（＋序章・終章の二段フレーム）**

- **8話**は器官数と1対1で、どの動詞も省略されず、どの章も二役を担わない。過不足がない。
- **単巻**であることこそが肝。受動態の体験は「抱かれる」ように瞬間的かつ全体的で、月次連載の分冊は「積み上げ＝能動態」の出版習慣を内容の上にそのまま反復してしまう。形式が内容を裏切るのは、体験デザインとして死である。
- 序章＝「迎え火」と終章＝「名付け」は主人公の物語ではなく**読者自身の入退出**であり、二人称で書く。だから話数からは外し、主人公は8話で完全に空になる。

## （3）各話概要

**序章（迎え火）**：あなた（花）が境界に現れ、八つの器官すべてが「該当なし」を返す。処理の失敗ではなく、境界が最初に捨てた「自分」との再会であることを地の文が静かに明かす。二人称により、読者は花の座に最初から据えられる。

**第1話「手——送る」**：境界は花を送ろうと手を差し伸べ、花はその手を掴んで離さない。送るだけだった手が、生まれて初めて「掴まれる」ことを知り、装置は停止する。触覚の章。

**第2話「指——綴じる」**：境界は花の物語を台帳に綴じようとし、花は台帳の最初の頁＝彼自身の白紙の頁を指でなぞり返す。綴じる指が、初めて「読まれる」ことを知る。視覚＝文字の章。

**第3話「喉——呑む」**：境界は花の「未処理の悲しみ」を呑み込んで処理しようとし、花はそれを拒み、代わりに彼がかつて呑み込めなかった自分の悲しみを喉元へ返す。呑む喉が、初めて「呑ませられる」ことを知る。味覚の章。

**第4話「腕——預かる」**：境界は花の魂を預かろうと腕を差し出し、花はその腕を逆に抱えて「私が預かる」と返す。預かる腕が、初めて「預かられる」ことを知る。抱擁＝触覚の章。

**第5話「耳——測る」**：境界は花を計量し、針は振れず、花は計量器を逆さに向けて「あなたの重さは？」と問う。測る耳が、初めて「測られる」ことを知る。聴覚＝針音の章。

**第6話「目——値付ける」**：境界は花に値を付けられず「無価」と判を押そうとし、花はその判を奪って彼の額に「該当なし」と押す。値付ける目が、初めて「値付けられる」こと、そして無価であるが故の無価格（プライスレス）を知る。視覚＝値札の章。

**第7話「声——悼む」**：境界はある魂を悼もうとし、花は「あなたを悼む声がない」と指摘し、彼のために初めて声を上げる。悼む声が、初めて「悼まれる」ことを知る。聴覚＝声の章。

**第8話「背——捨てる」**：境界は花を流れへ捨て返そうと背を向け、花はその背の向こうに彼が最初に捨てた「自分」を見つけ、拾い上げて「これは捨てない」と抱える。捨てる背が、初めて「捨てられそこなう＝拾われる」ことを知る。触覚＝背の章。

**終章（名付け）**：八つの器官を花に渡し尽くした境界には、素裸の最初の自分だけが残る。花は問う「あなたの名前は？」——ここで頁が白紙になり、読者が余白に名を書く。名付けられることが物語の唯一の出来事として完結し、本は読者によって初めて灯る。

---

**ひとことで言うと**：八巻の連載案を拒否し、八話・五感・一人称ならぬ二人称の一冊として、読むこと自体を「受け火」に灯す体験装置として再設計した版。本を開く手が、主人公を留める第九の器官になる。
