# 创意水平（--idea-level）

创意水平选择 发散（diverge）与 升华推理（Aufheben）要走到多极端。通过**两个杠杆**适用：递进式**发散提示**（主杠杆）+ **温度**（辅助杠杆）。采用两杠杆设计的原因：reasoning 模型（经网关的 deepseek-v4-pro）对温度超过 1 的反映并不可靠。提示在 prompt 中承担「更极端」的语义，温度在采样中加以强化。

| 水平 | 温度 | 含义 | 发散/升华提示 |
|---|---|---|---|
| `standard`（默认） | 0.9 | 一般地极端 — 既有的行为（向后兼容） | `[発散を重視]` |
| `very` | 1.2 | 非常极端 | `[非常に極端な発散を重視]` |
| `extreme` | 1.5 | 极度极端 | `[極度に極端な発散を重視]` |

无论水平如何，最终化都始终使用温度 **0.0**。

## 两杠杆设计的依据（调查发现）

- **网关受理超过 1 的温度。** 通过直接 API 调用确认 DeepSeek 的 Anthropic 兼容端点可无错受理温度 1.2・1.5。这回答了最初的调研问题「温度の1越え設定の可否」——可以，超过 1 的值可设置。
- **在 reasoning 模型上，温度单独不是可靠的杠杆。** 网关的 reasoning 模型通过扩展思考块作答，单次采样无法证明仅凭温度就能得到可测量的「更极端」输出。因此语义主要由提示承担，温度作为强化。
- **适当的参数值**（对「どの程度のパラメータが適切なのか」的回答）：水平构成 0.9 / 1.2 / 1.5 的单调阶梯。超过 1.5 的值有语无伦次的风险；0.9 则让默认行为与旧版本完全一致。

## 各引擎的行为

| 引擎 | 水平的适用方式 |
|---|---|
| `sdk`（默认） | 把温度与提示两者都传给 API |
| `claude-code` | 没有温度旋钮（`claude -p`）。仅通过提示近似水平 |

`sdk` 引擎**仅在显式指定 `idea_level` 时**注入提示，因此既有的仅温度调用保持原行为。`claude-code` 引擎优先使用创意水平（3 档），未指定时回退到既有的基于温度的两档提示。
